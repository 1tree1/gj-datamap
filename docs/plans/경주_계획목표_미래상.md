# 경주 — 도시기본계획 · 도시재생 계획목표와 미래상 정리

작성 2026-11-01. 두 계획을 **따로** 정리했다. 각 항목 끝의 등급은 리포 기준(T1 원문 전사 / T2 2차 보고서 / T3 학술·백과 / T4 언론·웹).

> **확인 필요.** 아래 서술 문구(미래상·목표·전략)는 클라우드 세션에서 뉴스·시청 사이트 본문을 직접 열 수 없어 **검색 결과 요약(T4)** 에서 옮긴 것이다. 정량 수치만 리포 `public/data/report_stats.json`(2030 기본계획 승인본 전사, T1)에서 가져왔다. `9_도시/`의 md 전사본과 대조한 뒤 등급을 올리거나 문구를 고쳐야 한다.

## 2. 도시재생

### 2-1. 경주시 도시재생 전략계획(변경), 2022.01

- 법적 근거: 도시재생특별법 §17 (전략계획), 변경 공고 2022.02.10 (경주시 공고, hwp 첨부 — 본문 미확인)
- 계획 범위(공청회 공고): **성건·성동·황오동**. 주요 내용: 활성화지역 지정 변경 · 사업 우선순위
- **비전·목표 문구: 미확인.** 검색 결과에 본문이 없음. `9_도시/` 전사본에서 보충해야 할 1순위 항목.
- 리포에 반영된 T1 내용은 **쇠퇴진단 표(p.251)** 만: 3지표(인구 20%↓ 또는 3년 연속 감소 / 사업체 5%↓ 또는 3년 연속 감소 / 20년↑ 노후건축물 50%↑) 중 2개 이상 충족 동을 활성화지역 후보로 봄. 황남동 노후건축물 82.0%.
