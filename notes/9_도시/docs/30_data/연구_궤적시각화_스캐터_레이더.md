# A_t–ρ_t–H′_t 궤적 시각화 패턴 + 두 도시 비교 워크플로우

> 원문 제목: "도시별 A_t–ρ_t–H′_t 궤적을 시각화하는 패턴(예: 스캐터 + 화살표, 레이더 차트), 혹은 두 도시(예: 서울 vs 대구)를 비교하는 최소 예제 워크플로우"
> 출처 성격: Perplexity 기반 리서치 정리

전제: 이전 단계에서 다음 형태의 테이블을 이미 만들었다고 가정한다.

```text
df_metrics columns:
- city_id      (예: 'seoul', 'daegu')
- year         (예: 2000, 2005, ... )
- A_t          (도시+준도시 권역 면적, km2)
- P_t          (도시+준도시 권역 인구)
- rho_t        (평균 인구밀도, 명/km2)
- H_rel_t      (상대 엔트로피, 0~1)
```

---

## 1. 도시별 A–ρ–H′ 궤적: 스캐터 + 화살표

### 1) 컨셉

- x축: 평균 인구밀도 ρ_t (명/㎢)
- y축: 도시화 권역 면적 A_t (㎢)
- 색상: 상대 엔트로피 H′_t (0~1 → compact~sprawl)
- 연도 순서대로 점을 찍고, 인접 연도 사이를 **화살표(벡터)**로 이으면 "시간에 따라 도시가 어느 방향으로 움직였는지"가 시각적으로 보인다.

해석 예시:

- 오른쪽 위로 이동(ρ↑, A↑): 인구·면적 동시 증가, 고밀 확장
- 오른쪽 아래(ρ↑, A↓): 면적은 줄고 밀도는 증가 → 재집약/재개발
- 왼쪽 위(ρ↓, A↑): 전형적인 sprawl — 저밀 확산
- 색이 점점 진해지며 H′가 1에 가까워지면 점점 분산형으로 변하는 것

### 2) 단일 도시 궤적 시각화 pseudo-code (matplotlib)

```python
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.colors as mcolors
import numpy as np

def plot_city_trajectory(df_metrics, city_id):
    # 1) 대상 도시 필터 + 연도 정렬
    d = df_metrics[df_metrics["city_id"] == city_id].sort_values("year")

    # 2) 값 추출
    years = d["year"].values
    rho = d["rho_t"].values
    A = d["A_t"].values
    H = d["H_rel_t"].values  # 0~1

    fig, ax = plt.subplots(figsize=(7, 6))

    # 3) scatter + color = H'
    sc = ax.scatter(rho, A, c=H, cmap="viridis", s=80, edgecolor="k", zorder=3)

    # 4) 인접 연도 간 화살표(벡터) 그리기
    for i in range(len(years) - 1):
        x0, y0 = rho[i], A[i]
        x1, y1 = rho[i+1], A[i+1]
        ax.annotate(
            "", xy=(x1, y1), xytext=(x0, y0),
            arrowprops=dict(arrowstyle="->", lw=1, color="gray", alpha=0.7),
            zorder=2
        )

    # 5) 각 점에 연도 라벨 (선택)
    for x, y, yr in zip(rho, A, years):
        ax.text(x, y, str(yr), fontsize=8, ha="left", va="bottom")

    # 6) 축/컬러바 설정
    ax.set_xlabel("평균 인구밀도 ρ_t (명/㎢)")
    ax.set_ylabel("도시+준도시 권역 면적 A_t (㎢)")
    ax.set_title(f"{city_id} 도시화 궤적 (A_t vs ρ_t, 색=H'_t)")

    cbar = plt.colorbar(sc, ax=ax)
    cbar.set_label("상대 엔트로피 H'_t (0=집중, 1=분산)")

    plt.grid(alpha=0.3)
    plt.tight_layout()
    return fig
```

### 3) 여러 도시를 한 번에 그리는 패턴 (small multiples)

```python
def plot_multiple_cities_trajectories(df_metrics, city_ids):
    n = len(city_ids)
    ncols = 3
    nrows = int(np.ceil(n / ncols))

    fig, axes = plt.subplots(nrows, ncols, figsize=(5*ncols, 4*nrows), sharex=True, sharey=True)
    axes = axes.flatten()

    for ax, city_id in zip(axes, city_ids):
        d = df_metrics[df_metrics["city_id"] == city_id].sort_values("year")
        if d.empty:
            ax.axis("off")
            continue

        years = d["year"].values
        rho = d["rho_t"].values
        A = d["A_t"].values
        H = d["H_rel_t"].values

        sc = ax.scatter(rho, A, c=H, cmap="viridis", s=40, edgecolor="k")

        for i in range(len(years) - 1):
            x0, y0 = rho[i], A[i]
            x1, y1 = rho[i+1], A[i+1]
            ax.annotate("", xy=(x1, y1), xytext=(x0, y0),
                        arrowprops=dict(arrowstyle="->", lw=0.8, color="gray", alpha=0.7))

        ax.set_title(city_id)
        ax.grid(alpha=0.3)

    # 공통 축 라벨
    fig.text(0.5, 0.04, "평균 인구밀도 ρ_t (명/㎢)", ha="center")
    fig.text(0.04, 0.5, "도시+준도시 권역 면적 A_t (㎢)", va="center", rotation="vertical")

    # 컬러바는 하나만
    cbar = fig.colorbar(sc, ax=axes.tolist(), shrink=0.7)
    cbar.set_label("상대 엔트로피 H'_t")

    plt.tight_layout(rect=[0.06, 0.06, 1, 1])
    return fig
```

## 2. 두 도시 비교: 레이더 차트 (서울 vs 대구)

### 1) 컨셉

스프롤/도시화를 "다차원 지표 묶음"으로 보는 경우, 여러 지표를 동시에 보여주기 위해 레이더(스파이더) 차트를 많이 쓴다. A_t, ρ_t, H′_t는 값의 스케일이 달라 그대로는 비교가 어렵기 때문에, **정규화(z-score, min-max 등)** 후 레이더에 올린다.

특정 연도(또는 "초기–말기 평균")에 대해:

- 축1: 정규화된 A_t (도시화 면적 크기)
- 축2: 정규화된 ρ_t (전반적인 밀도)
- 축3: 정규화된 H′_t (분산 정도)

### 2) 데이터 정규화 pseudo-code

```python
def normalize_minmax(series):
    vmin = series.min()
    vmax = series.max()
    if vmax == vmin:
        return series * 0 + 0.5  # 둘 다 같으면 0.5로
    return (series - vmin) / (vmax - vmin)
```

```python
def prepare_radar_data(df_metrics, year, cities=("seoul", "daegu")):
    d = df_metrics[(df_metrics["year"] == year) & (df_metrics["city_id"].isin(cities))].copy()

    # 필요한 지표만 선택 (필요하면 log변환 등도 여기서)
    raw = d.set_index("city_id")[["A_t", "rho_t", "H_rel_t"]]

    # 열별 min-max 정규화
    norm = raw.apply(normalize_minmax, axis=0)
    return norm  # index: city_id, columns: ['A_t','rho_t','H_rel_t']
```

### 3) 레이더 차트 그리기 pseudo-code (matplotlib polar)

```python
import numpy as np
import matplotlib.pyplot as plt

def plot_radar_for_two_cities(norm_df, metric_labels=None, title="도시 비교 레이더 차트"):
    """
    norm_df: index=city_id, columns=metrics (정규화된 0~1 값)
    """
    cities = norm_df.index.tolist()
    metrics = norm_df.columns.tolist()
    if metric_labels is None:
        metric_labels = metrics

    N = len(metrics)
    angles = np.linspace(0, 2*np.pi, N, endpoint=False).tolist()
    angles += angles[:1]  # 폐곡선

    fig, ax = plt.subplots(figsize=(6, 6), subplot_kw=dict(polar=True))

    for city in cities:
        values = norm_df.loc[city].values.tolist()
        values += values[:1]
        ax.plot(angles, values, label=city)
        ax.fill(angles, values, alpha=0.1)

    # 축 세팅
    ax.set_xticks(angles[:-1])
    ax.set_xticklabels(metric_labels)
    ax.set_yticklabels([])  # 반지름 눈금 제거(선택)
    ax.set_title(title)
    ax.legend(loc="upper right", bbox_to_anchor=(1.1, 1.1))

    return fig
```

사용 예:

```python
year0 = 2020
norm_df = prepare_radar_data(df_metrics, year0, cities=("seoul", "daegu"))
fig = plot_radar_for_two_cities(
    norm_df,
    metric_labels=["면적 A_t", "밀도 ρ_t", "분산 H'_t"],
    title=f"서울 vs 대구 도시 상태 ({year0}년, 정규화 지표)"
)
```

- 서울이 "A_t 크고, ρ_t 크고, H′_t도 높다" → 광역적·고밀·다소 분산형 구조
- 대구가 "A_t 작고, ρ_t 높고, H′_t 낮다" → 상대적으로 콤팩트한 단핵 고밀 구조

## 3. 두 도시 궤적 직접 비교 (화살표를 색/스타일로 구분)

```python
def plot_two_cities_trajectories(df_metrics, city1, city2):
    fig, ax = plt.subplots(figsize=(7, 6))

    for city_id, color in [(city1, "tab:blue"), (city2, "tab:orange")]:
        d = df_metrics[df_metrics["city_id"] == city_id].sort_values("year")
        years = d["year"].values
        rho = d["rho_t"].values
        A = d["A_t"].values

        ax.plot(rho, A, marker="o", color=color, label=city_id)

        # 각 점에 연도 라벨
        for x, y, yr in zip(rho, A, years):
            ax.text(x, y, str(yr), fontsize=8,
                    ha="left", va="bottom", color=color)

    ax.set_xlabel("평균 인구밀도 ρ_t (명/㎢)")
    ax.set_ylabel("도시+준도시 권역 면적 A_t (㎢)")
    ax.set_title(f"{city1} vs {city2} 도시화 궤적 (A_t vs ρ_t)")
    ax.grid(alpha=0.3)
    ax.legend()
    plt.tight_layout()
    return fig
```

색 대신 선 종류(실선/점선)나 마커 모양을 도시별로 달리면 프린트용 흑백 도표에도 대응할 수 있다.
