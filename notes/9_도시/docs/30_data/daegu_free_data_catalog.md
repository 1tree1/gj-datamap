# M. 데이터 수집 우선순위 (실전 순서)

재개발 분석을 위해 **가장 먼저** 받아야 할 순서:

### 🔴 1순위 — 즉시 다운로드 (첫 1주)
1. **건축물대장** (data.go.kr) → 건물 노후도 맵의 핵심
2. **주민등록인구** (jumin.mois.go.kr) → 인구감소/고령화 맵
3. **용도지역** (luris.molit.go.kr) → 재개발 가능 여부 판단
4. **공시지가** (realtyprice.kr) → 경제성 분석
5. **기상관측** (data.kma.go.kr) → 폭염/열섬 분석 기초

### 🟡 2순위 — 1개월 내 수집
6. **DEM 수치표고** (map.ngii.go.kr) → 분지 지형/경사 분석
7. **Landsat/Sentinel 위성** (GEE) → LST 열섬/NDVI 녹지 분석
8. **도시철도·버스 승하차** (data.go.kr) → 접근성 분석
9. **상권정보** (sg.sbiz.or.kr) → 경제활력도
10. **생태자연도 + 토지피복** (egis.me.go.kr) → 생태 제약 조건

### 🟢 3순위 — 분석 심화 단계
11. **지질도 + 시추공** (data.kigam.re.kr + geoinfo.or.kr) → 지반 안전성
12. **도시재생전략계획 PDF** (dgucenter.or.kr) → 기존 계획 검토
13. **항공사진 시계열** (map.ngii.go.kr) → 도시 변천 분석
14. **생활인구** (data.kostat.go.kr) → 실질 도시 사용 패턴
