# 구경주역 부지 — 소스 감사 및 확장 카탈로그 (2026.09)

> 선행 문서: `docs/10_gyeongju/구경주역_부지_자료_아카이브_설계.md`
> 1차 목록은 "행정이 이미 만들어 놓은 자료"에 치우쳐 있었음. 아래 6개 층(G1–G6)이 누락.

## G1 시간 축 — 현재 상태만 모으고 있었다

경주역 1918년 개통. 이 부지는 식민지기 철도도시화의 산물이고 그 형성 과정 자체가 설계 논거이자 논문의 축.

- 연도별 과거 항공사진(1970년대~) — 국토정보플랫폼, 공공데이터포털 항공사진
- 근대 지적원도·조선총독부 지형도·토지조사부 — 국가기록원, 국토정보플랫폼 고지도
- 구 지형도 1:25,000 시계열 — 국토지리정보원 (성토 이력)
- OSM 편집 이력 / 건축물대장 사용승인일 분포 → 건축연한 지도
- 지가·실거래 시계열, 국내인구이동(전입전출)

**분석 기회**: 2021년 폐역을 처치(treatment)로 둔 준실험 설계 — 폐선축 인접 필지 vs 대조군의 지가·개폐업·인구 비교. 국내 폐선부지 연구에서 아직 드묾.

## G2 법정 쇠퇴진단 지표 — 공모 자격 요건 자체가 없었다

도시재생법상 활성화지역·혁신지구는 인구감소·사업체감소·노후건축물 3요건 중 2개 이상 충족 필요.

- 도시재생 종합정보 개방체계 — 읍면동 쇠퇴진단 지표 원자료
- 노후건축물 비율 — 건축물대장 사용승인일에서 직접 산출(20/30년 병기), S2 집계구 단위
- 사업체 수·종사자 변화 — 전국사업체조사, SGIS 5개년
- **경주시 인구감소관심지역 지정(2025.12.30, 전국 18곳)** — 지방소멸대응기금 연계 논거. 지정 고시·근거지표 T1 확보
- 복합쇠퇴지수 — 인천연구원 등 선행 방법론 차용

## G3 재해·지질 제약 — 노반 위에 짓는다는 사실

2016 경주지진 M5.8, 양산단층대. 부지는 수십 년 하중을 받은 철도 노반·성토층.

- 활성단층 지도·지진위험지도 — 지질자원연구원, 행안부 활성단층 조사사업
- 시추공 지반정보(N값·토층) — 국토지반정보 통합DB
- 지질도 1:50,000 — 지오빅데이터
- 홍수위험지도·침수흔적도, 토양지하수정보시스템, 국가지하수정보센터
- 기상청 ASOS/AWS·기후변화 시나리오, 에어코리아

## G4 실사용 프록시 — "서 있다"와 "쓰인다"는 다르다

- **건축HUB 건물에너지정보 서비스 API**(공공데이터포털) — 건물별 전기·가스. 0 수렴 = 실질 공실
- 야간조도 VIIRS/DMSP 시계열
- 소상공인 상가업소 DB 반기 차분 — 업종별 생존곡선
- 빈집 실태조사 — 국토부 빈집정보

→ 넷을 필지에서 조인하면 **"서 있으나 죽은 블록"** 지도. 부지 프로그램의 가장 강한 근거.

## G5 미시 물리 인프라

- 지하공간통합지도(상하수도·통신·가스·전력·공동구) — 인입/이설 비용
- **도로명주소 전자지도 건물 출입구 포인트** — 보행 네트워크 실제 시종점, 접근성 정확도 좌우
- 도로대장·도로폭·보도 유무 — H/W비, 가로유형 분류
- 주차장·가로등·CCTV·가로수
- 버스 승하차 실측(교통카드) — 한국교통안전공단 대중교통 현황조사, TAGO
- V-World 3D, 디지털트윈국토 — 조망·일조 시뮬레이션 입력

## G6 유산 도시 계획의 제도·방법론 — 가장 큰 누락

- **ICOMOS Heritage Impact Assessment 가이드** — 세계유산 인근 개발 영향평가 국제표준. 3,822억 규모면 사실상 요구됨
- **UNESCO Historic Urban Landscape 권고** — 유산을 도시 층위로 다루는 방법론, 개념 프레임으로 직접 사용 가능
- 세계유산 등재조서 및 **완충구역 경계** — 국가유산포털·UNESCO WHC
- **「신라왕경 핵심유적 복원·정비에 관한 특별법」 + 시행령, 핵심유적 14곳** — 경주 고유 법정 계획 체계, 지구단위계획과의 관계 정리 필요
- 경주시 경관계획·조망점(경관법)
- 고고학 매장문화재 분포 — 지하층 계획 상한

## 경주 특유의 사건 층

- **2025 APEC 정상회의 경주 개최** — 숙박·교통·경관 대규모 선행투자. 무엇이 생기고 무엇이 남았나 = "경주 STAY"의 수요 근거이자 반박 근거
- 대구경북신공항 — 관광 접근축 재편
- 신경주역(KTX)과의 이중 중심 — 구경주역 역할 정의의 전제
- 한수원 본사 이전·방폐장 유치지역 지원사업 — 재정·인구 개입 변수, 지역개발 선례집

## 먼저 손대야 할 열 가지 (착수 순서)

1. 도시재생 쇠퇴진단 지표 + 노후건축물 비율 자체 산출 — 공모 자격 요건
2. 인구감소관심지역 지정 고시·근거지표 — 재원 연계 논거
3. 세계유산 완충구역 경계 + 신라왕경 특별법 체계 — 규제 상한의 마지막 겹
4. 연도별 과거 항공사진 — 취득에 시간 소요
5. 건축HUB 건물에너지 API + 상가업소 개폐업 — 실질 공실 지도
6. 도로명주소 건물 출입구 포인트 — 접근성 분석 정확도
7. 활성단층·지반 시추공 — 층수·사업비 하한
8. ICOMOS HIA + HUL 권고 — 읽는 데 하루, 논리는 프로젝트 전체를 지탱
9. APEC 준비 투자 목록과 사후 시설 현황 — "경주 STAY" 수요 검증
10. 버스 승하차 실측 + GTFS — 등시선 입력

## index.csv 확장

두 필드 추가:
- `axis` — 시간 / 인구·쇠퇴 / 경제 / 이동 / 환경·재해 / 물리인프라 / 유산·경관 / 방법론
- `proxy_for` — 이 자료가 직접 측정하지 못하는 무엇의 대리 지표인가. **건물 에너지 사용량은 '에너지' 데이터가 아니라 공실의 프록시**이며, 기록하지 않으면 반년 뒤 자기 분석의 논리를 재구성할 수 없음
