# 도시의 강접·약접을 창의적으로 해석·시각화하는 프로그램 기획

> 원문 제목: "첨부한 파일와 여러 논문, 웹 서치를 바탕으로 어떠한 유형의, 어떠한 분야의 데이터들을 창의적으로 조합하여 기존 도시의 강접과 약접을 창의적으로 해석하여 이를 시각화하는 프로그램을 만들려면 어떤 계획, 준비사항들이 필요한지 연구해봐"
> 출처 성격: Perplexity 기반 리서치 정리 / 참조: urbanis_data_architecture.html

가능하다. 다만 단순 "지도 뷰어"가 아니라, **도시를 다층 그래프로 모델링해서 강한 연결(강접)과 약한 연결(약접)을 정량화·가시화하는 분석 플랫폼**을 만든다는 관점에서, 데이터 조합과 시스템 설계를 먼저 잡아야 한다.

---

## 1. '강접/약접' 개념부터 데이터 용어로 재정의

도시의 강접/약접을 그냥 "직감적인 느낌"이 아니라, **네 가지 축의 강·약 연결로 쪼개서 정의**하는 게 중요하다.

- 형태·네트워크 축: 도로망·블록 구조 상에서 **중심성(접속성)**이 높은 연결 vs 막혀 있거나 우회가 필요한 연결
- 기능·활동 축: 인구·유동·상권·시설 이용 데이터 상에서 **흐름이 집중되는 경로/공간** vs 거의 쓰이지 않는 공간
- 사회·경제 축: 인구 구성·소득·사업체 구조가 다양한 지점 간의 **연결(혼합)** vs 동질적인 집단끼리만 묶인 분리된 공간
- 환경·경험 축: 보행 경험·녹시율·소음·열섬·스트리트뷰 분석을 통해, **사람이 머물고 싶어 하는 공간의 연속성** vs 단절 지점

→ 이 네 축을 각각 "강접/약접 그래디언트"로 수치화하고, 나중에 통합해서 **도시의 강·약 결(結) 지도**로 보여주는 구조를 목표로 잡는다.

---

## 2. 데이터 축 설계 – 무엇을, 어디서, 왜 쓰는가

### 2.1 형태·네트워크(Physical / Network) 레이어

- 행정경계(시/군/구/동), 연속지적도(필지), 도로 중심선, 수계, DEM, 정사영상 등 **기초 공간 데이터**
- 소스: SGIS 행정경계, V-World 연속지적도/용도지역도/수계, OSM 도로네트워크, NGII DEM·정사영상
- 활용:
    - 도로교차로·블록 경계를 추출해 **도로 그래프 + 블록 단위 노드** 생성
    - 지형(경사), 수계, 대규모 기반시설이 만드는 **물리적 단절선(weak tie candidates)** 식별

### 2.2 기능·활동(Functional / Activity) 레이어

- 건축물대장(용도·연면적·연령), 토지특성, 개별공시지가, 실거래가
- 인구·가구·사업체 통계(SGIS 격자 + KOSIS), 유동인구·카드매출(가능한 범위 내), 학교·의료·상업·문화시설·교통시설 POI
- 활용:
    - 블록·필지 단위의 **용도 혼합도, 인구·고용 밀도, 상권·시설 집중도** 계산
    - 도로엣지 상의 통행량/이용량 프록시(유동+POI+통근 추정)로 **기능적 강접/약접 엣지** 산출

### 2.3 사회·경제(Socio-economic) 레이어

- 연령·성별·가구유형·소득(가능한 범위)의 행정동/격자 통계, 고령화율, 노후주택 비율 등
- 활용:
    - 서로 다른 사회·경제 구조를 가진 공간 간 연결이 **사회적 약접(bridging tie)** 역할을 하는 부분
    - 반대로, 동일 집단만 밀집된 **사회적 클러스터(닫힌 강접)**를 드러냄

### 2.4 규제·계획·환경 레이어

- 용도지역·지구, 지구단위계획구역, 도시계획시설, 정비·재생구역
- 대기질, 소음, 지표온도, 재해위험지구, 녹지·NDVI, 일사량·일조 등 환경 데이터
- 활용:
    - 법적·물리적 제약으로 인해 **연결이 끊기거나 왜곡되는 부분(약접)**
    - 환경·공원·녹지 네트워크가 만드는 **생태적 강접(그린 인프라 축)**

### 2.5 인지·경험(Perceptual / CV) 레이어

- 네이버 스트리트뷰 파노라마 → DeepLab/SegFormer 등으로 **녹시율(GVI), 스카이뷰 팩터, 입면 투명도/활성도, 노후도** 추출
- 위성·항공영상에서 건물·포장·녹지 분류, 변화 탐지
- 활용:
    - 보행자가 느끼는 연속적/단절된 공간감을 분석해, 물리적 네트워크와 다른 **경험적 강접/약접**을 계량화

## 3. 데이터 모델 – urbanis 아키텍처 위에 '강접/약접' 계층 올리기

urbanis 아키텍처는 이미 **법정동코드(행정동코드)·PNU·격자(H3 등)**를 JOIN 키로 통합하는 설계가 되어 있다. 이 위에 "강접/약접 해석용 레이어"를 추가한다.

### 3.1 기본 스키마 확장

1. **공간 단위 테이블**
    - `parcel(pnu, adm_code, geom, ... )` – 필지
    - `block(block_id, geom, primary_road_ids, adm_code, ... )` – 도로로 둘러싸인 블록
    - `grid(grid_id, level, geom, adm_code, ...)` – 100m/H3 격자
2. **그래프 테이블**
    - `road_node(node_id, geom)` / `road_edge(edge_id, u, v, length, type, ... )` – 네트워크 분석용
    - `urban_link(link_id, from_unit, to_unit, type(도로/시각/사회/환경), weight, metrics...)` – 강접/약접 지표 저장용 메타그래프
3. **지표 테이블**
    - `unit_metrics(unit_id, unit_type(parcel/block/grid), metrics_json)` – 용도혼합도, 인구밀도, 접근성, 환경지표 등
    - `edge_metrics(edge_id or link_id, metrics_json)` – 중심성, 통행량프록시, 시각적 연속성 등

### 3.2 JOIN 전략

- 대지(PNU) 선택 → `parcel` → `block`/`grid`/`adm_code`로 상향 연계
- 행정동/사용자 폴리곤 선택 → 포함되는 `parcel`/`block`/`grid`를 모두 가져와 네트워크 상의 강·약접 패턴을 집계
- 격자(H3/100m) 단위로 모든 지표를 올려두면 city-scale 히트맵과 그래프 분석을 동시에 수행 가능

## 4. 분석 프레임 – 강접/약접을 어떻게 수치화·조합할지

### 4.1 네트워크 중심성·접속성 기반

- 도로 그래프에서 betweenness, closeness, eigenvector 중심성을 구해 **"도시의 뼈대가 되는 강한 연결(간선축)"**을 추출
- 중심성이 낮고 단절된 도로·블록은 "약접 후보"로 표시, 하지만 인지·활동 층에서 중요할 수도 있으므로 나머지 레이어와 교차 검증

### 4.2 기능·활동 플로우 기반

- 통근/통학/유동인구/카드매출/POI 분포를 활용해 **블록/격자 간 상호 작용 강도(중력모형, OD 매트릭스)**를 추정
- 연결 강도가 높은 쌍을 **기능적 강접**, 상호작용이 거의 없는 인접 블록은 **기능적 약접**으로 분류

### 4.3 사회·경제·환경·경험 레이어 결합

- 사회적 이질성이 높으면서도 상호작용이 강한 연결은 "bridge형 약접(Granovetter weak tie)"로
    - 예: 저소득 주거지와 인접한 상업·문화지구를 연결하는 거리
- 환경·경험 레이어(GVI, 열섬, 소음 등)에서 체감 품질이 급변하는 경계는 **경험적 약접(심리적 단절)**로 태깅

### 4.4 강접/약접 통합 인덱스

- 각 축별로 0~1 정규화된 지표를 만들어 S_morph, S_func, S_soc, S_env
- 축별 가중치를 조정해 **종합 강접지수/약접지수**를 정의
- "강접–약접 스펙트럼"을 선형이 아니라, 유형(예: 물리적-기능적 불일치형, 사회적-환경적 취약형 등)으로 분류할 수 있게 다차원 클러스터링까지 고려

## 5. 시각화·프로그램 기획 – 어떻게 보여주면 '창의적 해석'이 되는가

### 5.1 지도 위 다층 레이어 + 그래프 오버레이

- 베이스: V-World 타일맵 위에 행정경계·지적도·도로망
- overlay 1: **강접 도로축** – 중심성/활동량 상위 % 도로를 강조
- overlay 2: **약접 경계/틈새** – 기능적·사회적·환경적 약접지수가 높은 경계를 하이라이트
- overlay 3: **연결 재편 제안** – 약접 지점에 "가상 보행로/공공공간" 제안선을 얹고, 연결 전·후 지표 변화를 애니메이션으로

### 5.2 강접/약접 망의 "패턴 라이브러리"

- 여러 도시/구역에서 계산된 강접/약접 패턴을 저장 (예: 그리드형 상업축, 방사형 교통축, 수계에 의해 절단된 주거지 등)
- 사용자가 대구의 특정 구역을 선택하면, **비슷한 패턴을 가진 다른 도시 사례**를 옆에 띄워주는 "도시 패턴 추천"

### 5.3 인터랙티브 실험도구

- 슬라이더로 각 축(형태/활동/사회/환경)의 가중치를 조정 → 강접/약접 맵이 어떻게 변하는지 실시간 확인
- 특정 약접 지점을 클릭하면,
    - "왜 여기서 약접이 발생하는지(도로 끊김, 사회적 단절, 시설 부족, 환경악화 등)"를 설명하는 카드
    - "어떤 개입(도로연결, 공원/시설 추가 등)이 강접화에 도움 될 수 있는지"를 정량적 before/after 그래프로 제시

## 6. 구현·준비 로드맵 (현실적인 단계)

1. **개념·지표 설계 단계**
    - "강접/약접"을 3~4개 축으로 정확히 정의하고, 각 축에 대응하는 지표 후보 리스트를 정리 (4.1~4.3)
    - 대구 1~2개 구(예: 중구, 수성구)를 파일럿으로 삼아, 손으로라도 지표를 계산해보며 개념 튜닝
2. **공간 데이터 레이크 구축**
    - urbanis 아키텍처에 따라 SGIS·V-World·공공데이터포털·Kakao 등을 연동해, PNU/adm_code/격자 기준으로 통합 파이프라인 구성
    - 초기엔 "형태+기본통계+시설+교통" 정도까지 우선 구축, 환경·CV 레이어는 2차
3. **그래프·지표 엔진 구현**
    - PostGIS + Python(GeoPandas/networkx) 또는 Spark/GraphFrames로 도로그래프·블록·격자 생성 + 중심성·접근성 지표 계산
    - unit_metrics/edge_metrics 스키마에 각종 지표를 저장하는 배치 잡 구축
4. **시각화·API 레이어**
    - 백엔드: FastAPI/Spring으로 "영역/대지/행정코드 입력 → 강접/약접 지표·맵 반환" API 설계
    - 프론트: MapLibre/Leaflet + deck.gl(또는 Kepler-like UI)로 레이어 토글·인터랙티브 비교·등시선·그래프 오버레이 구현
5. **패턴·추천 엔진(고급 단계)**
    - 강접/약접 맵을 patch 단위로 클러스터링해 "도시 패턴 코드북"을 만들고, 새 영역을 입력했을 때 유사 패턴을 찾아주는 검색/추천 기능
    - 장기적으로는 DRL-urban-planning 같은 프레임워크를 참고해, 강접/약접 지표를 보상으로 두는 레이아웃 제안 모듈도 얹을 수 있다

→ 이 계획을 뼈대로 잡아두면, 기존 urbanis 데이터 아키텍처를 그대로 활용하면서 **"도시의 강·약 결을 드러내고, 개입 아이디어를 제안하는 인터랙티브 연구툴"** 쪽으로 자연스럽게 확장할 수 있다.
