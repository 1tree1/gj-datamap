# 위대한 도시를 설계하는 사람들의 학습 로드맵

**역사적 거장부터 현대 최고 전문가까지 — 그들은 무엇을, 어떤 순서로, 왜 공부했는가**

---

## 서문: 도시 계획의 거장들은 "전공자"가 아니었다

도시 계획의 역사에서 가장 놀라운 사실은, 이 분야를 근본적으로 변혁한 인물들 대부분이 **정규 도시계획 교육을 받지 않았다**는 것이다.

Ebenezer Howard는 속기사였다. 15세에 학교를 중퇴하고 법원 속기사로 일하면서, 여가 시간에 사회개혁 서적을 독파했다. 정규 건축·계획·공학·조경 교육을 전혀 받지 않은 그가 쓴 *Garden Cities of To-morrow* (1898)는 20세기 전체 도시계획의 방향을 바꿨다.

Jane Jacobs는 고등학교 졸업 후 대학에 진학하지 않았다. Columbia 대학 야간 Extension에서 2년간 경제지리학 수업을 들은 것이 전부였다. 저널리스트로 일하면서 뉴욕 거리를 직접 관찰한 것이 그녀의 유일한 교육이었다. *The Death and Life of Great American Cities* (1961)는 도시계획 역사상 가장 영향력 있는 책이 되었다.

반면 Le Corbusier는 스위스 미술학교에서 장식미술을 공부하고 파리의 건축 사무소에서 실무를 익혔다. Jan Gehl은 코펜하겐 왕립미술아카데미에서 건축 석사를 받았지만, 아내(심리학자)와 이탈리아 광장에서 사람들의 행동을 관찰한 경험이 그의 이론의 핵심이 되었다. Ian McHarg는 글래스고에서 조경학을, 하버드에서 도시계획과 조경학 석사를 받았다.

이 사실이 말해주는 것은 명확하다: **도시를 설계하는 능력은 단일 전공이 아니라, 여러 분야의 지식과 관찰을 통합하는 능력에서 나온다.** 아래 로드맵은 이 통합의 순서와 구조를 제시한다.

## Part I. 거장들의 학습 DNA — 무엇이 그들을 만들었나

### 1. Ebenezer Howard (1850–1928) — 속기사에서 도시의 아버지로

| 학습 요소 | 내용 |
|---|---|
| 정규 교육 | 15세 중퇴, 독학 |
| 핵심 경험 | 21세에 미국 Nebraska 이주 → 시카고 거주 (1871 대화재 이후 재건 도시 목격) |
| 결정적 영향 | Edward Bellamy의 유토피아 소설 *Looking Backward* (1889), Henry George의 토지 단일세(Single Tax) 이론, Peter Kropotkin의 상호부조론 |
| 방법론 | 사회개혁 문헌 독파 + 영국·미국 도시 직접 관찰 + 투자자 설득력 |
| 핵심 역량 | **사회학적 상상력** + **경제적 실현 가능성 분석** + **비전의 시각화** |

**교훈**: Howard는 "도시란 무엇이어야 하는가"라는 근본 질문에서 출발했다. 기술적 디테일은 Barry Parker와 Raymond Unwin 같은 건축가에게 맡기되, **비전과 원칙의 설계**는 자신이 했다.

### 2. Le Corbusier (1887–1965) — 모더니즘의 선구자

| 학습 요소 | 내용 |
|---|---|
| 정규 교육 | La Chaux-de-Fonds 미술학교 (장식미술), 정규 건축학위 없음 |
| 핵심 경험 | 유럽·동방 여행 (그리스 파르테논, 이스탄불 모스크), Auguste Perret (철근콘크리트 건축)와 Peter Behrens (산업 디자인) 사무소 근무 |
| 결정적 영향 | 산업혁명의 기계 미학, 기하학, 아테네 헌장 (CIAM) |
| 방법론 | 스케치 여행 + 이론 저술 + 도발적 전시 + 실현 프로젝트 |
| 핵심 역량 | **기하학적 공간 구성** + **기술 혁신 (철근콘크리트)** + **매체를 통한 비전 전파** |

**교훈**: Le Corbusier는 건축·회화·도시계획·출판을 하나의 통합적 실천으로 수행했다. 하지만 그의 가장 큰 약점 — **실제 도시에서 사람들이 어떻게 살아가는지에 대한 관찰 부족** — 은 이후 Jane Jacobs와 Jan Gehl에 의해 정면 비판받는다.

### 3. Jane Jacobs (1916–2006) — 관찰의 혁명가

| 학습 요소 | 내용 |
|---|---|
| 정규 교육 | 고등학교 졸업, Columbia Extension 2년 (경제지리학) |
| 핵심 경험 | Scranton Tribune 기자 → 뉴욕 이주 → 프리랜스 저널리스트 → Architectural Forum 부편집장 (1952) |
| 결정적 영향 | Greenwich Village의 일상적 도시 생활, Robert Moses의 도시 파괴에 대한 분노, William H. Whyte의 관찰 방법론 |
| 방법론 | **직접 관찰** + 저널리스트적 질문법 + 경험적 근거 기반 비판 + 커뮤니티 액티비즘 |
| 핵심 역량 | **관찰 → 패턴 인식 → 원리 도출** + **글쓰기** + **시민 조직화** |

**교훈**: Jacobs는 "전문가가 보지 못하는 것을 비전문가가 볼 수 있다"는 것을 증명했다. 그녀의 4가지 다양성 조건 (복합용도, 짧은 블록, 다양한 건물 연령, 높은 밀도)은 모두 **현장 관찰에서 귀납적으로 도출**되었다.

### 4. Ian McHarg (1920–2001) — 생태학적 계획의 창시자

| 학습 요소 | 내용 |
|---|---|
| 정규 교육 | Glasgow 미술학교 (조경학) → Harvard GSD (도시계획 석사 + 조경학 석사) |
| 핵심 경험 | 2차 세계대전 참전 (이탈리아 전선), 스코틀랜드 빈민가 성장 환경 |
| 결정적 영향 | Lewis Mumford의 지역주의, 생태학 (Charles Elton, Eugene Odum), 지질학, 수문학 |
| 방법론 | **GIS의 원형인 레이어 오버레이** (투명 지도 중첩) + 학제간 팀 구성 |
| 핵심 역량 | **자연과학과 설계의 통합** + **체계적 분석 방법론** |

**교훈**: McHarg는 Penn 대학에서 30년간 가르치면서, 조경학과에 생태학자, 지질학자, 수문학자, 기후학자를 교수진으로 초빙했다. 그의 핵심 메시지: **"자연과 함께 설계하라, 자연에 맞서 설계하지 마라."**

### 5. Jan Gehl (1936– ) — 사람을 위한 도시의 설계자

| 학습 요소 | 내용 |
|---|---|
| 정규 교육 | 코펜하겐 왕립미술아카데미 건축학 학·석사 (1960) |
| 핵심 경험 | 졸업 후 6년 건축 실무 → 1966년 "공공공간의 형태와 이용" 연구 그랜트 (5년) → 40년간 교수 + 연구 |
| 결정적 영향 | **아내 Ingrid (심리학자)**와의 이탈리아 광장 행태 연구, Jane Jacobs, 행동심리학 |
| 방법론 | **체계적 공공생활 조사** (카운팅, 매핑, 트레이싱, 트래킹, 사진 기록) → 점진적 개선 → 재조사 |
| 핵심 역량 | **관찰의 과학화** + **건축-심리학 융합** + **증거 기반 설계** |

**교훈**: Gehl의 혁신은 "사람을 먼저 연구하고, 그 다음 공간을 설계하라"는 순서의 전환이다. 그의 연구가 건축학에서 시작되었지만 심리학, 사회학, 보건학과 융합되면서 폭발적 영향력을 가지게 된 것은 **학제간 결합**의 위력을 보여준다.

### Stage 0. 기반 교양 — "도시 이전에 인간을 이해하라"

거장들의 공통점은 도시를 기술적 대상이 아니라 **인간 문명의 표현**으로 봤다는 것이다. Howard는 사회개혁 문학을, Jacobs는 경제학과 생태학을, McHarg는 자연과학을, Gehl은 심리학을 통해 도시에 접근했다.

#### 0-1. 인문학적 기초 (The Humanist Lens)

**왜**: 도시는 결국 사람이 사는 곳이다. 사회가 어떻게 조직되고, 권력이 어떻게 공간을 형성하며, 문화가 어떻게 장소를 만드는지 이해하지 못하면 "작동하는" 도시를 설계할 수 없다.

**필수 읽기**:

| 분류 | 도서/저자 | 핵심 내용 |
|---|---|---|
| 도시 철학 | Lewis Mumford, *The City in History* (1961) | 도시 문명 5,000년사, 도시의 기원부터 현대 메갈로폴리스까지 |
| 관찰의 기술 | Jane Jacobs, *The Death and Life of Great American Cities* (1961) | 도시가 실제로 작동하는 방식, 4가지 다양성 조건 |
| 사회-공간 관계 | Henri Lefebvre, *The Production of Space* (1974) | 공간은 사회적으로 생산된다는 마르크스주의 공간론 |
| 장소의 의미 | Yi-Fu Tuan, *Space and Place* (1977) | 공간(space)이 장소(place)가 되는 경험적 과정 |
| 경제와 도시 | Edward Glaeser, *Triumph of the City* (2011) | 도시 경제학, 집적 경제, 왜 도시가 부유하고 혁신적인가 |
| 불평등과 도시 | Mike Davis, *Planet of Slums* (2006) | 글로벌 도시화의 어두운 면, 비공식 정주 |

**보충 활동**: 자신이 사는 도시의 한 블록을 선택해 Jane Jacobs처럼 일주일간 시간대별 관찰 일지를 작성한다.

#### 0-2. 자연과학적 기초 (The Ecological Lens)

**왜**: McHarg가 증명했듯이, 자연 시스템을 무시한 도시는 재난을 초래한다.

**필수 읽기**:

| 분류 | 도서/저자 | 핵심 내용 |
|---|---|---|
| 생태학적 설계 | Ian McHarg, *Design with Nature* (1969) | GIS의 원형, 자연 적합성 분석 |
| 기후와 도시 | Victor Olgyay, *Design with Climate* (1963) | 기후 반응형 건축·도시의 원리 |
| 복원력 | C.S. Holling, "Resilience and Stability of Ecological Systems" (1973) | 회복탄력성(resilience) 개념의 기원 |
| 물의 도시 | Herbert Dreiseitl, *Waterscapes* (2001) | 도시 수경관, 지속가능한 우수 관리 |

**보충 지식**: 기초 지질학 (토양·암석·지하수), 기초 수문학 (유역·하천·홍수), 기초 생태학 (천이·서식지·생물다양성), 기초 기후학 (기온·강수·바람 패턴)

#### 0-3. 시각적 사고 기초 (The Visual Thinking Lens)

**왜**: 도시 설계자는 아이디어를 시각적으로 표현하고 소통해야 한다.

**필수 역량**:

| 역량 | 내용 | 학습 방법 |
|---|---|---|
| 손 스케치 | 빠른 개념 스케치, 다이어그램, 단면도 | 매일 스케치 습관 (Urban Sketchers 방식) |
| 지도 읽기/제작 | 지형도, 토지이용도, 주제도 해독 능력 | GIS 입문 (QGIS 튜토리얼) |
| 공간 감각 | 스케일 감각, 비례감, 거리-시간 관계 | 도시 산책 + 거리 측정 습관화 |

### Stage 1. 핵심 전공 심화 — "하나의 우물을 깊게 파라"

모든 거장은 **최소 하나의 전문 분야를 깊이 있게 마스터**한 뒤 확장했다. 아래 5개 트랙 중 자신의 핵심 전공을 선택하고, 나머지는 Stage 2에서 연결한다.

### Stage 2. 도시계획 프레임워크 — "이론의 지도를 그려라"

개별 전공을 도시 계획이라는 통합 프레임워크로 연결하는 단계.

#### 2-1. 계획 이론의 계보 (Planning Theory Lineage)

도시계획 이론은 다음과 같은 진화를 거쳤다. 각 단계를 순서대로 학습한다.

```
[1898] Howard: Garden City              — 유토피아적 물리계획
  ↓
[1920s] Perry: Neighborhood Unit         — 근린 단위의 과학
  ↓
[1930s] Le Corbusier: Ville Radieuse     — 모더니즘 기능주의
  ↓
[1961] Jacobs: Death and Life            — 모더니즘 비판, 복잡성 이론
  ↓
[1965] Davidoff: Advocacy Planning       — 사회정의, 참여계획
  ↓
[1969] McHarg: Design with Nature        — 생태적 계획
  ↓
[1973] Arnstein: Ladder of Participation — 시민 참여의 8단계
  ↓
[1977] Alexander: Pattern Language       — 설계 패턴의 체계
  ↓
[1993] Calthorpe: TOD / Duany: New Urbanism — 보행 친화 도시
  ↓
[2010s] Gehl: Cities for People          — 인간 중심 도시
  ↓
[2016] Moreno: 15-Minute City            — 근접성의 도시
  ↓
[2020s] Digital Twin + AI + Climate Adaptation — 데이터 기반 적응 도시
```

#### 2-2. 단계별 필수 학습 텍스트

| 시대 | 핵심 텍스트 | 핵심 개념 |
|---|---|---|
| 이론적 기원 | Patrick Geddes, *Cities in Evolution* (1915) | 조사(Survey) → 분석 → 계획의 3단계 |
| 모더니즘 | Le Corbusier, *The Athens Charter* (1943) | 기능적 도시: 주거-노동-여가-교통 |
| 모더니즘 비판 | Jacobs, *Death and Life* (1961) | 복합용도, 짧은 블록, 밀도, 건물 다양성 |
| 참여 계획 | Sherry Arnstein, "A Ladder of Citizen Participation" (1969) | 참여의 8단계 (조작→정보제공→파트너십→시민통제) |
| 생태 계획 | McHarg, *Design with Nature* (1969) | 레이어 오버레이 적합성 분석 |
| 패턴 언어 | Christopher Alexander, *A Pattern Language* (1977) | 253개 설계 패턴의 계층 체계 |
| 뉴어바니즘 | Andrés Duany et al., *Suburban Nation* (2000) | 스프롤 비판, 트랜섹트, 폼기반코드 |
| 인간 중심 | Jan Gehl, *Cities for People* (2010) | 5km/h의 건축, 12가지 공공공간 품질 기준 |
| 15분 도시 | Carlos Moreno et al., "Introducing the 15-Minute City" (2021) | 6대 기능의 근접 접근성 |
| 스마트시티 | Anthony Townsend, *Smart Cities* (2013) | 기술과 시민의 관계 |
| 회복탄력성 | 100 Resilient Cities, *City Resilience Framework* | 7가지 회복력 특성 |

#### 2-3. 법·제도 프레임워크

| 분류 | 학습 내용 |
|---|---|
| 한국 법체계 | 국토계획법, 택지개발촉진법, 도시개발법, 건축법, 스마트도시법 |

### Stage 4. 통합 실천과 리더십 — "실제 도시에서 검증하라"

#### 4-1. 통합 프로젝트 경험

이론과 도구를 실제 도시 문제에 적용하는 단계. Gehl이 코펜하겐을 40년간 실험실로 사용한 것처럼, **하나의 도시/지역을 깊이 알고 반복적으로 개입하는 경험**이 핵심이다.

| 경험 유형 | 학습 내용 |
|---|---|
| 마스터플랜 참여 | 비전 → 부지분석 → 대안 설계 → 평가 → 선호안 도출의 전 과정 |
| 공공공간 개선 프로젝트 | Gehl 방법론 적용 — Before/After 공공생활 조사 |
| 커뮤니티 샤렛 (Charrette) | 주민 참여 설계 워크숍 기획·진행 |
| 정책 제안서 작성 | 데이터 분석 → 정책 대안 → 영향 평가 |
| 국제 사례 연구 여행 | 계획 도시 직접 방문·관찰 (세종, 송도, 코펜하겐, 바르셀로나, 싱가포르) |

#### 4-2. 거장들에게서 배우는 리더십 원칙

| 원칙 | 근거 |
|---|---|
| **관찰이 이론에 선행한다** | Jacobs는 이론 없이 관찰에서 출발했고, Gehl은 관찰을 과학으로 만들었다 |
| **비전은 구체적이어야 한다** | Howard의 6,000에이커 계획, Perry의 5,000~9,000인 근린단위처럼 숫자가 있는 비전 |
| **하나의 혁신적 다이어그램이 천 페이지 보고서를 이긴다** | Howard의 3자석, Perry의 근린단위도, Duany의 Transect |
| **점진적 개선을 측정하라** | Gehl의 방법: 조사 → 소규모 개선 → 재조사 → 확대 |
| **여러 분야의 전문가와 협업하라** | McHarg의 학제간 팀, Le Corbusier의 CIAM |
| **실패에서 배워라** | 1기 신도시의 침상도시 문제 → 2기의 자족성 강화 → 3기의 교통 우선 |

## 결론: 거장들의 공통 공식

이 로드맵의 전체 구조는 거장들의 학습에서 반복적으로 나타나는 하나의 공식으로 요약된다:

**깊은 관찰 + 하나의 전문성 + 학제간 융합 + 실현 의지 = 위대한 도시 계획**

Howard는 속기사의 관찰력으로 산업도시의 비극을 보았고, 사회개혁론을 흡수해 전원도시를 구상했으며, 사업가를 설득해 실현했다. Jacobs는 저널리스트의 관찰력으로 거리의 발레를 발견했고, 경제학과 생태학을 빌려 도시 복잡성 이론을 세웠으며, 주민을 조직해 고속도로를 막았다. Gehl은 건축가의 눈으로 광장을 보았고, 심리학자인 아내와 함께 행태를 과학으로 전환했으며, 코펜하겐을 40년에 걸쳐 보행자의 도시로 바꿨다.

어떤 전공에서 시작하든, 핵심은 같다: **도시에 나가서 관찰하고, 이론을 세우고, 도구로 검증하고, 사람들과 함께 실현하라.**
