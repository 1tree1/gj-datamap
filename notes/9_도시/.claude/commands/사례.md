쟁점: $ARGUMENTS

1. `docs/20_cases/구경주역_사례_데이터베이스.md`에서 이 쟁점과 **구조적으로 동형(●●●)** 인 사례를 우선 고른다. 유사도 ●는 참고로만.
2. 심층 자료가 있으면 함께 읽는다 — `구경주역_참조사례_안동_우메코지.md`, `구경주역_도심공동화_사례_부산_전주_울산.md`, `사례심층_광주_푸른길공원.md`.
3. **실패 사례를 최소 1개 포함**한다. 심의에서는 성공 사례보다 강하다 — 검토했음을 증명하기 때문.
4. 각 사례를 고정 코딩 항목으로 정리한다:

```
사례명 / 위치 / 결과(성공·부분·실패·진행) / 유사도 / 검증([S] 출처확인 · [K] 일반지식)
부지면적 · 폐선연장 · 소유주체 · 사업방식 · 총사업비와 재원구조
도입용도 믹스 · 주거 비율 · 보존 철도유산 · 규제 특례
단계 수와 각 단계 내용 · 민간 진입 시점 · 착수~준공
완공 후: 지가 / 방문객 / 거주인구 변화
실패·지연 요인
```

5. **구경주역 이식 가능성**을 마지막에 쓴다 — 무엇을 가져오고 무엇을 가져오면 안 되는지. 차이(면적, 매장문화재, 고도제한, 관광 규모, 자릿수)를 반드시 명시한다.
6. `[K]` 사례는 인용 전 원문 확인이 필요하다고 표시한다.
