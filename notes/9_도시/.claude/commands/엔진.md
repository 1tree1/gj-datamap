요청: $ARGUMENTS

1. `docs/40_engine/구경주역_최적화엔진_Part5.md`를 읽는다. **설계는 이미 확정되어 있다** — 재설계하지 말고 구현 순서를 따른다.
2. `gjplan/` 현재 상태를 확인하고 12주 구현 순서 중 어디까지 왔는지 판단한다.

| 주차 | 목표 | 완료 판정 |
|---|---|---|
| 1–2 | `io/` + `constraints/compile.py` | 경계 면적이 손계산과 일치 |
| 3–4 | `generate/network.py` + `blocks.py` (S1+S2) | 무작위 100개 중 유효 90%↑ |
| 5–6 | `evaluate/cheap.py` + `mid.py`, NSGA 첫 구동 (3목적) | 2026.1 공고안이 목적공간 전선 위에 찍힘 |
| 7–8 | 정직평가 500회 + `surrogate.py` | R² ≥ 0.85 |
| 9 | `plots.py` + `program.py` (S3+S4), 5목적 | 생성 획지 분포가 인근 실제 분포 ±10% |
| 10 | `optimize/phasing.py` (MILP) | 제약 위반 0 |
| 11 | `export/` 3종 (dxf, xlsx, 3dm) | 면적표 합계 = 구역 총면적 |
| 12 | 대안 A–E + 검증 그림 | — |

3. 구현할 때 지킬 것:
   - **제약은 페널티가 아니라 불가능이다.** `buildable` 마스크로 잘라낸다
   - **차원을 낮게 유지한다.** 50차원을 넘으면 NSGA-III가 수렴하지 않는다. S1 유전자 8–14차원, S3 4차원, S4 획지수×2
   - **대리모델 없이 정직 평가로 루프를 돌지 않는다.** 등시선 10–60s, 조망 5–30s
   - **가중치를 넣지 않는다.** 파레토 전선 전체를 내고 대안 A(보존)–B(사업성)–C(접근성)–D(조직정합)–E(균형)로 제시
   - **대리모델 오차를 반드시 보고한다** (R², MAE, 최종 5개 대안의 대리값 vs 실측값 비교표)
   - Ladybug 일조·열환경은 **루프에서 제외**하고 최종 5개만 검증

4. `compile` 단계는 **경계 면적을 즉시 출력**한다. 좌표계 오류는 여기서 잡는다.
