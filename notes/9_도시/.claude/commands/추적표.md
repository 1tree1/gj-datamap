description: 계획 결정 하나를 추적표 한 행으로
---

결정 사항: $ARGUMENTS

지구단위계획의 모든 결정은 "왜 이렇게 정했는가"에 답할 수 있어야 한다. 아래 형식으로 한 행을 만든다.

```
decision_id:
항목:            # 무엇을 정했나 (예: 종축 보행로 폭 30m)
값:
근거 데이터:      # 어느 자료의 어느 수치인가 (index.csv id + page_refs)
근거 등급:        # T1–T4
방법:            # 어떻게 도출했나 (규칙 / 최적화 / 사례 이식 / 심의 의견)
목적함수 영향:     # f₁ 접근성 · f₂ 유산영향 · f₃ 사업성 · f₄ 조직정합 · f₅ 공공성·환경
alternatives:    # 검토했으나 채택하지 않은 대안 + 기각 이유 (실패 사례를 명시)
사람의 조정:      # 파레토 해에서 손으로 바꾼 부분과 그 이유
상위계획 정합:     # 2030 도시기본계획 / 경북 종합계획 / 국가철도망계획 중 어디에 걸리나
```

원칙:

- **생성 결과를 그대로 제출하지 않는다.** 최종안은 파레토 해 하나를 사람이 다듬은 것이고, 조정 내역도 이 표에 남는다.
- "AI가 그렸다"는 근거가 될 수 없다. 모든 결정은 파라미터로 추적 가능해야 한다.
- `alternatives`에는 **왜 단일 대형 복합거점이 아닌가** 같은 질문의 답이 들어간다 (→ 울산 우정혁신도시).
