## 이미 확정된 판단 — 다시 뒤집지 말 것

- 국내 폐선부지 21개 중 면적 개발은 안동·진영·진주뿐. 8ha 가구·획지 문제의 국내 선례는 **사실상 구 안동역 하나**
- 1단계 문법 = 연결 + 기반 + 보행 (구 안동역). 단, 경주는 매장문화재 때문에 지하주차를 1단계에 넣을 수 없다
- 비가역 투자는 뒤로 (교토 우메코지 29년). 민간자본은 공원 개원 13년 후에 들어왔다. 빌릴 것은 기간이 아니라 **순서**
- 단일 대형 = 울산형. 분산 삽입 = 부산형
- 방문객 수를 성공 지표로 삼으면 전주의 10년 뒤. 성과지표는 두 축으로 나란히
- 성공 지표는 "건물이 방향을 바꾸는가" (광주 푸른길)
- 선형 축은 한 점만 끊겨도 전부 무력화 → 최소값 지배 지표

## 반드시 지킬 것

1. **실패 사례를 최소 1개 포함한다.** 울산 우정혁신도시 / 트렌토 Le Albere / 발렌시아 예술과학도시 / 광주 양동·월산동 근린재생. 심의에서는 실패 사례가 성공 사례보다 강하다.
2. **자릿수 차이를 명시한다.** 교토 관광객 규모는 경주와 자릿수가 다르다 — 수족관급 사업성을 가정하지 않는다.
3. `[K]` 표시 사례는 **인용 전 원문 확인 필요**로 표기한다.
4. 유사도 ●●●(구조적 동형)를 우선한다. ●는 참고로만.
