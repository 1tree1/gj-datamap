핵심 개념: 행정코드가 만능 열쇠(Universal Key)

한국의 모든 공공 데이터는 법정동코드(10자리) 또는 PNU코드(19자리)로 연결됩니다. 사용자가 "대구 중구 삼덕동"을 입력하면 → 법정동코드 2711010200이 자동 매핑되고, 이 코드 하나로 건물대장, 용도지역, 인구통계, 공시지가 등 모든 데이터가 자동으로 결합됩니다. 즉, 행정코드 = 데이터 통합의 JOIN 키입니다.

import requests # 방법1: Kakao Local API (주소 → 좌표 → 행정코드) def get_admin_code(address): url = "https://dapi.kakao.com/v2/local/search/address.json" res = requests.get(url, params={"query": address}, headers={"Authorization": "KakaoAK {YOUR_KEY}"}) doc = res.json()["documents"][0]["address"] return { "법정동코드": doc["b_code"], # "2711010200" "행정동코드": doc["h_code"], # "2711051000" "lat": doc["y"], "lng": doc["x"] } # 방법2: SGIS API (행정코드 → 경계 GeoJSON) def get_boundary_geojson(admin_code): url = "https://sgisapi.kostat.go.kr/OpenAPI3/boundary/hadmarea.geojson" res = requests.get(url, params={ "accessToken": get_sgis_token(), "year": "2024", "adm_cd": admin_code[:5], # 시군구 단위 "low_search": "2" # 읍면동 하위 포함 }) return res.json() # GeoJSON FeatureCollection # 방법3: V-World API (PNU → 토지정보) def get_land_info(pnu): url = "http://api.vworld.kr/ned/data/getLandCharacteristics" res = requests.get(url, params={ "key": "{VWORLD_KEY}", "pnu": pnu, "format": "json", "numOfRows": "10" }) return res.json() # 지목, 면적, 용도지역 등

1 수집: 행정코드로 배치 API 호출
사용자가 영역을 지정하면, 해당 영역 내 모든 법정동코드 목록을 추출하고, 각 코드로 병렬 API 호출을 수행합니다. V-World 토지API는 PNU 기반이므로, 먼저 지적도에서 영역 내 필지 PNU 목록을 추출 후 배치 요청합니다. 위성영상은 bbox(bounding box) 기준으로 STAC API를 통해 Cloud-Optimized GeoTIFF를 부분 로드합니다.
aiohttp (비동기 배치) pystac-client geopandas.sjoin rasterio (COG)
2 통합: 행정코드/PNU를 JOIN 키로 병합
모든 테이블/속성 데이터는 법정동코드 또는 PNU로 JOIN합니다. 공간 데이터(SHP/GeoJSON)는 GeoPandas sjoin(공간 조인)으로 병합합니다. 격자 데이터(인구밀도 100m, 유동인구 50m)는 H3 헥사곤 인덱스로 통일하여 해상도 차이를 해결합니다.
pandas.merge(on='pnu') geopandas.sjoin h3-py (헥사곤 인덱싱)
핵심 JOIN 로직 (Python 의사코드)
# 1. 영역 내 법정동코드 추출
area_codes = get_dong_codes_in_boundary(user_geojson)
  # → ["2711010200", "2711010300", ...]

# 2. 각 코드로 속성 데이터 수집
buildings   = fetch_building_ledger(area_codes)    # 건축물대장 API
land_info   = fetch_land_characteristics(pnu_list) # 토지특성 API
land_price  = fetch_official_price(pnu_list)       # 공시지가 API
population  = fetch_population(area_codes)         # KOSIS API
amenities   = fetch_poi_kakao(center_coord, radius) # Kakao POI

# 3. PNU 기준 병합 → 필지 단위 통합 테이블
parcel_df = (cadastral_gdf                         # 지적도 (geometry)
  .merge(buildings, on='pnu')                      # + 건물 정보
  .merge(land_info, on='pnu')                      # + 토지 특성
  .merge(land_price, on='pnu')                     # + 공시지가
)

# 4. 행정동 단위 통합 → 동 단위 집계 테이블
dong_df = (admin_boundary_gdf                      # 행정경계 (geometry)
  .merge(population, on='admin_code')              # + 인구통계
  .merge(parcel_df.groupby('dong_code').agg(...))  # + 건물/토지 집계
)

# 5. 공간 조인 → 용도지역 오버레이
parcel_with_zoning = gpd.sjoin(parcel_df, zoning_gdf, how='left')

# 6. 격자 데이터 → H3 인덱싱
parcel_df['h3_idx'] = parcel_df.apply(
  lambda r: h3.latlng_to_cell(r.geometry.centroid.y, r.geometry.centroid.x, 9), axis=1)
merged = parcel_df.merge(population_grid, on='h3_idx')
3 가공: 분석 지표 산출
통합된 데이터에서 도시 분석에 필요한 파생 지표를 계산합니다:
• 건물 노후도: (현재연도 − 사용승인일) → 30년 이상 = 노후 건축물
• 용적률 잔여분: (법적 최대 용적률 − 현재 용적률) → 개발 잠재력
• 녹지접근성: 각 필지에서 가장 가까운 공원까지 도보 거리 (Valhalla 등시선)
• 15분도시 점수: 6대 기능 접근성 종합 (가중 평균)
• NDVI 변화율: 연도별 Sentinel-2 NDVI 차이 → 녹지 손실/증가
• 열섬 취약도: NDVI × 불투수면비율 × 건물밀도 복합 지수
numpy/pandas Valhalla (등시선) rasterio (NDVI) scikit-learn OSMnx (네트워크)
