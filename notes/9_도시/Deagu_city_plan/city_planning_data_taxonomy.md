# 도시 형성을 위한 데이터 분류 체계 (City Planning Data Taxonomy)

도시를 계획할 때 조사·수집·분석해야 하는 데이터를 **10개 대분류 → 하위 영역 → 구체적 데이터 항목** 순으로 정리한 레퍼런스이다. 각 대분류는 도시 계획 라이프사이클의 어느 단계에서 주로 사용되는지, 어떤 분석 도구·기법과 연결되는지를 함께 표기한다.

---

## 1. 자연환경 데이터 (Natural Environment)

도시의 물리적 골격을 결정하는 가장 기초적인 데이터 레이어. Ian McHarg의 "Design with Nature" 방법론에서 모든 계획의 출발점으로 정의된다.

### 1-1. 지형·지질 (Topography & Geology)

| 데이터 항목 | 설명 | 해상도·단위 | 주요 소스 |
|---|---|---|---|
| DEM (Digital Elevation Model) | 지표면 고도 래스터 | 1–5 m 해상도 | LiDAR, 항공측량, SRTM |
| 경사도·경사향 (Slope & Aspect) | DEM에서 파생, 개발 적합도 판단 | 도(°) 단위 | GIS 파생 |
| 지질 구조도 | 암반 종류, 단층선, 지질 시대 | 1:5,000~1:50,000 | 국가 지질조사 기관 |
| 토양도 | 토성, 배수 등급, 투수계수, 지력 | 1:5,000 | 국가 토양 조사 |
| 지반 지지력 (Bearing Capacity) | 구조물 하중 지지 능력 | kN/m², 시추공별 | 지반조사 보고서 |
| 지진 위험도 | 활성 단층, 지진 가속도 지도 | PGA (g) | 지진연구원, USGS |
| 지하수위 | 계절별 지하수면 깊이 | m, 관측정별 | 수문관측소 |

**분석 기법**: GIS 경사 분석, 지질 오버레이, 지반공학 시뮬레이션
**핵심 기준**: 경사 5% 이하 = 최적 개발지, 5–15% = 조건부 개발, 15% 초과 = 보전·녹지

### 1-2. 기후·기상 (Climate & Meteorology)

| 데이터 항목 | 설명 | 수집 주기 | 주요 소스 |
|---|---|---|---|
| 기온 데이터 | 월별·일별 최고/최저/평균 기온, 열대야 일수 | 시간별~일별 | 기상청 AWS |
| 강수량 | 월별 강수량, 강우강도-지속기간-빈도(IDF) 곡선 | 10분~일별 | 기상청, 수문자료 |
| 풍향·풍속 | Wind Rose 다이어그램, 계절별 주풍향 | 시간별 | 기상관측소 |
| 일조·일사량 | 수평면 전일사량, 일조시간, 태양 경로도 | 시간별 | 기상청, NASA POWER |
| 상대습도 | 월별 평균, 결로 위험 평가용 | 시간별 | 기상청 |
| 적설량 | 최대 적설 깊이, 제설 기준 | 일별 | 기상청 |
| 미기후 시뮬레이션 | 도시 열섬, 바람 통로, 그늘 영역 | 시나리오별 | CFD 시뮬레이션 |
| 기후변화 시나리오 | RCP/SSP별 미래 기온·강수·해수면 예측 | 10년 단위 | IPCC, 기상청 |

**분석 기법**: Wind Rose 분석, 태양 경로 시뮬레이션 (Ladybug/Grasshopper), CFD (전산유체역학), IDF 곡선 분석
**핵심 기준**: 겨울 주풍향은 건물 방풍 계획, 여름 탁월풍은 자연환기 통로 설계에 반영

### 1-3. 수문·수계 (Hydrology & Water Resources)

| 데이터 항목 | 설명 | 주요 소스 |
|---|---|---|
| 유역 경계 | 집수 구역, 수계 네트워크 | DEM 파생, 수자원공사 |
| 하천 유량 | 평수량, 갈수량, 홍수량 (재현기간별) | 수문관측소 |
| 홍수 위험 지도 | 50·100·200년 빈도 침수 예상 구역 | 국토부, FEMA |
| 수원 가용량 | 취수 가능한 지표수·지하수 총량 | 수자원장기종합계획 |
| 수질 데이터 | BOD, COD, SS, pH, 중금속 | 환경부 수질측정망 |
| 해수면 상승 시나리오 | RCP별 미래 해안 침수 예측 | IPCC, 해양조사원 |

### 1-4. 생태·환경 (Ecology & Environment)

| 데이터 항목 | 설명 | 주요 소스 |
|---|---|---|
| 식생도 | 식물 군락 분포, 수관 피복율 | 위성영상 NDVI, 현장조사 |
| 동·식물상 목록 | 출현 종, 개체수, 서식지 유형 | 생태조사, 환경영향평가 |
| 보호종·핵심 서식지 | 멸종위기종, 천연기념물 서식 범위 | 환경부 |
| 생태 축 (Ecological Corridor) | 녹지 연결성, 생태 네트워크 | GIS 연결성 분석 |
| 대기질 | PM2.5, PM10, NO₂, O₃ 농도 | 에어코리아 |
| 소음 지도 | 교통·산업 소음 등고선 | 소음측정, 시뮬레이션 |
| 토양 오염 | 중금속, 유류, 과거 산업 이력 | 토양환경조사 |

**분석 기법**: GIS 기반 생태적합성 분석, NDVI 시계열 분석, 생태 네트워크 그래프 분석
