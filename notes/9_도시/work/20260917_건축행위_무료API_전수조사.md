# 건축행위(지구단위계획·인허가·설계 검토)에 쓸 수 있는 무료 API — 전수 조사 (2026-09-17)

전제: 이미 있는 키 = V-World · 공공데이터포털(DATA_GO_KR_KEY) · ITS(DATA_GO_KR_KEY_CAR) · KOSIS · 국가법령정보.
표기: **[신규키]** = 별도 가입·키 필요 / **[기존키]** = 공공데이터포털 키로 서비스별 '활용신청'만 하면 됨 / **[무키]** = 키 없이 호출 / **[신청]** = 무료지만 심사·계약 필요 / **[검증]** = 이 세션에서 실제 호출 또는 페이지로 확인.
"건축행위"를 인허가 단계 순서로 묶었다: ① 대지·권리 → ② 규제·계획 → ③ 문화유산 → ④ 지반·재해·환경 → ⑤ 기반시설 → ⑥ 시장·수요 → ⑦ 교통·접근 → ⑧ 절차·행정·법령.

## 검증 수준 정직 고지
- 이 세션에서 **실제 호출로 확인**: V-World UO101/UO301/UO601/UP201/UM000/UQ121~128/UQ141, 토지이음 목록·첨부.
- **페이지 확인**: gis-heritage WMS/WFS 서비스 목록·URL 형식(응답은 미확인 — 브라우저 차단).
- **검색 확인**: 건축HUB 인허가 API 존재, 지반정보 시추공 파일→API, 기상청 API허브 무료.
- 나머지(SGIS·localdata·juso·Kakao·한전·ODsay·Tmap·R-ONE·통계누리·EGIS 등)는 **내 지식 기준**이며 쿼터·가입 조건은 변동 가능 — 신청 전 각 포털에서 재확인 필요.
