# 프로그램 면적표 v2 — 설계 메모 (컨텍스트 보존용, 2026-10-11)

## 요청
사용자가 `user_program_list_v1.md`의 프로그램 리스트를 주고, 컨셉(NEXUS 1918 / CULTURAL INTERCHANGE, CONNECT·EXCHANGE·SPREAD)을 더 고려해 디테일·수정·구성하고, 대상 인구·이용자를 가정해 **전체 면적표**를 만들라고 했다. 공공청사·의회를 사용자가 직접 포함시켰다(앞서 비교안 B였던 것이 포함으로 바뀜).

## 정리한 구조 (제안)
- 권역(사용자 6군 → 8군): A 공공청사·의회 / B 일상생활(정주) / C 청년 업무권(GROWTH HUB) / D 창작·체험권(EXCHANGE) / E 역사문화예술권(CULTURAL GATEWAY) / F 방문자 관문·모빌리티(CONNECT) / G 야외·공공공간 / H 주차·운영.
- 중복 정리: 아티스트 레지던시(D와 E-4 중복) 1개로. 철도 전시 3곳(구 역사·철도기억관 / 근대역사 전시관 / 철도와 원도심 체험전시실)은 역할 분담(실물 / 도시사·기획 / 체험). 교육실 6종(직무교육실·단체 교육실·시민 강좌실·학교 연계 역사교육실·보존복원 교육실·공동회의실)은 공유 교육실 풀로. 공방 3종(공동 제작공방·공개 공방·지역 공예 제작실·전통공예 체험실)은 공예 공방 클러스터로. 안내센터·출발 안내소·라운지·연결 안내는 방문자 관문 1동.
- 추가 제안(선택, 별도 소계): 체류 연장 장치(식음·야간 프로그램·소규모 숙박·작가 체류실 확장), 모빌리티 허브(환승·셔틀 승강장·공유 모빌리티; 시 구상 3대 전략), 마을기업·협동조합 사무실.
- 서사 수정: "1918년 개통부터 폐역까지" → 1918 개업(사정동, 관보 1924호 운수개시 인가 12-28) → 1936 현 위치 이전 → 2021 폐역. 구 역사는 등록문화유산 아님(코레일 철도기념물 2013), 이전 vs 현위치 보존은 미정(면적 2,807㎡ = 1,404×2F 실측).
- 공공청사·의회: 시 구상은 2단계(민자유치, 시청 이전 포함), 국비 대상 제외, 법정 상한 21,110㎡(본청 17,759+의회 3,351)+가산. 포함 시 1·2단계 구분 표기. 저녁 공동화 위험은 일상생활·공연장·주거·야간 프로그램으로 완화.

## 인구·이용자 가정 (모델 입력)
- 방문: 외지인 일평균 140,085 × 포획률 α(보수 5.9% / 기준 7.9% / 적극 10.6%) = 11,067명/일(기준), 설계일 ×1.48, 피크 1시간 7.0%.
- 근로: 청년 일자리 906(연 순유출 1,208의 75%), 공공청사 정원 본청 902+의회 40(조례) 또는 850(통계연보 2023), 시설 운영 인력은 면적 ÷ 원단위로 산출.
- 정주: 청년·신혼 600세대(450~750), 798명.
- 인근 주민(S2, 2026-08 KOSIS): 황오+황남+성건+월성 4동 30,261명, 0~4세 219, 5~9세 314, 10~14세 603, 20~39세 5,235, 65세 이상 12,374(40.9%). 동천동 19,727명(0~4세 214). 경주시 242,512명(0~4세 4,810).
- 학교·단체: 가정(연 학생 방문 수·동시 수용 학급).

## 모델 구조 (part2_model_v2.py로 작성 예정)
- 실(室) 단위 행: 권역 / 프로그램 / 실 / 산정 근거(용량 × 원단위 × 가산) / 용량 / 원단위(최소·기준·최대) / 면적(보수·기준·적극) / 층 / 비고.
- 원단위 출처: R2·R3 계산 입력표(✔ 법정·사례), R5(실별 원단위, 진행 중), 미확인은 '설계 가정'으로 표기.
- 합산 후 대지면적(계획 경계 217,876㎡ × 획지율 0.60 = 130,726㎡)로 건폐율·용적률·높이 산정. 주차는 경주시 조례(문화·집회·판매·업무 100㎡/대, 근생·숙박 200㎡/대, 주거 0.7대/세대) + 지상 주차전용건축물.
- 산출물: `20261010_program_area_table_v2.md`(면적표+구조+가정), CSV, XLSX(openpyxl 가능 시), 결과 요약.
