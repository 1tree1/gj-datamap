# 02 해결방안: 프로그램과 규모 — 15장 상세 목차와 산정 결과 (v1)

작성 2026-10-10. 근거 조사 `research/R1~R4`(프로젝트 내부, 청사·주거·업무 기준, 문화·상업·숙박·주차 기준, 수요 통계)와 계산 `calc/part2_model.py`(결과 `calc/part2_results.md`·`.csv`)를 합쳤다. 해결 컨셉(23쪽)과 도로·필지 계획(24·25쪽)은 사용자가 하며, 이 문서는 대지면적을 획지율 60%로 가정해 계산한다. 등급 T1~T4, 상태 ✔ 원문 확인 / △ 2차·가정 / ✘ 근거 없음.

## 1. 결정과 전제

- **계획 경계** 217,876㎡(Rhino 측정). 대지면적(획지 합계) 130,726㎡ = 경계 × 60%(strata 최종 59.6%, clean 67.2%), 공원·광장 16%, 도로 24%. 도로·필지 확정 후 재계산한다.
- **앵커 선정(제안)**: 청년창업·기업지원(청년오피스복합타운), K-헤리티지·역사문화예술, 청년주거 3개를 앵커로, 창작 스튜디오를 EXCHANGE 보조 앵커로 둔다. 모빌리티 허브(시 구상 3대 전략)와 숙박·상업·커뮤니티는 기타 프로그램으로 둔다. 시청·의회는 비교안 B로 계산한다.
- **산정 3유형**: ① 정책목표형(청년 일자리, 청년주거: 목표 인원 → 면적) ② 수요추정형(문화·숙박·상업·허브: 방문 유동 → 이용자 → 면적) ③ 법정·기준형(청사 면적 상한, 주차 조례, 건폐율·용적률).
- **시나리오**: A = 청년·문화 앵커형(NEXUS), B = A에서 청년오피스를 절반으로 줄이고 시청·의회 캠퍼스를 더한 안(기존 덱). 케이스 = 보수 / 기준 / 적극.

## 6. 규제 정합과 기존 안과의 비교

- **높이** 최고 19.5~20.0m로 도심 20m 지구(92.9%)·15m 지구(7.1%)와 맞는다. 단 15m 지구와 도로 인접 3층(15m) 가이드에는 청년주거 18m·창업 19.5m가 걸릴 수 있어 필지별 확인이 필요하다.
- **건폐율·용적률**: 고시 결정도 상업 80/450, 공공청사·문화 60/250 안이다. 현 용도지역 자연녹지(20/100)를 그대로 두면 A 기준 건폐율 21.3%가 한도(20%)를 약간 넘고 용적률 86%는 안이다. 지구단위계획에서 용도지역·획지별 지표를 정하는 경로(특별계획구역, 세부개발계획)가 필요하다.
- **주차** 지하 불가로 지상 주차전용건축물(건폐율 90%·용적률 1,500%까지 허용 [T1 ✔])을 쓰며, 지구단위계획수립지침 3-2-5(차 없는 거리 목적 시 완화)와 도시재생특별법 제32조·제54조가 완화 경로다. 공개공지는 문화·판매·숙박 10%, 업무 5%이며 용적률·높이 1.2배까지 완화된다(경주시 건축 조례 [T1 ✔]).
- **매장유산**: 지하 0·성토 2m 미만, 보호·전시 전용 부분은 건축면적·바닥면적 불산입 [T1 ✔]. 공중광장·데크의 기초와 높이는 미검증 가정이다.
- **기존 안(strata 최종 209,930㎡, 용적률 163%) 대비**: 기존 규모는 이 산정의 **적극안(197,371㎡)** 수준이다. 기준안은 112,368㎡(54%)로, 기존 안은 획지 크기×층수로 정해져 수요 근거가 없었다. 판매·음식 23.7%→9.8%, 창조산업 9.4%→5.0%, 청년주거 714~816세대→600세대로 줄고, 시 구상에 있던 숙박(0→59실)과 모빌리티 허브가 새로 들어온다.
