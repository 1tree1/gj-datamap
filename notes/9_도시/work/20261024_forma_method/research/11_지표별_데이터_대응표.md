2. **새로 받아야 하는 데이터는 8종**입니다: ① 기상청 AWS 경주시(283) 풍향·풍속·기온 ② 도로교통량 통계연보 2025(국도 지점 AADT) + ITS 차량검지(VDS) 교통량 ③ 환경부 세분류 토지피복지도(1 m급, 2025년판) ④ 도로명주소 출입구정보 ⑤ 국가유산청 공간정보 SHP·WMS/WFS(현상변경 허용기준·문화유적분포지도) ⑥ 실거래가 API 3종(토지·상업업무용·단독다가구 매매) ⑦ 하천구역(법정) 폴리곤 ⑧ SGIS 집계구·격자 인구. 나머지는 저장소에 있습니다(§3).
3. **바람 입력은 교체할 수 있습니다(1차 「불가」에서 「가공 필요」로 정정).** Forma 기본 풍배도는 Global Wind Atlas의 ERA5 2008~2017 통계이며, detailed wind 분석에 **사용자 EPW 파일 반입**이 지원되고 rapid와 풍배도를 공유합니다 [T4 Autodesk 포럼 직원·사용자 답변, 2026-10-25 확인]. 따라서 AWS 283 시간 자료 → EPW 생성 → Forma 반입 경로가 열립니다. 미기후(UTCI 유사) 분석의 기상 결합(ERA5)이 EPW를 따르는지는 미확인(Q15 잔존).
4. **경주시의 기상 관측점은 AWS 「경주시」 지점번호 283, 경상북도 경주시 탑동, 해발 40 m**입니다 [T2 기상청 날씨누리 AWS 관측 목록, 2026-10-24]. ASOS(종관)는 경주에 없고 가장 가까운 ASOS는 포항(138)·영천(281)입니다 [T2]. 자료는 기상자료개방포털(분·시·일·월·연, 1997년~, CSV/Excel)과 기상청 API허브(무료, 일반회원 20,000건/일)에서 받습니다 [T2]. 포털의 바람장미 메뉴는 「컨텐츠 준비 중」(2026-10-24)이므로 풍배도는 AWS 시간 자료에서 자체 집계합니다.
5. **소음 검증용 공식 측정값은 경주에 없습니다.** 국가소음정보시스템 「측정지점」 메뉴의 도시 목록(환경소음 자동·수동, 측정망 전체·중앙·지방)에 경주시가 없고, 경북은 포항시(자동·수동)·구미시(수동)만 있습니다 [T2 noiseinfo.or.kr/noise/spot.do, 2026-10-25 확인]. 소음 입력(도로 교통량)도 공개 데이터로 완결되지 않습니다. 국도 지점 AADT(통계연보 2025)는 받을 수 있으나 시도(市道) 교통량은 ITS VDS(서비스 추가 신청)와 경주시 교통정보센터 원자료 청구(REQ-001)에 달려 있습니다. 소음 기준값 도로변 주거지역 낮 65·밤 55 dB(A)는 국가지표체계 2차 인용(T2)이고 「환경정책기본법 시행령」 별표 1 원문은 법령정보센터 페이지가 본문 없이 응답해 미열람입니다(2026-10-25).
