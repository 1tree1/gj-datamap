## 요약

1. **한 문장 정의** — 사용자가 그린 경계와 골격(축·도로·진입) 위에서, 법정 규제를 불가능 영역으로 잘라내고, 경주 원도심(S2) 실측 분포·프로그램 수요·사용자 확정값으로 정한 범위 안에서 보조 골목·가구·공원·획지·용도·매스를 규칙으로 생성해, 가중치 없는 목적(MVP: 사업성 f₃·조직정합 f₄·공공성 f₅①)으로 NSGA-III 파레토 전선을 구하고, 성격이 다른 소수의 대안을 사람이 골라 다듬어 모든 수치와 조정을 출처 등급과 함께 추적표에 남기는 절차입니다 [판단, 이 문서 — 실행 §0.4·자동화 §0.4 조정].
2. **7층 구조** — ① 데이터(입력 정합 M0) → ② 제약(M1) → ③ 생성(M2~M6) → ④ 평가(M7) → ⑤ 최적화(M8) → ⑥ 선택·사람 조정(M9·M11·M12) → ⑦ 검증·보고(C-1~C-9·M10·지배 검사·추적표). ③~⑤만 최적화 루프 안(Python, 1회 ms~1 s)이고 Rhino·Forma·Ladybug는 모두 루프 밖입니다. 사용자가 결과를 보는 층은 따로 없고 M12 Rhino 실행기·M9 벡터 그림이 그 역할을 하며, KPI 대시보드·웹 3D 뷰어는 원 문서 미설계입니다(§2.4, X-37).
3. **데이터 반영 다섯 방식** — ① 불가능 마스크(법정·물리 금지) ② 생성 규칙의 범위(S2 실측·사용자 확정) ③ 목적함수(ms 계산·변별력) ④ 보고 KPI ⑤ 사후 검증·비교 기준. 같은 데이터라도 법정이면 ①, 실측 분포면 ②·③, 분 단위 계산이면 ⑤로 갑니다.
4. **밀도는 결과** — 「최적 용적률 한 값」은 만들지 않습니다. 상한(법정) ∩ 조직(S2) ∩ 하한(수요) 범위를 등급표로 만들고, 전선 해의 값을 네 분모 × (GSI·물리 FSI·법정 FSI)로 보고합니다. 사례 밴드 B는 [가정]이라 사후 점검에만 씁니다.
5. **환경은 세 층** — 루프 안 제약(높이·인동 0.5H·축 연속 C-8·지하 0) / 루프 안 목적·KPI(녹지 접근 f₅①, H/W, 선택 시 동지 그림자 K9′; 투수 K5는 포장·식생 규칙이 없어 지금 계산 불가) / 최종 3~5안 정밀 검증(판례 일조·SVF·VSC·바람·소음·UTCI). 층끼리 합산하지 않습니다. 지반·오염은 「정화 전 = `buildable` 제외, 나머지 = `cost_factor`」 규칙만 있고 자료가 없으며, 북천 하천구역은 해당 여부, 바람은 쾌적 척도·기준이 확인 대기입니다(§9.2).

## 6 용적률·건폐율 도출 논리

### 6.1 「최적 용적률 한 값」을 만들지 않는 이유

사용자 요청은 「경주 조직 → 사례 밀도 → 부지 건폐율·용적률 도출 → 그 값을 반영해 최적화」였습니다(Q28·Q33 ⑤). 시스템은 같은 순서를 따르되 세 곳이 다릅니다(자동화 §4.1).

1. 결과는 한 값이 아니라 **범위**입니다. 범위는 최적화 전에 「도출 밴드 표」(`density_band.xlsx`)로 사용자에게 먼저 보입니다.
2. 조직 상단 1.12(경계 띠 (c))는 범위를 **자르지 않고 점검 열**로 둡니다. 조직 정합은 규제가 아니기 때문입니다.
3. 사례 밴드 B는 [가정]이라 **사후 점검**에만 씁니다.

밀도(GSI·FSI·L)는 유전자가 아닙니다. 유전자는 가구별 밀도 등급 d_b이고, 실제 건폐율·용적률은 등급표 → `solve` → `fit`을 거친 **결과**입니다(실행 §2.2).

### 7.1 목적과 분리 원칙

사용자 요청(Q35)은 「건폐율과 용적율, 그리고 작은 골목길과 매스 배치는 … 건강하게 잘 작동되고 있는 다른 도시들의 공간정보들을 여러 개 학습해서」 생성하는 것이었습니다. 시스템은 이것을 생성모델이 아니라 **측정 → 규칙 범위·채점 기준(A)**과 **비슷한 가구 형태 템플릿(B)**으로 번역했고, 사용자가 합의했습니다(UC-20). 핵심 장치는 「건강한 도시」를 형태로 고르지 않는 것입니다 — 형태로 골라서 형태를 배우면 순환 논리가 됩니다(T6-28).

| 원칙 | 내용(건강 §1.7) |
|---|---|
| 1 | 판정 집합 J(사람·활동·시간의 결과)와 학습 집합 F(물리 형태)는 교집합이 없음 |
| 2 | J에 F의 기계적 함수(인구밀도·상가 밀도·야간광 수준)를 넣지 않고 변화율·비율로 |
| 4 | 판정을 `judge_results.csv`에 날짜와 함께 고정한 **뒤에** 형태를 잼 |
| 5 | 비건강 대조군도 같은 코드로 재고, 분포가 겹치면 「건강한 도시에서 관찰된 범위」라고만 씀 |

### 7.5 현재 결과의 함의

1. **지금 엔진 범위는 바뀌지 않습니다.** 「건강」 확정이 0곳이라 정의역을 옮길 근거가 없습니다. MVP 정의역은 경주 S2 실측 + 법정 상한 + V0·사용자 확정값으로 진행합니다 [판단, 이 문서].
2. **f₄의 뜻을 「건강한 형태」가 아니라 「경주 주변 조직과의 정합(맥락 연속)」으로 명시합니다.** 경주 원도심은 비건강(예비)이므로 f₄ 최선 해는 「쇠퇴 조직의 형태를 그대로 따르는 해」일 수 있습니다. 그래서 f₄를 유일한 형태 기준으로 쓰지 않고, 건강 분포가 확보되면 「건강 관찰 범위 이탈」을 보조 KPI로 나란히 둡니다. f₄를 경주 S2에 두는 이유는 사용자 요구 G3·G4(경주다운 거리, 주변과 이어지는 계획)와 CLAUDE.md §5-7·§5-8(주변 건물이 방향을 바꾸는가, 축 연속)이 「주변과의 정합」을 요구하기 때문입니다 [판단, 이 문서 — P T6-4 #1의 조정안, 사용자 확인 대기 X-20].
3. **학습 결과가 엔진에 들어가는 순서**: `judge_rules_v1.yaml` 사전 등록 → 판정 고정 → 같은 코드로 형태 측정(경주 기준선 v2 포함) → 건강·비건강 분포 겹침 확인 → 겹침이 작은 지표만 정의역 갱신 후보 → M1 20 m 마스크가 우선(교토 간선 31 m처럼 경주 상한을 넘는 범위는 「마스크 밖」 표시) → 추적표 행.
4. **경주 측정 원천이 바뀔 수 있습니다.** 엔진 정의역 근거(교차 간격 30–46 m, 정본 (a) 등)는 `ctx_fixed`(22,621동) 기반 측정이고, 건강 문서는 경주도 B001(23,579동)·교차점 분절 방식으로 「기준선 v2」를 다시 재도록 했습니다. 재측정 뒤 정의역 수치를 갱신할지 정해야 합니다(X-20).
5. **국내 경로**: HU1 제안은 SGIS 집계구 단위 「인구가 유지된 가구」를 주 경로로 올린 (c)입니다. 같은 SGIS 자료를 f₅①(D11)도 기다리므로 청구를 한 번에 묶을 수 있는지 확인이 필요합니다(X-40).
6. **일정**: 핵심 형태 측정 + 판정은 12.5~16일 [가정]이고 엔진 구현(22.0–22.5일 [가정])과 둘 다 Claude Code 몫인데 통합 일정이 없습니다. 이 문서는 학습 반영을 MVP 밖(확장판 이후)으로 두는 것을 제안합니다 [판단, 이 문서]. AU-6(0.50 고정 여부)은 기본값(탐색)으로 화면 2를 진행하고, 형태 측정 뒤 HU6(해외 분포 사용 위치) 결과로 재검토합니다(X-08·X-46).
7. **델프트 Stationsbuurt**(「역사 도심 옆 철도 부지 재개발」)는 학습 기준이 아니지만, 폐역 부지인 구경주역의 필지·가로 규칙 점검 사례로 쓸 수 있는지 HU17에서 정합니다.
8. **공모 본문 사용 제한**: 이 절의 해외 기준 도시·대조군 이름과 사진은 공모 본문에 쓰지 않고, 공모 본문에는 방법(사전 등록 판정 → 형태 측정 순서)만 씁니다(실행 머리말 전제 ② [T1, 가이드라인 경유], §1.4).

### 8.5 파레토 → 대안 선택 규칙

| 판 | 대안 | 고르는 규칙 |
|---|---|---|
| MVP | M1 사업성 | 전선은 단가 「중」으로 구하고, 전선 해의 f₃를 단가 3점(저·중·고)에서 다시 계산해 점마다 최선 해를 찾음. **세 해가 같을 때만 M1**, 다르면 「M1 미정(단가 민감)」으로 세 해 모두 표시 |
| | M2 조직정합 | f₄ 최선 |
| | M3 공공성 | f₅① 최선(기존·계획 성분 병기) |
| | M4 균형 | 목적마다 순위 백분위 → **가장 나쁜 목적의 백분위가 가장 높은 해**(최악 순위 최대화). 단가 3점에서 같을 때만 채택 |
| | (보조) 경향 요약 | 정규화 목적공간 K-means 3군집 대표해 — 서술용(KPF 2019 [T3]) |
| 확장판 | A 보존 / B 사업성 / C 접근성 / D 조직정합 / E 균형 | A–D는 f₂·f₃·f₁·f₄ 최선, E는 M4 규칙, B·E에 단가 3점 규칙 |

- 이상점 거리(정규화 척도에 가중이 숨어 듦) 대신 최악 순위 최대화를 쓰는 이유는 가중치 금지 원칙입니다(T-106). 「목적을 대칭으로 본다」는 판단 자체는 추적표에 남깁니다.
- 고른 대안은 C-1~C-9를 다시 통과해야 하고, 두 규칙이 같은 해를 고르면 차순위를 씁니다.
- **제출 층**(결정도 재현안·대표안·권고안 3안 + 분산 삽입형 1안)은 분석 층(M1~M4·A–E)과 따로 둡니다. 분산 삽입형은 S3 문제라 엔진이 만들지 못하므로 사람과 규칙으로 별도 작성합니다(CLAUDE.md §5-4, MU8 입력 미정).

### 8.7 사람 조정과 추적표

- 최종안 = 전선 해 하나 + 사람의 조정입니다. 수정은 `alt_mk.3dm` 사본 안에서만 하고, `diff_3dm.py`가 단위 assert → `lot_id`·`bldg_id` 매칭 → (a) 파라미터로 되돌릴 변경은 `config.yaml` 패치 후 같은 시드 재실행 (b) 형태 손 수정은 추적표 「사람의 조정」 (c) C-1~C-9 재검사로 나눕니다. 제약을 어기는 손 수정은 채택하지 않습니다(자동화 §3.12).

- 첫 행 제안 T-101~T-108(자동화 §8.5): 가로망 골격 고정(T-101), 유전자 단위 가구 9(T-102), EPSG:5187 정본(T-103), FSI 1.12 → 점검 열(T-104), 일조 연속 2시간 → 보고 KPI(T-105), M4 최악 순위 최대화(T-106), 축 ① B1 띠 고정(T-107), 단가 3점 규칙(T-108).
