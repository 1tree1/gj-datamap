# 구경주역 마스터플랜 지식그래프 (v1, 2026-10-06)

"어떤 데이터·법규·계획이 마스터플랜의 어떤 값을 정하는가"를 노드와 엣지로 한 장에 보이게 만든 것이다.
내 설계 방향 + 2030 경주도시기본계획 + 도시재생 계획·성과 보고서 + 417쪽 연구 + 매장유산·경관·공모 문서 + 프로젝트 자료를 한데 놓고, 각 엣지에 **관계·강도·근거 위치**를 붙였다.

## 열기

`knowledge_graph.html`을 더블클릭한다. 인터넷이 필요 없다(D3·데이터·CSS 전부 한 파일, 약 1 MB). Chrome에서 렌더·상호작용을 확인했다(Edge·Safari는 미확인).
화면이 좁으면(1450 px 미만) 왼쪽 패널이, 더 좁으면(1250 px 미만) 오른쪽 패널도 접힌 채 열린다 — 위쪽 ◧ ◨ 버튼으로 다시 펼친다.

특정 상태를 바로 열려면 주소 뒤에 붙인다:

| 보고 싶은 것 | 주소 끝에 붙이기 |
|---|---|
| 최고 높이·층수를 정하는 것(상류 2단계) | `#v=detail&f=P_H&d=up&h=2` |
| 고도지구가 정하는 것(하류) | `#v=detail&f=L_GODO&d=down&h=2` |
| 값 × 근거 표 | `#v=matrix` |
| 값 노드를 근거 등급으로 칠하기 | `#v=detail&c=grade` (현재 값 출처는 `c=cur`) |

## 세 가지 보기

1. **한눈에** — 묶음(그룹) 단위 구조. 묶음을 클릭하면 요약, **더블클릭하면 그 묶음의 노드로** 들어간다. 선 위 숫자 = 묶음 사이 엣지 수.
2. **전체 그래프** — 노드 184개와 엣지 491개 전부. 노드에 마우스를 올리면 연결이 강조된다. 노드를 **더블클릭**하거나 왼쪽 '마스터플랜 값' 목록을 누르면 **초점 보기**: 그 노드의 상류(정하는 것)·하류(영향 주는 것)만 1–3단계로 남긴다. 이게 질문에 직접 답하는 화면이다.
3. **값 × 근거 표** — 행 = 마스터플랜 값 32개, 열 = 근거 묶음. 칸 = 그 묶음에서 그 값으로 가는 직접 엣지 수, ■ = hard 포함, ○ = 자료 공백 포함.

노드를 클릭하면 오른쪽에 **이 노드를 정하는 것 / 이 노드가 정하는 것**이 관계별로(한정·배제·고정·규모 산정·보정·지침·파생·순서·재원·충돌·평가) 나온다. 각 항목에 출처 등급·자료 상태·강도·근거 위치가 붙는다. `K1-031` 같은 점선 밑줄 번호는 원문에서 쪽 단위로 뽑은 사실이다(마우스를 올리면 요지, 누르면 전문).

## 어휘

- **노드 종류(열 순서)**: 설계 방향 → 계획·고시 → 법규·기준 → 데이터 → 파생 제약·모델 → 마스터플랜 값 → 평가함수. 왼쪽일수록 원천, 오른쪽일수록 결과. 마스터플랜 값은 다시 다른 값을 정하므로(용도 구성 → 주차·교통·오수) 오른쪽으로 여러 칸으로 나뉜다.
- **엣지 `A → B`**: A가 B를 정한다. 굵은 선 = hard(불가능·상한: 규제·법정), 가는 선 = soft(조정·참고), **점선 = 추정**(문서로 확인하지 못하고 설계 논리로 이은 것), 점점선 = 충돌.
- **자료 상태**: 보유 · 부분 · 요청 · 없음. 없음·요청은 빨간 점선 테두리 — **아직 못 구한 자료**.
- **출처 등급**: T1 법정문서 · T2 공공발간 · T3 학술 · T4 언론·2차(빨간 `T4` 표시). 공모·지구단위계획 문서에는 T1–T2만 쓴다.
- **스케일**: S1 부지 · S2 원도심 1 km · S3 도시·폐선축. 필터로 가를 수 있다. S3 통계로 S1 프로그램을 정당화하지 않는다.
- **근거 등급(값 노드 오른쪽 원)** — 코드가 엣지로부터 계산한다:
  - **A** T1·T2 근거가 hard 관계로 값을 직접 한정·산정·고정한다(파생 노드를 거치면 그 입력으로 환원)
  - **B** 확인된 T1–T3 근거가 보정만 한다
  - **C** 방향·저작(추정·T4 포함)뿐
  - **D** 값을 한정할 핵심 근거가 자료 공백(없음·요청)
  등급은 '쓸 수 있는 근거'이지 현재 값이 그 근거를 썼다는 뜻이 아니다.
- **현재 값 출처**(`cur_src`): 고정입력 · 법정·실측 · 혼합 · 저작 · 가정 · 미산정. plan_clean 스크립트·추적표를 보고 **내가 매긴 감사 분류**다. 틀리면 `kg_nodes.csv`에서 고친다.
- 값 노드 왼쪽 위 분홍 `⚡n` = 그 값에 걸린 상충(엣지 + 원문 근거) 수.

두 값을 겹쳐 보면 연결할 일감이 나온다: **근거 등급이 A·B인데 현재 값이 저작·가정·미산정인 값**(오른쪽 홈 패널에 근거 건수 순으로 나열).

## 고치는 법

노드 추가: `kg_nodes.csv`에 한 줄(`id`는 영문 스네이크, `kind`는 intent/plan/law/data/derived/param/eval). 엣지 추가: `kg_edges.csv`에 한 줄 — `rel`은 limits·excludes·anchors·sizes·calibrates·guides·derives·sequences·funds·conflicts·evaluates, `strength`는 hard/soft, `basis`는 확인/추정, **`note`와 `ref`에 근거를 쓴다**(근거 없는 엣지는 `basis=추정`). 값 노드는 `cur_src`·`cur_note`도 채운다. 저장 후:

```bash
python build_kg.py
```

## 이 그래프의 한계 (인용 전 읽을 것)

- **엣지의 `확인`은 '프로젝트 문서·PDF에서 직접 확인'이라는 뜻이지 원문 대조를 마쳤다는 뜻이 아니다.** 원문 근거 308건은 에이전트가 쪽 단위로 추출했다(K1은 핵심 문구 144건을 쪽 본문에서 직접 대조해 불일치 0건이라고 보고). 사람이 원문과 대조하기 전에는 수치를 인용하지 말 것.
- 이미지로만 있는 쪽(시 구상 도면·현상변경 허용기준 표·황오동 경관계획도 등)은 판독값이고, 원문 PDF가 저장소에 없는 문서(공모 가이드라인 B-004)는 쪽 표지로 인쇄쪽을 정했다.
- 현황 앵커 3,822억·79,438㎡ 등은 대부분 언론 경유 T4다. 시 구상 토지이용표(B-002 p.23)는 혁신포럼 발표자료가 인용한 도면이라 시 구상 원문과 대조가 필요하다.
- 법령 별표(주차장법·환경부고시 등)는 미러·요약 경유다. 최저주거기준은 계획서가 인용한 2011년 공고다.
- 417쪽 연구의 제안 24건은 학생 설계안(비법정)이다. 2030 기본계획 수치는 2013 기준이다. 2040 재정비·2035 전략계획은 발표자료 수준이다.
- 엣지 방향·강도·basis는 설계 판단이 섞여 있다. 의심스러운 엣지는 `basis=추정`으로 내려 두었다.

## 원문 대조에서 바로잡은 것 (기존 문서·시드 정정)

- 2030 기본계획 설문(경주역 부지 활용 44.5% 등)은 인쇄쪽 **79**(기존 '78'). '동서 분리' 진단의 출처는 p.285(기존 '133–139').
- 417쪽 연구: (옛)경주역 제안 24건 중 **시청·의회를 두는 안은 0건**, 구 역사 **이축 0건**, 터미널을 구경주역으로 옮기는 안 7건. '인지지도 63장' → 유효 설문 63명·인지지도 27명. '트램 남북 18 km' → 북·남 각 약 18 km.
- 구 역사: **'개업 1918.12.28'은 어느 문헌에서도 확인되지 않는다**(1918.10 개통·1918.11.1 영업개시, '12월 28일'은 2021 폐선일). 등록문화유산 기재 문서 없음(2013 철도기념물만).
- 매장유산: '성토 후 공원·주차장'은 발굴 유예(**표본·시굴은 실시**), '2 m 미만 성토'는 표본·시굴 유예 — 서로 다른 조건. 관로 매설은 참관조사.
- 높이: 고도지구 20/15 m 하나가 아니라 **황오동 경관 가이드(필수) 도로 인접 3층·15 m**, 시가지경관지구 6층·30 m, 현상변경 허용기준 3구역 ⑤ 8/12 m가 겹친다.
- 면적: 218,478(내 경계)·156,460(고시)·148,770(전략계획·지표조사)·79,438(시 구상)·160,000(활성화계획) 5종이 혼재 — 분모부터 정해야 한다.
