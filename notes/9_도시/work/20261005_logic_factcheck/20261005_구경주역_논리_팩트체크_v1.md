## 0. 결론 먼저

1. **정리본의 논리 구조는 이 프로젝트의 원칙과 잘 맞는다.** "공식 데이터"와 "설계자 가정"을 가르는 규율, S1(부지)·S2(원도심)를 잇는 동서축, 관광객·근로자·거주자 세 인구, 성동시장 연계(상권과 경쟁하지 않음)는 전체기록에서 이미 확정한 방향(P1·P6, 교훈 4·5·6)과 일치한다.
2. **그러나 면적 체계가 현재 경계와 맞지 않는다.** 정리본의 25,000 / 29,438 / 25,000㎡는 79,438㎡(시 구상 면적, T4, 정의 불명)를 쪼갠 값이다. 지금 `최종콘타모델_v2.3dm`에 있는 사용자 경계는 **218,478㎡(300×945m)**로 79,438㎡의 2.75배다(79,438㎡는 현재 경계의 36%). 면적·인구·밀도 수치는 전부 다시 산정해야 한다.
3. **숫자 대부분은 사실이다.** 872만·5,020만·79,438㎡·황성공원 895,373㎡·청년 약 4.5만(18.5%)·79억은 대조되었다. 확인되지 않은 것은 철도도심재생과장의 "청년 오피스" 시의회 발언, 청년정책 총액 105억, 시민원탁회의 순위, 황오동 세대수·면적이다(원문 회의록 확인 필요).
4. **고쳐야 할 가정**이 있다: ① 관광객 5~8% 이동은 근거 없는 가정이며 S3/S2 통계로 S1 프로그램을 키우는 구조다 ② 남측 건폐율 25~30%는 자연녹지(법정 20%)·용도지역 변경 전제를 밝혀야 한다 ③ 연면적 15,000~20,000㎡는 산술이 안 맞는다(6,250~7,500㎡ × 2층 = 12,500~15,000㎡) ④ 북측 25,000㎡에 시청급 공공청사 + 오피스 + 청년주거를 넣으면 용량이 모자란다.
5. **정리본이 약하게 다룬 것 중 저장소에는 강한 근거가 이미 있다.** 동서 단절(985m 무횡단, 폭 3.2m 육교 1개, 우회율 중앙값 3.5), 황오동 쇠퇴(10년 −32.7%, 20–39세 −44%), 숙박 인허가(황오동·성동동 65곳 = 시 전체 53%), 공공청사 24,987㎡(고시 2026-8호 T1에 이미 결정), 규제 4겹과 매장유산. 반대로 정리본은 **규제·고도·매장유산·모빌리티·주차를 전혀 다루지 않는다.**
6. **정리본과 전체기록의 프로그램은 같지 않다.** 시청 본청 이전·모빌리티 허브·P+R·청년주거 2,150세대·구 역사 이축(전체기록 v2)과, 문화예술 남측·Open Workshop·Residency·청년오피스·청년주거 350세대·구 역사 보존(정리본)은 어느 쪽을 정본으로 할지 결정이 필요하다(§6).

## 1. 내가 이해한 것

### 1.1 정리본의 논증 (한 장)

- **명제**: 구 경주역은 독립 관광시설이 아니라 `폐역 → 사람을 만드는 도시 인프라`. 남측은 사람을 끌어들이고(VISITOR), 북측은 머물게 하고(DAILY), 중앙은 만나고 주변으로 확산시킨다(EXCHANGE).
- **근거 사슬**: 정책(혁신지구 79,438㎡) → 위치(황리단길·대릉원 ↔ 황성공원, 성동시장 ↔ 황오동 두 축) → 수요(관광 872만, 청년 4.5만, 청년오피스 정책) → 인구 세 종류(방문·근로·거주) → 프로그램 그래디언트(`PUBLIC → CREATIVE → DAILY`, 역사·문화예술 → 체험 → Open Workshop → Studio/Residency → Office/Community → 공공청사 → 청년주거) → 면적 배분(남 31.5% / 중 37.1% / 북 31.5%).
- **작동 메커니즘 6단계**: 기존 관광수요 이용 → 남측 문화예술로 동선 확장 → 중앙 체험·워크숍으로 체류시간 증가 → Studio·Residency·Office로 생산 연결 → 북측 공공청사·청년주거로 매일 반복 인구 → 동서 공공축으로 성동시장·황오동에 확산.
- **방법 규율**: "공식 확인 데이터"와 "설계자가 정한 목표값"을 구분하라(§36–38). 5~8%, 1%, 1.3명/세대, 350세대, 700~900명, 25,000/29,438/25,000, 9,000/9,500/10,938은 가정이라고 쓴다. 이 규율은 CLAUDE.md §3.1–3.2와 같다.

### 1.2 저장소에 기록된 당신의 설계 방향

- **작업 원칙**: 데이터 기반. 고정 입력은 경계선 하나. 417쪽 연구 부지 제안 + 공고안 + 참조사례를 같은 5개 목적함수로 평가해 목적공간에 찍고, 파레토 해를 손으로 다듬는다. 제약은 페널티가 아니라 불가능(`buildable` 마스크)으로 다룬다. S1/S2/S3를 섞지 않는다. 학부 스튜디오 과제라 절차·권한 제약(시청 이전 결정, 토지 매입 등)은 가정으로 명시하고 진행하고, 물리·유산 제약만 제약으로 둔다.
- **경계**: 사용자가 라이노 `내가 하고자하는 경계라인`에 직접 그린 선(v2 → 현재 파일). 경계 안의 기존 건물·기존 지구단위계획은 무시.
- **프로그램(2026-09-30 v2 블록계획)**: 경주시청 본청 이전(15%) · 청년주거 최대 2,150세대(28%) · 헤리티지 블록(역전광장 + 구 역사 이축 + 역사헤리티지관, 13.9%) · 문화프로그램(10.5%) · 근린 마켓홀(7.6%) · 체육센터·주민지원(4.9%) · 주차빌딩 2(715면 + P+R 806면) · 선형공원·도로. 구조는 종축 945m(남단 R1 ↔ 북단 R2) + 횡축 A·B·C, 핵심 보행축 `성동시장 → 광장 → 구 역사 → 육교 desire line → 황오동`.
- **두 축 지표**: (방문객·체류시간) / (거주인구·생활업종·야간활동)을 항상 나란히.

## 4. 논리 점검 — 데이터가 마스터플랜을 정말 뒷받침하는가

### 4.1 스케일을 섞는 곳 (CLAUDE.md §3.3)

- 872만(황리단길·대릉원 일원)과 5,020만(경주시)은 S2/S3 통계다. 정리본은 이 값에 5~8%를 곱해 **S1 남측 문화공간의 1,000~2,000명/일 규모**를 만든다. 같은 구조의 전체기록 원칙은 "S3 통계로 S1 프로그램을 정당화하지 않는다"다. 872만은 맥락(왜 이 방향인가)에는 쓸 수 있지만 **면적·규모의 근거가 될 수 없다.**
- 대체 방법(공급 측 용량 방식): `프로그램 연면적 ÷ 1인당 이용면적 × 회전율`로 수용 가능한 일 방문 인원을 먼저 구하고, 그 값이 아래 실측 기준선과 비교해 비현실적이지 않은지 확인한다.
  - 부지 현재 유동: 구역 D(폐역 구역) 밀도 79~80명/ha(거주 27·근무 117·유동 1,259, 전체기록 4.4 표기 그대로), 부지+300m 350명/ha(소상공인365 2025.06~2026.06, T2). 단위·구역 면적은 원자료로 재확인 권장.
  - 황리단길 300m: 유동/(주거+직장) 14.1, 주말/주중 1.72(T2). 성동시장 200m 1,175명/ha.
  - 정리본의 추가 1,195~1,911명/일은 위 구역 D 유동 값(1,259)과 같은 자릿수의 1~1.5배다(단위가 일 단위 구역 합계라는 전제, 추정). 가능한 범위인지 보이려면 위 용량 계산이 필요하다.
- 체류시간 문제의 증거는 정리본에 없지만 저장소에 있다: 황오동 방문객 설문 2024에서 3시간 미만 체류 79%, 1만 원 이상 지출 2.7%, 경주시민 56%(B-001, T2). "체류시간을 늘리는 체험·워크숍"의 직접 근거다.

### 4.2 규제·유산이 빠져 있다 (CLAUDE.md §3.4)

정리본의 면적·건폐율·층수는 "건축 가능한가"를 묻지 않는다. 저장소의 `buildable` 판정을 반영해야 한다.

- 용도지역: 자연녹지 77.5%(법정 건폐율 20%), 2종일반주거 16.3%, 일반상업 6.2%(§2.2). 청년주거·오피스·공공청사의 용도는 지구단위계획 세부개발계획(특별계획구역)과 용도지역 변경이 전제다. 주상복합형 청년주거는 상업용지에서 불허(전체기록 4.7).
- 높이: 고도지구 95% 이상, 20m(삼층석탑 현상변경허용기준 수용값 → 공공청사도 예외 없음) → 5층 상한.
- 매장유산: 시굴 대상 145,879㎡(고시 구역의 93%), 발굴 유예 조건은 2m 미만 성토 + 성토 후 공원·주차장 → **1단계 지하 불가, 지상 평면주차·공원은 가능**. 유적점 5곳이 경계 안에 있다.
- 역사문화환경보존지역: 필지 기준 경계의 78.9%(현상변경 허가 선행). 세계유산 완충구역·신라왕경 특별법 해당 여부는 판정 불가("해당 없음" 금지).
- 정리본 §14·15의 "남측은 건물로 꽉 채우지 않는다(광장·야외)"는 방향은 이 제약과 **잘 맞는다**(남측의 오픈스페이스·야외전시·마당은 발굴 유예 조건과 양립). 반대로 북측의 중층 업무·주거·청사 집중은 5층·자연녹지 조건에서 용도지역 변경을 요구한다.

### 4.3 면적 배분의 근거 — 용량 점검

정리본의 북측 25,000㎡ 기준으로 간이 점검(전체기록 숫자 사용):

| 항목 | 값 | 출처 |
|---|---|---|
| 경주시청 본청 지상 면적표 | 25,400㎡(기준면적 산입 20,850) + B1 주차 340면 | 전체기록 3.4 |
| 청년주거 350세대 | 약 18,000㎡(36㎡ 전용 ÷ 70% × 350) | 전체기록 3.2의 세대 산식 |
| 오피스 700~900명 | 약 11,200~14,400㎡(1인 16㎡) | 전체기록 4.5c 시청 산식 준용 |
| 합계(지상) | 약 55,000~58,000㎡ | |
| 25,000㎡ × 건폐율 40% × 5층(20m) | 약 50,000㎡ | 층수 = 고도 ÷ 층고 |

**청사까지 넣으면 북측 25,000㎡로는 용량이 모자란다.** v2는 시청 블록만 31,171㎡를 잡았다. 청사를 빼고 청년주거 + 오피스만이면 들어간다. 즉 "북측 25,000㎡"는 프로그램이 정해진 뒤에 나오는 결과여야 한다.

### 4.4 정리본의 서사가 더 강한 곳

- **세 인구 + 근로인구**: 전체기록은 관광(방문)과 정주(거주)를 다뤘지만 "매일 반복되는 근로인구"를 별도 축으로 두지 않았다. 시청 500m 구역의 직주 균형·저녁 매출 증거(T2)와 황오동 사업지 격자(32셀) 종사자 −23.1%(2018→2023, B-001)가 이 축을 받쳐 준다.
- **Open Workshop·Residency의 구분(체류 vs 정주)**: 전체기록 4.5e(예술인 675명, 국악 14.2%, 도서관·사적지·박물관 540명 vs 창작·예술업 125명, 황리단길 공방의 임대료 이탈)가 "공연장이 아니라 공방·작업실·국악 연습실"이 맞다고 결론낸 것과 같은 방향이다. 1946 경주예술학교(남한 최초 예술전문학교, 교사가 옛 경주역사·철도기관고)는 부지를 예술로 쓴 80년 전 선례로 서사 근거가 된다.
- **상업 원칙**(내부 상업 < 기존 도시 상업)은 전체기록 P6(성동시장·중앙시장과 경쟁 금지)와 일치하고, 숙박은 "객실 공급이 아니라 운영"(마을호텔·짐보관·P+R·청년 장기체류)이라는 4.12 결론과도 맞다.

## 6. 결정이 필요한 것 (사용자)

1. **정본은 무엇인가**: 정리본의 남·중·북 문화-교류-생활 구도를 새 마스터플랜 방향으로 확정하는가, 전체기록의 v2 블록계획(시청·모빌리티 허브·청년주거 28%)을 유지하면서 정리본을 서사로 얹는가, 둘을 합치는가.
2. **면적 기준**: 현재 경계(218,478㎡)에서 구역을 다시 나눈다고 이해했다(정리본의 79,438㎡ 체계는 폐기). 맞는가. 79,438㎡를 "혁신지구 공식 구상 면적"으로만 서술해도 되는가.
3. **구 역사**: 남측에 보존·활용(정리본)인가, 이축(v2)인가. 어느 쪽이든 등록문화유산이 아니라는 사실이 서술에 반영되어야 한다.
4. **모빌리티·주차(P+R·트램 예비 부지)**를 프로그램에 남기는가. 남기지 않는다면 주차난·자가용 77%·공식 구상의 모빌리티 허브에 대한 입장이 필요하다.
5. **청년주거 규모**: 시범 350세대(정리본)와 2,150세대(v2) 중 어느 쪽을 기준으로 방어할 것인가(둘 다 대안으로 두고 목적함수로 비교할 수도 있다).
6. **공공청사 = 시청 본청 이전**으로 볼 것인가(고시 공공청사 24,987㎡의 이행), 아니면 일반 공공청사·청년오피스인가.
