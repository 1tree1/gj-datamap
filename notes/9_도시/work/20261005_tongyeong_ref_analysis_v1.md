### 1.2 구경주역 보고서·PT에 가져갈 규칙 (이 문서의 결론을 작업 규칙으로 번역)

1. **평가 항목을 목차로 쓴다.** 공모지침·심의 요건의 항목명을 보고서 요약부에 번호로 재진술하고, PT 구분 슬라이드는 원문 문구를 유지한다. 순서만 서사에 맞게 바꾼다.
2. **보고서는 '펼침(2쪽)' 단위로 설계한다.** 왼쪽 = 제목 블록 + 본문 + 소도해, 오른쪽 = 대형 이미지가 기본형이다.
3. **한 쪽 한 논거, 제목은 주장형.** PT 제목 형식은 "Label: Claim"(예 "Existing: Vacant Site").
4. **시각 어휘 사전을 한 번 정의해 문서 전체에 고정한다.** 용도 색·구역 색·선종·아이콘 칩을 장마다 바꾸지 않는다(이 응모안의 PT는 장마다 색 의미가 바뀌어 매 장 범례가 필요했다).
5. **고정점을 정한다.** 보존할 구조물 하나를 정하고 모든 렌더·도해에서 같은 색·위치로 반복한다(구경주역 후보: 구 역사(등록문화유산이 아님 — 코레일 철도기념물 2013, 원문 대조 완료; v2 계획은 이축)·삼층석탑·폐선 노반 등 — 선정은 사용자 결정).
6. **스케일 사다리로 내려간다.** 광역 → 지구 → 부지 → 가로 단면 → 눈높이. 같은 베이스 지도에 정보를 쌓은 장 다음에, 같은 베이스에서 정보를 빼서 결론만 남기는 장을 둔다.
7. **PT 도입은 정서, 분석은 보고서로 이관한다.** PT는 장당 제목 한 줄 + 이미지가 기본이고, 임베디드 텍스트 중앙값이 57자다.
8. **챕터마다 사람 장면 1장** — 손그림 하루 + 직후 근거 도해.
9. **숫자는 닫히게 쓰고 기준을 병기한다.** 합계 = 총계, 도넛에는 기준(연면적/대지면적)과 출처 등급. 보고서와 PT 숫자는 같은 기준으로 맞춘다.
10. **증거는 시연으로 만든다.** 결과 먼저 → 빈 상태에서 되감기, 프레임당 변수 하나, **변화한 컨트롤에 하이라이트 + 한 줄 캡션**(이 응모안에는 없어서 읽을 수 없었다), 미완은 윤곽선으로 로드맵화.
11. **마지막 두 장은 같은 카메라의 현황/제안 쌍.** Q&A 슬라이드를 따로 두지 않으면 마지막 장이 질의응답 내내 화면에 남으므로 가장 강한 한 장으로 둔다.

### 1.3 그대로 따라 하면 안 되는 것

- **출처·기준연도 표기가 보고서·PT 모두 없다.** 우리 규칙(공모·지구단위계획 문서는 T1–T2, 출처 등급 병기)과 충돌한다. 출처는 보고서 본문·표에 두고 슬라이드에는 이름 + 큰 숫자만 올린다.
- **보고서와 PT의 숫자가 어긋난다.** IRR이 보고서 R.p58(LH 사업 기준)에서 11.17%, 같은 보고서 R.p8과 PT 툴(S.75–87)에서 18%이고 연결 설명이 없다. R.p8의 툴 스크린샷은 Carbon Reduction 52%·Landfill Diversion 100%인데 PT 최종은 42%·미완이다. 중점설계구역 185,000㎡와 계획부지 191,846㎡도 사유 표기가 없다(R.p18).
- **오탈자·복붙 오류.** 보고서 'Our Vison'·'Startegy', PT S.62 우측 라벨 복붙, S.20 'peple', R.p43 캡션 복붙(PT S.39에서 정정됨).
- **시연형 증거에 분모·기준선·가정이 없다.** Car-Free 90%가 무엇의 90%인지, Carbon 42%가 무엇 대비인지 화면에 없다. UI 글씨는 약 5pt다.
- **광역(S3) 지도로 부지(S1) 프로그램을 정당화한다**(S.19). 스케일 혼용 금지 규칙 위반이다.
- **작은 글씨와 대비 부족.** 캡션 7–9pt(S.32·S.35), 밝은 사진 위 흰 글자(S.17), 노란 띠 위 흰 라벨(S.50).

## 6. 설득 전략 상세

전략을 다섯 층으로 나눠 적는다. 각 항목은 **무엇을 했나 → 근거 쪽 → 왜 먹히나 → 가져갈 때 주의** 순서다. 구경주역 적용 메모는 제안이며 결정은 사용자 몫이다.

### 층 A. 심사 구조에 맞추기

**A1. 과업 미러링** (§4.2 참조)
- 보고서 R.p7이 "발주 브리프에서 이해한 과업 6개"를 그대로 번호로 재진술하고 "이 과업으로 발주처와의 대화를 시작한다"로 맺는다. PT는 아젠다(S.3)와 구분 슬라이드 8장이 같은 문구를 쓴다.
- 왜 먹히나: 심사위원은 과업별 채점표를 들고 있다. 구분 슬라이드가 "지금부터 항목 N에 답한다"를 알려 주므로 채점이 쉽고, 한 과업이 둘로 나뉠 때(S.13 → S.54) 빠뜨리지 않았음도 보인다.
- 주의: 과업 문구를 줄이면 1:1 대응이 약해진다. 원문을 유지하고 순서만 서사에 맞게 바꾼다.

**A2. 발주처 언어로 시작하는 정렬**
- R.p4의 첫 문장은 응모자의 장점이 아니라 발주처(국토교통부·LH)의 비전·임무 서술이다. 이어 파리협정 이행을 기반으로 선언하고, "우리 제안 = 그 이행 수단"으로 읽히게 4키워드(Holistic Planning / Connectivity / Placemaking / Regeneration)와 6원칙을 제시한다.
- R.p8은 4열 정책 캐스케이드(국가 → 광역 → 도시 → 부지)이고 마지막 열만 포스터형이다(슬로건 "Becoming a World Leader in Sustainability" + 6개 링 배지). PT S.14는 이를 3열로 압축한다: 파리협정 로고 + "37% by 2030", 생태발자국 3.3→1 지구 픽토그램, 상위계획 7개 목록. 시의 목표 문장이 S.15에서 응모안의 결론 문장으로 다시 나와 둘이 같은 문장이 된다.
- 6원칙은 PT에서 아이콘 없이 텍스트만 든 초록 원 6개다: Healing the City / Cultural Community / Carbon Neutral / Circular Economy + Resources / Disaster-Free by Design / Car-Free. 같은 6개가 후반 S.65에서 측정 대시보드의 목표로 다시 나온다(약속 → 측정).
- 왜 먹히나: 비전이 설계자의 취향이 아니라 상위계획의 요구로 읽힌다. 심사위원이 속한 기관의 말로 설득한다(추정).
- 주의: 화면에 출처 줄이 전혀 없다(S.14). 구경주역에서는 T1 법정문서(도시재생 혁신지구 공모지침, 폐철도 기본구상, 도시기본계획, 고도 보존·육성 특별법 등)로 사슬을 짜되 조항·쪽은 보고서에 달고 슬라이드에는 이름 + 큰 숫자만 올린다.

**A3. 질문 재진술과 평가 방식 약속**
- R.p7은 과업 6개 옆에 **열린 질문 7개**(What / How / Should / Can …)를 놓고, 의문사를 굵게 처리하며 국문 열에도 영어 의문사를 남겨 좌우를 정렬한다. 마지막 문장은 "이 쟁점을 서로 다른 관점의 개념안으로 풀고 핵심 원칙 기준으로 평가하겠다"는 절차 약속이다.
- 왜 먹히나: "우리는 과업을 이해했고 무엇이 열린 문제인지 안다"를 증명하고, 이후 모든 장을 그 질문의 답으로 프레이밍한다.
- 가져갈 것: 대안 A–E를 같은 기준으로 평가한다는 우리의 서사(비교 대상 18개 + 5개 목적함수)와 정합한다.

**A4. 형식 준수 신호**
- 표지는 순백에 중앙 2행뿐이고 우상단에 빈 칸(2+5, 접수번호 칸으로 추정)이 있다. 팀 소개(S.4)는 이름 없이 분야 7개만. 식별 정보는 문서 전체에서 0이다. 공모 규정을 지킨다는 신호이며, 지침이 같은 요구를 할 때만 따라 한다.

### 층 C. 논리와 증명

**C1. 스케일 사다리 + 한 장 한 논거 (S.19–29)**
- 한 장이 논거 하나만 맡고 지도의 프레임이 앞 장보다 한 단계 좁아져 마지막에 사람 시점에 닿는다: S.19 수요권(20/60/90분 동심원 + 닻 아이콘 앵커) → S.20 상위계획 정렬(시 생활권 3·축 2) → S.21 수렴 화살표 → S.22 자연 연결(물·녹지·바람 3컷) → S.23 거점 밀도(트레일 22노드) → S.24 차 없는 수단 → S.25 부지 가로 위계 → S.26 시선 부채꼴 → S.27 기존 격자 연장 → S.28 가로 단면 10m → S.29 눈높이 hero.
- **같은 베이스에서 쌓고 빼기**: S.19 → S.21(같은 광역 지도에서 정보를 빼서 결론만), S.25 → S.26(같은 부지 도면에서 색 선을 빼서 시선만). R.p25는 현황 앵커 지도와 수렴 화살표 지도를 완전히 같은 프레임으로 짝지어 "있는 것 → 만들 것"을 겹쳐 읽게 한다.
- 주의: S.19의 링은 실제 등시선이 아닌 단순 원이다. 구경주역은 등시선 폴리곤으로 정직하게 그릴 수 있다. 다만 이 지도는 S3(광역) 위치 설명용이며 S1 프로그램의 근거로 쓰지 않는다.

**C2. 지역 척도로 비교하기**
- S.28·R.p30: 제안 가로를 지역 대표 시장골목(동피랑 시장길)과 같은 10m 폭으로 나란히 그린다. 기존 골목만 붉은 외곽선·치수선(13m/16m 건물 높이)으로 구분한다. "새 가로 = 기존 골목과 같은 스케일"이라는 가장 명확한 정량 근거이며, 지역 심사위원이 아는 단위다.
- 가져갈 것: 구경주역 원도심 골목의 실측 폭·높이(T1–T2 출처)와 같은 문법으로 비교.

**C3. 반론 선제 차단 (S.25)**

**C4. 전통 원리 → 현대 단면 (S.51 / R.p35)**

**C5. 닫히는 숫자** (§6 A에 이어 별도)

**C7. 미완성을 로드맵으로 (S.86–87)**
- 예고된 공백(S.65에서 이미 빈 도넛 5개를 보였다), "Preliminary"라는 기대치 조정, 윤곽선 하나로 공백을 로드맵으로 전환, "The Way Forward"라는 섹션명의 미래시제, 완료 3개로 파이프라인(입력 → 계산 → KPI)을 끝까지 시연해 나머지는 청중이 외삽. 약점은 남은 5개의 일정·방법·데이터가 어디에도 없다는 점이다. 구경주역은 gaps.md 항목과 연결해 방법·일정을 한 줄이라도 넣는다.

**C8. 사업성은 질적 도식 (S.60–63)**
- S.60 전국 경제기반형 도시재생 사례 7개 도시 지도(일반/선도 2색 선, 상태 괄호: Preferred bidder announced / on hold / Transited to Public-led)로 정책 선례와 같은 궤도임을 보이고 민간 참여의 어려움을 암시 → S.61 원인 2축(입지·사업성) 표 + 통영 사업여건 5카드 + 결론 바 → S.62 같은 블록을 통매각 vs 분할매각(시설 단위 vs 주동 단위)으로 대비하는 A/B 대구와 빨간 점선 매각 단위 박스 → S.63 이해관계자 스택 → 라벨 달린 이중 화살표 → 중개체(REITs) → 사업 박스. 수치는 융자 "사업비의 50%까지 연 2.2%" 둘뿐이며 출처가 없다.
- 61–63은 보고서 R.p56–57의 박스·도식을 "단락 삭제, 도식 유지"로 이식했다. 양적 증거(사업비·현금흐름·IRR 등)는 PT에 옮기지 않았다.
- 보고서의 3장은 반대로 **수치 체인이 끝까지 닫힌다**(§3.4): R.p56 진단 깔때기(국내 사례 → 원인 → 통영 5여건 → SWOT → SO/WO/ST/WT 4전략, 2장의 car-free·수변 복합·문화관광 허브 어휘가 전략 문장에 되풀이된다) → R.p57 해법 3가지(필지 분할·주동 단위 매각·마중물 + REITs) + 개략공사비·사업비 표(단가 × 면적 = 공사비로 재현) → R.p58 가정·결과·민감도·재원·투자·현금흐름(J-커브)·분양 스케줄·손익·재무상태. 모든 표가 백만원 단위의 한 체계로 닫혀서 "검증 가능성"으로 신뢰를 만든다. 요컨대 **PT는 질적 도식, 보고서는 정량 체인**으로 분업한다.
- 3장의 틀은 회색 바탕(#E6E6E6) + 진회색 배너 좌우 2단 + 청색 소제목, 사진 0장이다. 디자인 장(1–2장)의 인상 기반 설득과 완전히 다른 "모델 기반 설득"임을 바탕색으로 알린다.

### 층 D. 인지 부하 관리

**D1. 어휘 고정과 변주** — R.p4 4키워드가 R.p6–7 단 제목, R.p8 6목표 배지, R.p9 흐름도(Sustainability → Regeneration / Connectivity / Placemaking → Cultural + Tourism Hub)와 Live / Work / Play / Move 4테마로 네 번 변주되어 머리에 새겨지고, 이후 챕터 구성(Placemaking 4쪽)과 PT 띠 라벨이 같은 어휘를 쓴다.

**D2. 의미 색 + 번호 일치** — 구역 4색(Work 보라·Play 청·Live 노랑·Move 회색)이 사진 행·미니맵·평면 지시선·PT 띠에서 같다. 지도의 번호 배지 색 = 하단 썸네일 배지 색(R.p26 녹/파 루프)이라 "지도 ↔ 사진"이 1초에 연결된다. 조감의 번호·색은 범례색과 일치한다(S.35).

**D3. 밀도 리듬** — 여백 → 이미지 → 고밀도 텍스트 → 도식 → 무텍스트. 영문 약 500단어의 R.p6–7은 균일한 사진 슬롯과 4단 고정 그리드로 상쇄하고 바로 뒤에 도식(R.p8–9)·무텍스트 장 구분(R.p10–11)이 온다. "고밀도 쪽 바로 뒤에는 반드시 이미지 쪽"이 규칙이다.

**D4. 정보 위계** — 영문 제목이 주장, 국문 제목은 6–15자 명사형 주제어 라벨(예 "Regeneration of a Local Anchor" → "폐조선소의 재생")로 심사위원이 훑어보는 용도. 본문은 '굵은 한 줄 소제목 → 평서문 → 불릿'이라 소제목만 읽어도 흐름이 선다. 도면 라벨은 영문 단독이다.

**D5. 3층 번호 구조 (S.35 / R.p32–33)** — ① 조감도의 번호 배지가 "어디" ② 하단 같은 번호의 원형 사진·캡션이 "무엇"(Anchor Type: Cultural / Leisure / Institutional / Creative Industry / Commercial) ③ 번호 없는 지시선 문구 10개가 "어떤 가치". 가치 문구는 비전 6원칙을 공간 속성으로 번역한 것으로 보인다(추정): "Carbon neutral buildings via joint city-client commitment, solar rooftop PVs and battery storage", "Integrated green and blue (33%)", "Improved air quality due to car-free environment" 등.

**D6. 같은 그림의 재등장** — 요약 슬라이드(S.33 프로토타입 3종)의 그림이 상세 챕터(S.41 WORK, S.51 LIVE)에서 확대 재사용되고 빌드 시리즈(S.43 → 44 → 45)는 같은 레이아웃에 정보를 하나씩 더한다. 일관성이 곧 규칙 기반 설계라는 인상을 준다.

### 층 E. 마무리

**E0. 보고서의 닫힘 — 정서 클라이맥스 뒤에 낙차를 두고, 끝은 닫지 않는다**
- R.p52 "A Legacy Project": 영문 2단 + 국문 2단 본문(영문 약 330단어, 경어체 선언형), 좌하 흑백 "Before : The Existing Conditions"(약 6%), 우측 전 높이 컬러 조감 스트립(약 33%). 단락마다 앞 장의 키워드(car free, 저에너지, 도시농업, 연결성, 이동성)를 한 번씩 재호명해 보고서 전체를 회수하고, 마지막 문단은 "대형 조선업이 떠났으므로 사람을 다시 불러야 한다"로 끝난다. 정량 근거는 0이다.
- R.p53: 쪽 전체 풀블리드 조감 1컷 + 우상단 흰 굵은 한 줄 "Proposed Regeneration of the Waterfront"(바다의 빈 영역에 그림자와 함께). 보존 크레인이 아치 보행교·야외 무대·관중 광장을 감싸는 **프레임**이고, 분홍 벚나무 링이 시선을 모으며, 하단·우측 가장자리에는 실제 기존 시가지 항공사진이 합성되어 "현실 도시에 이식된 계획" 인상을 준다. PT S.89가 이 컷을 다시 쓴다.
- 이후 R.p54–55가 색을 모두 뺀 회색 구분 쪽으로 의도적으로 낙차를 만들고 3장(숫자 3쪽)이 이어진다. **R.p59는 백지로 끝난다** — 마지막 인상은 재무상태표(2022 열 전부 0)이고 닫는 문장·크레딧·팀·감사 표시가 없다(노트 해석: 홀수 쪽 마무리 때문에 남은 백지로 읽힘, 추정). 3장에는 운영 주체·준공 후 관리도 없다.
- 가져갈 것: 에필로그 = 본문 + Before 소사진 + 컬러 스트립 → 풀블리드 1컷 + 한 줄 제목. 단 사업성 장을 마지막에 두면 마지막 인상이 숫자가 되므로 (a) 사업·운영 장을 에필로그 앞에 두거나 (b) 사업성 장 뒤에 한 문장 결론 + 대표 조감 1컷의 닫는 쪽을 따로 둔다. 운영 조직·재원은 사업성 장의 마지막 소절에 쓴다. 에필로그 문장에 성과지표(방문객·체류시간 / 거주인구·생활업종·야간활동)를 최소 한 문장 병기한다.

**공통 문법 규칙(여러 도해에서 반복된 것)**
1. 베이스는 저채도로 눌러 두고 대상지만 컬러(장마다 대상지 표시색은 하나).
2. 화살표는 머리가 크고 꼬리가 투명하다.
3. 아이콘은 원형 칩 + 흰 픽토, 사진은 원형 크롭.
4. 범례는 같은 장 안에 둔다. 용도는 직접 라벨, 범례는 2차 속성에만.
5. 번호는 지도 ↔ 사진 ↔ 캡션이 일치한다. 번호가 없는 문구(가치 콜아웃)는 서로 독립이라는 신호다.
6. 단계·빌드는 프레임당 정보 하나(색 하나, 컨트롤 하나)를 더한다.
7. 확대 원(줌 인셋)은 아이디어당 하나로 제한한다.
8. 같은 도해는 요약에서 상세로 재사용한다.
9. **약점**: 색 의미가 장마다 바뀌는 곳이 있다(S.24 주황 = 동력, S.25 주황 = 교통약자 공유 가로, S.28 노랑 = 보행). 방위·축척은 일부 도면에만 있다. 도넛의 기준이 표기되지 않았다(R.p29). R.p29 도넛의 Leisure는 녹색인데 R.p28 범례의 Leisure는 청록이다.

## 11. 구경주역 이식 골격 초안 (제안 — 제출 요강 확정 후 조정)

이 절은 추출 결과를 이 저장소의 사실(`CLAUDE.md`)에 대응시킨 **초안**이다. 이번 마감이 구경주역 건이라는 가정이며, 쪽수·판형·익명 여부·평가 항목은 제출 요강을 받아야 확정된다. 슬로건·존치 고정점·비교 대상 같은 선택은 사용자가 정한다.

### 11.1 보고서 골격

| 구획 | 레퍼런스 비율 | 기능 | 구경주역 대응 후보 |
|---|---|---|---|
| 앞부분 · 서문 | 15% | 정렬, 첫인상, 과업 재진술, 정책 위계 | 첫 문장 = 발주 취지(T1: 혁신지구 공모 지침, 2026.01 MOU, 폐철도 기본구상) → After 조감 1컷(고정점 후보 + 광장 + 인접 원도심 연속) → 요약(키워드 4–5) → 평가 항목 재진술 + 열린 질문 → 규제 4겹 위계 |
| 1장 현황·진단 | 20% | 문제(?) → 잠재력(!) → 상위계획 → 배치도·면적표 → 전략 | 부지(79,438㎡, 폐역 2021.12)와 폐선축 80.3km·17개소를 S1·S3로 분리 / 쇠퇴진단·인구감소관심지역(원문 치환 후) / 방문객과 거주인구 이원 지표 / 결정도 공고(참고안, 해칭) vs 제안(채색) / **면적표 합계 = 79,438㎡ 검산** |
| 2장 계획 | 54% | 설계 방향 → 연결 → 프로그램 → 가로·프로토타입 → 앵커 → 구역별 장면 → 생태·지반 → 인접 지구 상생 → 에필로그 | 슬로건 → 폐선축 연결(최소 통과 폭) → 프로그램(주거 부재 보완, 야간 활동) → 존치 역사·매장문화재 제약의 규칙화 → 1단계 연결·기반·보행의 단계 시퀀스(색 하나씩 추가) → 대안 A–E와 분산 삽입형 → 에필로그 |
| 3장 실현 | 10% | 사업 구조·재원·사업성 | 재원 구조(국비·시·철도공단, T1–T2 확인 후) / 운영 주체와 재원(교훈 9) / 단계별 순서 / 조정 내역 추적표 / 실패 사례 alternatives |

문서 단위는 **2쪽 펼침**(왼쪽 제목·본문·소도해, 오른쪽 대형 이미지)을 기본형으로 하고, 장 구분은 지역 모티프 한 가지 + 대형 숫자 + 장명으로 처리한다.

### 11.3 이 추출에서 바로 쓸 수 있는 것

- §6의 층 A–E를 "각 장이 맡을 설득 임무" 체크리스트로 쓴다.
- §8 카탈로그에서 장면별 도해 문법을 고르고(예: 연결 = M1·M2·M3·M7, 프로그램 = M8·M9·M10·M12, 단계 = M17, 대안 = M20의 A/B 대구, 시연 = M21) §9의 규격으로 틀을 만든다.
- 쪽별 노트의 "재사용 포인트" 줄이 쪽 단위 이식 메모다.

## 12. 한계와 확인 필요 사항

- 제작 주체·당선 여부·발표자 노트·시간 배분은 자료에 없다. 89장 규모라 장당 체류 시간은 짧았을 것으로 추정한다.
- 이미지·쪽 판독은 렌더링 이미지(보고서 약 1548×1095px, PT 약 1536×864px)와 확대 크롭 기준이다. 노트의 "(추정)"과 "(판독불가)"는 이 문서에도 그대로 적용된다. 예: 보고서 p.1 빈 칸의 용도, p.9의 5색 점 의미, S.12 화살표 방향의 의도, S.4 인포그래픽의 출처, S.82의 선택 윤곽선이 어떤 소프트웨어 표시인지.
- 보고서 본문은 래스터라 문장 단위로 대조하지 않았다. 정확한 문장이 필요하면 해당 쪽 이미지를 다시 봐야 한다.
- 색 코드는 임베디드 서체 정보와 렌더 픽셀 샘플링 값이어서 ±몇 단계 오차가 있다.
- 쪽별 노트의 "발표 설득 기능" 중 발화 문장은 모두 (추정)이다.
- 이 레퍼런스는 2018년 한국 국제공모 응모안이다. 구경주역은 규제 4겹·매장문화재·고도 지구 등 레퍼런스에 없는 제약이 있어 계획 내용이 아니라 **구조·설득 문법**만 이식한다.
