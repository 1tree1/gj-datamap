1. **구 역사 위치.** (2026-10-15 사용자 결정: 계획 모델 배치 유지) 계획 모델(사용자 최종 3dm)의 구 경주역사(1,403㎡, 88.7 × 24.1 m)는 실제 위치에서 남쪽으로 약 63 m 옮겨지고 33.8° 돌아가 있다. 실제 위치는 콘타 모델 '빌딩'(지적 정합, `ctx_fixed.pkl`)의 같은 크기 동(로컬 x 146–170, y 283–372)이다. 실제 역사는 화랑로 축(y≈342) 위에 있어, 중간마감안의 20 m 동서 도로는 실제 역사와 388㎡ 겹친다. 이전 세션에서 배경을 사용자 역사 복사본에 맞춰 34° 돌렸던 일(`project_masterplan_rough_v1_state`)과 같은 각도라, 의도한 이전이 아니라 정합 오류의 잔재일 가능성이 높다. 다이어그램은 계획 모델 배치를 그대로 두고 실제 위치를 붉은 점선으로 겹쳐 그렸다.

3. 획지 8(레지던시)은 이미 순획지 0.56이라 동측 목표(0.55)보다 높아 그대로 두었다.
