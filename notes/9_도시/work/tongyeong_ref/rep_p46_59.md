### p.47 (인쇄 41) — Creation of a City that Passively Absorbs, Clean, + Reuses Rain | 친환경 계획
- 유형: CONCEPT-DIAGRAM, SECTION-ELEV, PRECEDENT(원형 사진), (식재 팔레트 카드 그리드)
- 챕터·역할: 2. Masterplan : Landscape Design(펼침 오른쪽, 부제 "Urban Ecology + Sponge City Strategies"). 왼쪽 p.46의 4원 중 Sponge City·Phytoremediation을 기술(수치·종) 수준으로 증빙 — 선언 → 메커니즘 → 식재 구체화의 3단.
- 레이아웃: 좌 x 6–16%, y 15–47%: 원형 사진 3장 세로(Green Rooftops / Green Walls / Bio Swales) / 중앙 x 24–57%, y 13–65%: 회색 점선 대원(지름 약 33%W) 안 블록 아이소 단면(지상 매스 + 지하 보어 층) 제목 "Distributed Storm Water Management" / 우 상단 x 63–95%: 원형 사진 3장이 오른쪽으로 갈수록 높이 올라가는 계단식, 각 사진에서 계단식 점선 지시선이 하단 우측 식재 단면 스케치(x 59–95%, y 62–92%)로 내려옴 / 좌하 x 4.7–57%, y 72–92%: "Indicative Planting Palette" 사진 카드 2행×7 + 대형 동백 1장. 푸터 + 쪽번호 41. 이미지 약 85% : 텍스트 약 7% : 여백 8%. 색: 연녹 원 테두리 + 갈색(주황) 화살 + 점선 회색.
- 시각자료 인벤토리: 1. 아이소 블록 단면(Distributed Storm Water Management) — 지붕 녹화 3개 동, 중정 수목, 하부 투수 포장·보어 층(점무늬·청록 층) — 약 20% — 수채풍 + 갈색 유수 경로선, 구름·새, 사람 점경. 2. 원형 사진 6장(Green Rooftops / Green Walls / Bio Swales / Reduction of Ultra Violet Radiation(가로수 보행) / Healthy Environment Sports + Stress Reduction(요가) / Phytoremediation by Plants(습지 초본)) — 약 17% — 해외 스톡형 실사, 고채도. 3. 식재 단면 스케치(수목·뿌리·새·사람 실루엣) — 약 15% — 크림 배경, 수채풍, 뿌리 노출. 4. 식재 팔레트 15종 — 각 라틴 학명만 캡션: Acer Tegmuntosum / Albizia Kalkora / Alnus Japonica / Broussonetia Papyrifiera / Carpinus Cordata / Castanea Crenata / Fraxinus Chinensis // Fraxinus Bungeana / Ostrya Japonica / Quercus Serrata / Quercus Myrsinifolia / Tilia Amurensis / Ulmus Davidiana / Zelkova Serrata / Camellia Japonica(대형 1장) — 약 18% — 수목 전체 수형 사진, 위치·수량·크기 표기 없음.
- 다이어그램 해부: 아이소 단면 = 물의 경로를 갈색 선·화살로 추적(옥상 → 외벽 → 지하 투수층 → 지반 침투) + 큰 갈색 화살(경성 인프라 용량 감소) + 점선 화살(순환). 라벨 4개 소글씨(회색): Green Roofs Retention Capacity 40L/㎡, Vegetation can increase 60x times Water Infiltration, Reduction of Hard Infrastructure Capacity, Bioretention Facilities·Ecological Complexity — 수치 2개 있으나 출처 표기 없음(검증 불가). 우측: 원형 사진 → 점선 지시선 → 단면 속 해당 위치(기능 문구: Absorption of Pollutants · Temperature Regulation / Noise Buffer · Wind Breaks · Shading Effect · Natural Cooling / Evapotranspiration · Infiltration). 위계 = 대원 중앙 아이소 > 우측 단면 > 사진 > 팔레트(가장자리). 방위·스케일 없음.
- 텍스트: 헤드라인 "Creation of a City that Passively Absorbs, Clean, + Reuses Rain | 친환경 계획", 부제 "Urban Ecology + Sponge City Strategies". 국문은 헤드라인 옆 "친환경 계획"뿐(본문 국문 없음). 캡션은 명사구형 영문. 선언 문장 없음 — 라벨·수치만.
- 설득 기능: "정말 작동하는가 / 어떤 식물이 되는가" 질문에 기술 근거 제시. 논리형 80 : 정서형 20. 학명 15종으로 '현지 식생을 검토했다'는 전문성 신호(추정).
- 앞뒤 연결: p.46의 4원(Sponge City + Restore the Habitat)을 우측에서 확대 → 다음 p.48–51(뉴딜구역)로 조경 원리에서 사회·상생 프로그램으로 전환.
- 재사용 포인트: ① '대원 안 블록 아이소 단면 + 라벨 4' = 하나의 메커니즘을 한 그림으로 설명하는 규격. ② 사진 → 점선 지시선 → 단면 위치로 효과를 위치에 매핑(원형 사진 + 계단식 점선). ③ 식재 팔레트는 학명 + 사진 카드 격자(2×7)로 압축 — 구경주역에서는 경주 지역 식생·고도지구 규정 수종과 대조하고 학명 + 국명 병기, 수치(40L/㎡, 60배)에는 T1–T2 출처를 반드시 붙일 것(여기서는 출처 없음).
