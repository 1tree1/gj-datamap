### s.31 — Design Area: Land Use (토지이용계획)
- 유형: MAP-ANALYSIS (토지이용 계획도, 대상지 + 주변 맥락) / MASTERPLAN(필지 단위 프로그램 평면)
- 섹션·역할: REGENERATION / 초록 세로띠(#70C232) / 마스터플랜 구간의 첫 장 — "계획이 놓이는 구역과 이미 정해진 공공·정부 사업의 위치"를 지도 한 장으로 확정하는 도입 슬라이드(현황 + 제안의 접점).
- 레이아웃: 좌측 초록 세로띠(흰 세로 라벨 "REGENERATION"). 제목 좌상단 굵게 "Design Area:  Land Use", 우상단 굵은 한글 "토지이용계획". 지도가 제목띠 바로 아래(y 6%)부터 약 94%까지 우측 끝까지 풀폭(세로띠 이후 전체). 하단 6%는 흰 여백. 이미지:텍스트 ≈ 98:2. 색: 회색 베이스맵 + 연청 바다 + 파랑 외곽선 + 필지별 색(노랑/연두/청록/주황/황갈).
- 시각자료 인벤토리:
  1. 평면 지도(약 94% 면적) — 베이스맵은 회색 선·흰 건물 윤곽(기존 시가지와 등고선, 옅은 톤)로 눌러 놓고, 바다는 옅은 청색, 제안 구역(Shina SB Yard)만 필지별 색으로 채색 — 평면 정사영, 주간, 채도: 베이스 낮음 / 제안 구역 중간~높음 — 인물·식생 표현 없음(식생은 녹색 면으로 추상화).
  2. 대상지 외곽선 — 두꺼운 남색 실선으로 부지 경계(콜아웃 박스 "Shina SB Yard"), 좌측에 남색 점선 다각형으로 "URBAN REGENERATION AREA"(뉴딜 구역) 별도 표시.
  3. 필지 라벨 — 대문자 라벨이 필지 방향을 따라 회전해 부지 위에 직접 기입(예: ACADEMY, MEDIATHEQUE, CENTRAL PARK / DEVELOPMENT BUSINESS, CREATIVE INDUSTRY PROTOTYPE, OCEAN LAB INCUBATOR, RESIDENTIAL, TOWNHOUSE, APARTMENT, RETAIL, RESTAURANT RETAIL, STARTUP CAMPUS, LEISURE, FACILITY, SPORTS FACILITY, WATERSIDE PARK, CANAL WAY, WATERFRONT REORGANIZE BUSINESS).
  4. 범례 + 축척 + 북방위 — 바다 위 우하단(x 76~95%, y 76~82%)에 작게(범례 2종: 청록 칩 "Public Project" / 주황 칩 "Initiative Government Project (Tentative)"), 축척 막대 0·50·100·200·300M, 북방위(N, 원형 십자).
- 다이어그램 해부: 이 지도는 "고정"과 "제안"을 색으로 가른다. 해칭(빗금) 면 = 이미 정해진 사업(확대 확인): 청록 사선 해칭 = Public Project — 부지 북동 해안을 따라 도는 띠 "WATERFRONT REORGANIZE BUSINESS"와 부두 돌출부, 중앙 타원 "CENTRAL PARK DEVELOPMENT BUSINESS"(타원 자체는 선명한 녹색 + 둘레에 청록 해칭 후광), 그리고 부지 밖 북서쪽의 넓은 부두·안벽 면(라벨 없음, 뉴딜구역 경계 바로 위). 주황 사선 해칭 = Initiative Government Project (Tentative) — ACADEMY, MEDIATHEQUE, SPORTS FACILITY, CREATIVE INDUSTRY PROTOTYPE 4개 필지(주황 바탕 위 가는 사선, 둘레에 청록 후광이 있는 곳도 있음). 해칭 없는 채색 면 = 제안 필지: 노랑 = 창조산업(CREATIVE INDUSTRY; 원문 철자 "CREATIV INDUSTRY"도 병존), 연두 = 주거 계열(RESIDENTIAL / TOWNHOUSE / APARTMENT), 청록 = 상업·창업(RETAIL / RESTAURANT RETAIL / STARTUP CAMPUS), 회청록 = OCEAN LAB INCUBATOR, 황갈 = LEISURE·FACILITY, 선명한 녹색 = 공원·오픈스페이스(삼각 녹지 포함), 연청 띠 = CANAL WAY(대각선 운하), 연두 띠 = WATERSIDE PARK(서측 가장자리). 번호 체계는 없고, 필지 위 직접 라벨이 번호 역할을 대신한다(이 슬라이드에는 숫자 앵커 없음 — 숫자 앵커는 s.32, s.35에서 등장). 정보 위계: 부지(채색)가 도면 중심 1순위, 해칭된 고정 사업 2순위, 주변 맥락은 회색 배경. 읽는 순서: 제목 → "Shina SB Yard" 콜아웃 → 중앙의 CENTRAL PARK 타원 → 좌우 필지 → 우하단 범례. 스케일·방위: 있음(우하단). 도면 위 텍스트 양: 많음(라벨 약 25개, 약 9~12px).
- 텍스트: 제목 "Design Area:  Land Use" / "토지이용계획". 범례 "Public Project", "Initiative Government Project (Tentative)". 지도 라벨은 영문 대문자만(한글 없음). 글자 수: 도면 라벨 위주로 중간. 톤: 명사(프로그램명)만.
- 발표 설득 기능: "공모 과제에서 이미 주어진 공공사업은 존중하고, 나머지를 제안한다"는 태도를 지도 한 장으로 증명. 이어지는 s.32(Live-Work-Play-Move 총괄 마스터플랜)가 이 필지 구성을 입체로 보여준다. 발표자 한 문장(추정): "해칭된 부분은 시가 이미 정한 사업이고, 색이 칠한 부분이 우리가 제안하는 토지이용입니다." [보고서 대조 확인] 같은 지도가 보고서 p.21(인쇄 17, 오른쪽 면)에 이미 있다. 보고서 p.20–21은 "Overview : Land Use + Circulation | Regeneration Strategy | 도시재생 전략" 한 개의 펼침면(spread)이고, 오른쪽 면의 토지이용도(필지 라벨·해칭·범례·축척·방위가 PT와 동일)를 PT가 전면 지도로 키웠다. PT에서 달라진 것: (a) 범례의 오탈자 정정(보고서 "Pubilc Project / Initiative Goverment Project (Tentative)" → PT "Public Project / Initiative Government Project (Tentative)"), (b) 보고서 지도 위쪽의 "Inhabitant Requirements"(HOME-SCHOOL-JOB MATCHING… 순환 노선 도식 + SENIOR/YOUTH/KIDS 요구 3줄)와 하단의 10개 전략 원형(Ocean Lab Networks, Mixed Use, City for Pedestrian, Canal Road, Courtyard Blocks, Waterfront for Citizen, Floating Playground, Chicanes, District Unit for Guidelines, Urban Memory) 삭제, (c) 베이스맵을 PT 쪽이 조금 더 옅게 처리한 것으로 보임(추정). 즉 보고서에서는 "토지이용도 + 전략 10개"였던 것이 PT에서는 "토지이용도 단독"이다.
- 앞뒤 연결: s.30(Proposal for 과업 2) → s.31(대상지와 토지이용) → s.32(입체 마스터플랜 + Live-Work-Play-Move). 묶음 시작(s.31~36 = 마스터플랜 총괄 묶음).
- 재사용 포인트: 베이스맵은 회색으로 낮추고 제안 구역만 색으로 채우는 평면 지도 문법. 고정 사업(해칭)과 제안(채색)을 범례 2개로 구분. 필지 라벨을 도면 위에 직접 기입(번호 없이). 구경주역: 이미 결정된 결정도 공고(근린공원·상업·공공청사·문화·주차)는 해칭으로 구분하고, 100% 변경 가능하다는 프로젝트 원칙에 맞게 "참고안(해칭)" vs "제안(채색)"을 가를 수 있음.

### s.32 — Holistic Development:  Live, Work, Play, Move (전체 도시계획 방향)
- 유형: MASTERPLAN(아이소메트릭 매스 플랜) + PROGRAM-DIAGRAM(이벤트 10개 번호 목록) + CONTEXT-PHOTO(4색 사진 스트립) / ICON-SYSTEM(번호 배지)
- 섹션·역할: PLACEMAKING / 초록 세로띠 / 전체 마스터플랜의 "개념 총괄" — Live·Work·Play·Move 4개 구동축을 한 장에 묶고, 각 축이 부지의 어디에 어떤 이벤트·활동으로 구현되는지 번호로 핀 꽂는 핵심 슬라이드.
- 레이아웃: 좌측 초록 세로띠("PLACEMAKING"). 제목 좌상단 굵게 "Holistic Development:  Live, Work, Play, Move", 한글 우상단 굵게 "전체 도시계획 방향". 3단 구성 — 좌 15% = 이벤트 10개 세로 리스트(원형 사진 + 파란 번호 배지 + 소제목 + 설명), 중앙 50% = 아이소메트릭 마스터플랜(풀 높이), 우 28% = 상단 미니 키맵 + 하단 4개 사진 스트립(각 3장). 도식/사진:텍스트 ≈ 70:30(좌 리스트가 텍스트 집중). 색: 마스터플랜 9색(범례), 사진 스트립 헤더 4색(보라/하늘색/노랑/회색).
- 시각자료 인벤토리:
  1. 아이소메트릭 마스터플랜(중앙) — 베이(연청)와 구릉 지형(연두회색·등고선)을 배경으로, 서측(Work) 적색·보라 소형 블록 군집, 중앙 타원형 광장(Play) 주변의 청색(문화·교육)·청록(레저)·황색 블록, 남동측(Live) 황색 중정형 주거 블록, 곳곳에 녹색 쐐기·띠(녹지), 북동~남서 대각선 운하(연청 띠), 북쪽으로 길게 뻗은 부두와 케이블카 선(가는 이중선) — 풀 높이 약 85% — 매스 단색 채색(그림자 약함), 시점 약 40° 조감, 인물 없음, 채도 중~높음, 식생은 녹색 면.
  2. 번호 배지(파란 원, 흰 숫자) — 마스터플랜 위 핀 12개: 1(북쪽 부두 끝, 동쪽 부두) / 2(남동 녹지 섬) / 3(서측 중앙, 동측 중앙) / 4(중앙 좌) / 5(중앙) / 6·7(타원 광장) / 8(광장 옆 렌즈형 수공간) / 9(동쪽 원형 수공간) / 10(운하 위). 1과 3은 같은 이벤트가 두 곳에 배치(번호 중복).
  3. 이벤트 리스트 10개(좌) — 원형 사진 + 번호 배지 + 소제목 + 3~5줄 설명 — 지름 약 6%, 사진은 주·야간 혼합, 채도 높음.
  4. 범례 박스(바다 위, 마스터플랜 우상단) — 9색.
  5. 미니 키맵(우상단) — 대상지 윤곽에 Work(보라, 서)·Play(파랑, 중앙, 흰 하트 아이콘)·Live(노랑, 남동) 3개 존을 칠함, 점선 적갈색 = 대상지 경계, 검정선 = 기존 부두·해안선.
  6. 사진 스트립 4줄(우하단) — WORK(보라 헤더) 3장: 노란 컨테이너형 라운지, 코워킹 라운지, 개발자 작업실 / PLAY(청색 헤더) 3장: 계단형 수변 목욕장과 등대(추정: 해외 사례), 분수 놀이터, 거울 캐노피 광장(추정: 해외 사례) / LIVE(노랑 헤더) 3장: 마리나 주거, 야간 수변 보행로와 고층 주거, 주방 인테리어 / MOVE(회색 헤더) 3장: 공유 자전거, 연안 여객선(수상택시 추정), 녹색 충전 캐노피의 소형 전기차(번호 1·2·3 회색 배지).
- 다이어그램 해부: 읽는 순서는 제목 → 미니 키맵(구역 3분할) → 마스터플랜(구체 배치) → 번호 배지(이벤트가 어디서 일어나는가) ↔ 좌측 리스트(1~10) → 우측 사진 스트립(분위기). 색 코딩 2벌: ① 마스터플랜 범례(9종) — Culture / Education / Civic(청색), Commercial / Offices / Office-tel(적색), Creative Industries(보라), Leisure / Entertainment / Recreation(청록), Residential(노랑), Retail / Food + Beverage(분홍), Hospitality(갈색), Transport(회색), Landscaped Open Space / Green Roof / Urban Agriculture(녹색). ② 구동축 4색 — WORK(보라), PLAY(청색), LIVE(노랑), MOVE(회색)로, 키맵·사진 스트립 헤더에서 동일하게 사용. 이 4색 중 WORK 보라와 LIVE 노랑이 이후 슬라이드의 세로띠 색(s.41~48 보라, s.50~51 노랑)으로 그대로 이어진다. 기호 규칙: 파란 원 번호 = 이벤트/프로그램 핀(원형 사진과 같은 번호), 검정 굵은 선 + 검정 점 = 존 → 사진 스트립 연결(Work/Play/Live 3개, MOVE는 연결선 없음), 회색 번호 배지 1·2·3 = MOVE 수단(자전거·수상·전기차). 정보 위계: 마스터플랜(1순위) > 번호 배지 > 이벤트 리스트 > 사진 스트립 > 범례. 방위·스케일 표기 없음. 도면 위 텍스트: 범례 외 텍스트 없음(이벤트 설명은 좌 열에 분리).

### s.33 — Urban Prototypes + Key Design Elements (도시 프로토타입 및 주요계획 요소)
- 유형: PROTOTYPE-AXO(아이소메트릭 프로토타입 3종 나란히) / CONCEPT-DIAGRAM
- 섹션·역할: PLACEMAKING / 초록 세로띠 / "마스터플랜의 문법" 제시 — 평면(s.31)과 총괄(s.32) 다음에, 도시를 이루는 반복 가능한 3종 프로토타입(Work·Live·Play)을 입체 도식 3장으로 보여주는 해법 슬라이드.
- 레이아웃: 좌측 초록 세로띠("PLACEMAKING"). 제목 좌상단 굵게 "Urban Prototypes + Key Design Elements", 한글 우상단 굵게 "도시 프로토타입 및 주요계획 요소". 본문은 가로 3분할(각 약 28% 폭, 패널 높이 약 50%, 상단 y 20%~71%)이고, 패널 아래에 굵은 캡션 1줄씩. 하단 약 23%는 의도적 여백. 도식:텍스트 ≈ 85:5(+ 여백 10). 색: 패널 1 = 적색·살구·연보라, 패널 2 = 노랑·연두·분홍, 패널 3 = 청록·청색·회색 광장.
- 시각자료 인벤토리:
  1. 패널 1 "Flexible Live-Work Space Prototypes" — s.41과 동일한 업무·주거 블록 아이소메트릭(굵은 외곽선 필지, 적색 아이콘 5개, 확대 원 2개) — 약 28% — 단색 면, 가는 윤곽선.
  2. 패널 2 "Residential Courtyards for Social Interaction" — 중정형 저층 주거 블록(옥상은 연두 녹화, 중간 노랑, 기단 분홍), 굵은 외곽선; 좌상단 확대 원 "From traditional Hanok to open blocks with courtyard housing"(한옥 평면 → 열린 중정 블록으로 이행, 회색 화살표); 우하단 확대 원: 한 동의 건물에 해·비·바람 아이콘과 옥상녹화 — 약 28% — 단색 면 + 점경 인물(작은 점), 수변 연청.
  3. 패널 3 "Central Public Space" — 타원형 광장(연회색 바닥 + 검정 점 군중), 중앙에 청록 골리앗 크레인, 광장 북단의 청색 말굽형(계단 극장 추정), 남단 청색 타원(수공간), 부두, 주변 청록(레저)·청색(문화) 블록(굵은 외곽선), 가로수 띠; 좌상단 원형 사진 1개(황혼의 옥상 레스토랑 식사 장면)와 크레인을 잇는 가는 지시선 — 약 28% — 단색 면, 점경 인물 수백 개로 밀도 표현.
- 다이어그램 해부: 3패널 모두 같은 시점(아이소메트릭 약 30°)·같은 선 굵기·같은 배경 문법(주변 맥락은 백색 매스·가는 선, 제안 필지는 굵은 검정 외곽선 + 색)을 써서 "같은 도시의 다른 부분"임을 보여줌. 색 코딩은 s.32 범례를 따름: 적색·보라 = 업무·창조산업(Work), 노랑·연두 = 주거(Live), 청록·청색 = 레저·문화(Play). 기호: 확대 원 = 메커니즘/전략 설명, 가는 지시선 + 흰 점 = 확대 대상 연결, 적색 원형 아이콘 = 업종 태그(패널 1만 사용). 읽는 순서: 좌 → 중 → 우(Work → Live → Play), 캡션이 각 패널 하단 중앙에 있음. 방위·스케일 표기 없음. 도면 위 텍스트: 확대 원 1개(한옥 → 중정) 외 없음.
- 텍스트: 영문 캡션 3개 — "Flexible Live-Work Space Prototypes" / "Residential Courtyards for Social Interaction" / "Central Public Space"(굵게 약 12pt, 중앙 정렬). 확대 원 내 영문 "From traditional Hanok to open blocks with courtyard housing". 한글은 우상단 부제만. 글자 수 극소.
- 발표 설득 기능: 마스터플랜이 임의의 형태 모음이 아니라 "3종 프로토타입의 반복"이라는 점을 시각 문법으로 보증(검증 가능한 규칙 기반 설계라는 인상). 발표자 한 문장(추정): "이 도시는 유연한 업무-주거 블록, 중정형 주거, 중앙 공공공간의 세 가지 프로토타입으로 만들어집니다." [보고서 대조 확인] 보고서 p.31(인쇄 25) "Urban Prototypes + Key Design Elements | 도시 프로토타입과 주요 계획 요소 / Mixed Use + Flexible Framework for Adaptability"의 3패널 그림을 그대로 가져왔다. 보고서에서는 패널마다 위에 소제목("Flexible Work Space Prototypes" / "Residential Courtyards for Social Interaction" / "Central Public Space"), 아래에 굵은 소제목 + 영문·한글 본문 단락("Modular Buildings" / "Courtyards + Green Rooftops" / "Central Plaza + Waterfront")이 있었는데, PT는 본문 단락을 전부 삭제하고 소제목 1개만 패널 아래에 남기며 첫 패널 이름을 "Flexible Live-Work Space Prototypes"로 바꿨다(보고서 "Work" → PT "Live-Work"). 그림 자체(굵은 외곽선 필지, 적색 아이콘 5개, 확대 원)는 보고서와 동일.
- 앞뒤 연결: s.32(4축 총괄) → s.33(3종 프로토타입 입체) → s.34(공간 네트워크)로 이어짐. 이후 WORK(s.41)와 LIVE(s.51) 챕터에서 패널 1·2가 각각 확대 재사용된다(같은 그림의 재등장). 묶음 중간.
- 재사용 포인트: 3패널 아이소메트릭 + 굵은 캡션 + 확대 원 1~2개 문법. 같은 그림을 요약(여기)과 상세 챕터(s.41, s.51)에서 반복 재사용해 슬라이드 일관성 확보. 구경주역: 폐선축을 따라 반복되는 프로토타입 3종(예: 역사 존치형 / 선형 보행·주거형 / 광장형)을 같은 문법으로 표현 가능. 하단 여백이 크므로 캡션 아래에 1문장 설명을 넣는 개선 여지.

### s.34 — A Network of Urban Spaces (도시공간 네트워크)
- 유형: CONCEPT-DIAGRAM(추상 노드-링크) + MAP-ANALYSIS(보행 네트워크 평면 다이어그램)
- 섹션·역할: PLACEMAKING / 초록 세로띠 / "중앙 광장을 정점으로 한 공간 위계"를 추상 구조 → 실제 부지 대응의 2단으로 증명하는 개념 슬라이드(보행 중심·차 없는 도시 논리의 공간 버전).
- 레이아웃: 좌측 초록 세로띠. 제목 좌상단 굵게 "A Network of Urban Spaces", 한글 우상단 굵게 "도시공간 네트워크". 본문 좌 45% = 추상 노드-링크 도식, 우 45% = 부지 평면 위 네트워크 다이어그램. 여백 넉넉(상단 22%, 하단 20% 비움). 도식:텍스트 ≈ 98:2. 색: 연두~올리브 녹색 단색 계열(왼쪽은 라임~진녹 5톤, 오른쪽은 올리브 단색) + 회색(차량 도로) + 적색 점선(대상지 경계) + 남색 선(기존 해안·부두).
- 시각자료 인벤토리:
  1. 추상 노드-링크 도식(좌) — 중앙 큰 둥근 사각형 "Primary Plaza"(올리브 녹색, 내부에 동심원 3겹과 흰 하트), 좌우로 뻗는 점선 화살표 가로선 3줄, 각 선 위에 크기가 다른 원 노드(작은 원 ≈ 소공간, 큰 원 ≈ 중요 공간; 안에 동심 고리) 좌 7개 + 우 6개 = 13개, 노드 사이를 잇는 세로 점선 양방향 화살표, 가로선 양끝은 화살촉(외부로 연결) — 약 40% 면적 — 단색 계열 그라데이션 5톤(연두 → 진한 올리브), 사람·식생 표현 없음.
  2. 네트워크 평면 다이어그램(우) — 대상지 윤곽을 적색 점선, 기존 부두·해안을 남색 선으로 그린 위에 올리브 녹색 보행망을 굵기별로 표시: 굵은 화살표 대축(북서~남동 장축, 북쪽 해안 축, 남서로 향하는 대각 축), 가는 선 세가로 격자, 중앙의 진한 타원 + 흰 하트(중앙 광장)와 바깥 타원 링, 녹색 원 속 흰 보행자 아이콘 8개(보행 결절점), 회색 굵은 선 = 대상지 밖 차량 도로(남쪽 해안도로)와 회색 원 속 흰 자동차 아이콘 2개(서·동 진입부, 회색 화살표로 외부 방향) — 약 45% 면적 — 평면, 단색, 스케일·방위 없음.
- 다이어그램 해부: (a) 좌측은 위계 구조도: 가운데 Primary Plaza가 정점, 좌우 가로 축(동서) 3줄이 중앙을 지나 양끝 화살표로 도시로 열려 있고, 노드는 크기로 중요도를 나타내며 세로 점선이 이웃 노드를 연결. 하트 아이콘은 중앙 광장의 상징이며 s.32 키맵의 PLAY 존 하트와 동일. (b) 우측은 같은 구조를 실제 부지에 투영: 굵은 화살표 3개 대축이 중앙 광장을 지나 도시·바다·북쪽 부두로 뻗고, 가는 선이 필지 내부 가로망을 이룸. 차량 도로는 부지 밖에만 있고 부지 내부에는 없음(차 없는 환경). 색 규칙: 녹색 = 보행 네트워크, 회색 = 차량, 적색 점선 = 계획 경계, 남색 = 기존 해안선. 선 굵기 = 위계(굵을수록 상위 축). 읽는 순서: 제목 → 좌측 추상 구조 → 우측 평면(같은 하트 아이콘으로 연결). 범례·스케일·방위 없음(기호가 자명하다는 전제). 도면 위 텍스트 극소("Primary Plaza"만).
- 텍스트: 제목 "A Network of Urban Spaces" / 한글 "도시공간 네트워크". 도식 라벨은 "Primary Plaza" 하나. 글자 수 극소.
- 발표 설득 기능: "광장이 도시의 심장이고, 보행 네트워크가 이를 중심으로 짜여 있다"를 추상 → 실제 평면의 2단 논리로 증명. 발표자 한 문장(추정): "모든 길은 중앙 광장으로 모이고, 차량은 외곽에서 멈춥니다." [보고서 대조 확인] 우측 평면 다이어그램은 보고서 p.30(인쇄 24) "Masterplan : Urban Planning Elements / The Urban Street as Public Space | 도시 가로 계획 / A People Centred Urban Environment"의 좌측 "Human Centred Design" 열 하단 도식("Towards a Permeable Urban Scheme": 초록 보행망 + 파란 차량 도로, 상단 라벨 "Fine Grid / Larger Grid / Largest Grid / Fine Grid")을 재채색(초록 → 올리브, 파랑 → 회색)해 확대한 것이다. 같은 열 상단의 "Domestic zone / Creative industry zone / Leisure zone" 도식, 중앙 열의 가로 단면(4m·3m 차량 폭), 우측 열의 "Existing Local Streets" 단면(13m·16m)과 본문은 PT에서 s.27~28(Respecting the City Grid / Designing in Context – Human Scale)과 s.29 쪽으로 나뉘어 이동한 것으로 보인다(해당 슬라이드는 이 구간 밖이라 미확인). 좌측의 "Primary Plaza" 추상 노드-링크 도식은 보고서 p.30에 없고 PT에서 새로 만든 것으로 보인다.
- 앞뒤 연결: s.33(3종 프로토타입) → s.34(그 프로토타입을 잇는 공간 네트워크) → s.35(Site Anchors, 번호 앵커 + 지속가능성). 묶음 중간.

### s.41 — Flexible Live-Work Space Prototype (유연한 주거-업무 복합시설 프로토타입)
- 유형: PROTOTYPE-AXO(아이소메트릭 프로토타입 다이어그램 + 아이콘 콜아웃) / ICON-SYSTEM
- 섹션·역할: WORK / 보라 세로띠(#6F2F9F) / "WORK 파트의 개념 정의" — 건물 한 동이 아니라 "수정 가능한 모듈 규칙"을 먼저 제시하는 프로토타입 소개.
- 레이아웃: 좌측 보라 세로띠("WORK"). 제목 좌상단 일반체(굵지 않음), 한글 우상단 굵게. 좌 40% = 불릿 4줄(큰 글씨 약 20pt, 여백 넉넉), 우 55% = 아이소메트릭 도식(우측 끝까지). 도식:텍스트 ≈ 60:40. 색: 적색·주황 살구·연보라·연청(물)·연초록(녹지).
- 시각자료 인벤토리:
  1. 아이소메트릭 블록 도식 — 지구 단위 블록(두꺼운 검정 외곽선으로 제안 필지 강조, 주변 기존 맥락은 가는 선·백색 매스), 수변과 수로는 연청, 보행·조경은 연초록 — 약 55% 면적 — 매스 색: 하층 연보라 + 상층 살구색, 일부 블록은 진한 적색(상층)/보라(저층); 시점 약 30°; 인물 없음; 채도 중간.
  2. 적색 테두리 원형 아이콘 5개(흰 바탕에 적색 픽토그램) — ① 컴퓨터 앞 사람 ② 원형으로 연결된 사람들 ③ 톱니바퀴+선박+렌치 ④ 바닷가재·생선+돋보기 ⑤ 바닷가재·생선 — 각 아이콘에서 가는 검정 지시선이 해당 블록 위 흰 점으로 연결.
  3. 확대 원 2개(검정 테두리 큰 원) — 우상단 원: 분해 스택 다이어그램(보라 슬래브 + 점선 확장 + "+" 적색 슬래브 + 적색 스택 위 녹색 큐브(옥상녹화)) = 수직 증축 모듈; 좌하단 원: 보라 줄무늬 창고(기존 쉐드)와 점선 볼륨, 적색 양방향 화살표 = 쉐드 확장·개방 + 주변 백색 매스.
- 다이어그램 해부: 읽는 순서는 불릿(규칙) → 우측 도식(적용) → 확대 원(모듈 메커니즘). 색 코딩: 적색 = 사무·업무 블록, 보라/연보라 = 창작·제조 저층(창조산업)으로 읽히나 공식 범례는 없음(추정). 기호 규칙: 원형 아이콘 = 활동/업종 태그(지시선 + 흰 점 앵커), 확대 원 = 메커니즘 설명, 적색 양방향 화살표 = 확장 가능 방향, "+" = 모듈 추가. 정보 위계: 외곽 굵은선 필지(1순위) > 아이콘(2) > 확대 원(3) > 주변 백색 매스(배경). 방위·스케일 표기 없음. 도면 위 텍스트 0(전부 아이콘으로 치환).
- 텍스트: 영문 불릿 4개 — "Modular buildings" / "Flexible for growth" / "A place where innovation happens naturally" / "An active zone that remains open beyond working hours + days to host a variety of uses." 한글 부제 "유연한 주거-업무 복합시설 프로토타입". 글자 수 적음. 톤: 명사구·선언형, 마침표는 마지막 항목에만.
- 발표 설득 기능: "프로토타입 = 모듈 + 확장 규칙 + 업종 태그"를 한 장에 보여 마스터플랜이 고정안이 아니라 성장 가능한 틀임을 설득. 발표자 한 문장(추정): "건물은 모듈로 짓고 층을 얹어 자라며, 일과 후에도 열린 구역으로 운영됩니다." 보고서 p.31(인쇄 25) "Urban Prototypes + Key Design Elements"의 Live-Work 프로토타입을 확장한 것(추정).
- 앞뒤 연결: s.40(Proposal for) → s.41(개념) → s.42(스케치로 사람의 하루) → s.43~45(기존 쉐드 전용 프로토타입) 로 이어지는 WORK 묶음 시작.
- 재사용 포인트: 아이소메트릭 블록 + 굵은 외곽선 필지 + 원형 아이콘 태그 + 확대 원 2개 문법. 프로그램 설명을 문장이 아니라 아이콘(활동 pictogram)과 모듈 분해도로 치환. 구경주역은 철도 부지 선형 블록 위에 같은 문법 적용 가능.

  2. 한옥 단면 도식 — 한옥 2동 단면(주황 처마/마루 선, 검정 지붕), 물가(좌), 산(우), 마당 중앙, 상승 기류 화살표 — 약 28% — 한글 대형 글자(처마/한옥/마루/마당/배산임수)와 영문 로마자 표기·설명이 함께 놓임.

- 다이어그램 해부: 정보 흐름이 "전통 원리 → 현대 번역"의 이중 단면 대응. 한옥 단면: 처마(Cheo-ma) → 여름 차양·겨울 일사 허용 / 마루(Ma-ru) → 들어 올린 목재 마루의 교차 환기 / 마당(Ma-dang) → 사회적 교류 마당과 상승 기류 / 배산임수(Bae-san-im-su) → 물을 향하고 산을 등지는 입지. 현대 단면: 같은 개념이 "Overhangs Provide Shading in Summer", "Cross Ventilation for Cooling", "Public realm for resting and meeting", "Views to the water"로 이어짐. 추가 환경 전략 라벨: "Raised Ground Floor to Protect from Flooding", "Residents bike storage", "Ground Depressed for Ground Water Storage", "Rainfall water stowed and used for irrigation and toilet flushing", "Photovoltaic Panels Provide Electrical Energy", "Smart Living", "Use of local materials and construction materials with high recycled content", "Improved air quality", "Mandatory waste management allocation within all buildings", "Geothermal GSAP". 기호 규칙: 눈 = 조망, 하늘색 곡선 화살표 = 바람, 연한 적색 상향 화살표 = 열기 배출, 점선 화살표 = 물 흐름, 주황 = 한옥 요소. 읽는 순서: 좌상(축측도) → 우상(한옥) → 하단(현대 단면 좌→우). 도면 위 텍스트 양: 많음(라벨 약 30개, 약 7~11pt 작은 글씨). 방위·스케일 없음.
- 텍스트: 제목 "Contemporary Lifestyle of Sustainable Living" / 한글 "한국형 수변 주거공간". 한옥 설명 영문 인용: 'Cheo-ma' "Overhangs to limit effects of wind. Provide shade in summer, and allow for sun penetration in winter." / 'Han-ok' "Traditional Korean house. Thoughtfully and carefully planned around the surroundings and regional seasons." / 'Ma-ru' "Raised wood-floor living area allowing for cross ventilation." / 'Ma-dang' "Courtyard for social interaction with rooms joined to the space. Ascending air current for cooling." / 'Bae-san-im-su' "Expresses the concept of an ideal location for a house facing the water for cooling and turning the back to a mountain to be protected from winter winds." 한글은 용어(처마·한옥·마루·마당·배산임수)만 대형 글씨로 병기. 글자 수 많음(영문 라벨 다수). 톤: 기능 중심 명사구.
- 발표 설득 기능: 주거가 외국 템플릿이 아니라 한국 전통 원리에서 나왔음을 입증하며(한국형), 동시에 에너지·물·폐기물 같은 지속가능성 항목을 한 장에 담음. 발표자 한 문장(추정): "한옥의 처마·마루·마당이 그대로 현대 수변 주거의 차양·환기·중정이 됩니다." 보고서 p.35(인쇄 29) "Contemporary Lifestyle of Sustainable Living | Creating the Best Place to Live | 한국형 수변 주거공간"을 한 장으로 압축.
- 앞뒤 연결: s.50(공감 스케치) → s.51(근거) → s.52(생태 인프라)로 "주거 단위 → 도시 전체 생태 인프라" 확장. 묶음 끝.
- 재사용 포인트: "전통 원리 한 줄 요약(한글 대형 + 로마자 + 영문 1문장) → 현대 단면에서 같은 원리가 어느 요소로 번역되는지" 이중 단면 문법. 구경주역은 한옥·신라 왕경의 도시 구조(방리제 등)를 현대 가로/필지 규칙으로 번역하는 슬라이드에 응용 가능. 단면의 라벨은 "기능 + 위치" 짝으로 쓰고, 아이콘으로 눈·바람·물·에너지를 구분.

### s.52 — Grow + Flow: Ecological Infrastructure as a Catalyst for Urban Renewal (생태기반 조경계획)
- 유형: CONCEPT-DIAGRAM + ICON-SYSTEM + AERIAL(조감 축측도)
- 섹션·역할: REGENERATION / 초록 세로띠 / 생태 인프라를 "5개 흐름 + 4개 전략"의 수식으로 압축한 SUSTAINABILITY 핵심 슬라이드(비전 s.17의 지속가능성 축을 공간화).
- 레이아웃: 좌측 초록 세로띠("REGENERATION"). 제목 좌상단 일반체(긴 제목, 폭 약 55%), 한글 우상단 굵게. 상단 약 60% = 조감 축측도(좌에서 우로 가득), 우상단에 범례 박스(흰 바탕 가는 테두리), 하단 약 36% = 원형 4개 + "+" 기호 3개 + 캡션. 도식:텍스트 ≈ 75:25. 색: 라인(검정 가는 선) 위에 흰 매스, 연두(녹지), 청록 해칭 화살표(수로·물 흐름), 5색 흐름(녹/황/주황/분홍/회).
- 시각자료 인벤토리:
  1. 조감 축측도 — 마스터플랜 전체를 가는 검정 선 + 흰 매스로 표현(주변 시가지는 선만, 계획 구역은 연두 녹지 띠가 선형으로 흐름), 수변 가장자리를 따라 금색 점선(수변 보행로/연안 띠), 청록 해칭 화살표(수로·물 흐름 방향 표시, 부지 안팎을 가로지름) — 약 50% — 선화 + 부분 채색, 시점 높은 조감(약 40°), 인물 없음.
  2. 원형 아이콘 기둥(롤리팝) 7개 — 흐름별 픽토그램 원형 3~5개를 수직으로 쌓고 점선(같은 색)으로 수변 지면의 작은 타원 마커까지 연결 — 약 15% — 색 원 + 흰 픽토그램.
  3. 범례 박스 — 5색 막대 + 흐름명 + 1~2줄 설명(아래 텍스트 참조).
  4. 하단 원형 도식 4개(초록 링, 지름 약 12%) — ① Sponge City: 층상 지반과 옥상녹화 매스의 컷어웨이 축측도(주황 하향 화살표 = 침투, 주황 곡선 화살표 = 순환) ② Softening the Edge: 수변 가장자리 유형 4가지 타일(2×2, 식재형·목재 데크형·계단형·모래사장형으로 보임) ③ Restore the Habitat: 새 떼, 수목, 습지초, 지반 단면의 수채 단면 스케치 ④ Supporting the Ecosystem: 뿌리까지 보이는 큰 나무와 순환 화살표(녹색), 복숭아색 곡선 면.
- 다이어그램 해부: 읽는 순서: 제목 → 축측도(흐름 아이콘을 찾으며 "무엇이 어디에서 일어나는가") → 범례(색 = 흐름) → 하단 수식(원 4개를 "+"로 합쳐 하나의 전략으로). 범례(5개 흐름): Green Flow(Active Sport + Wellbeing, 아이콘: 벤치에 앉은 사람·보행·자전거·점수판 "2 1 5"·지팡이 든 노인과 아이) / Yellow Flow(Events, 아이콘: 스마트폰·눈·Wi-Fi) / Orange Flow(Art + Education, 아이콘: 독서·톱니바퀴 머리·커피잔·송전탑형 랜드마크) / Pink Flow(Phytoremediation Terraces, 아이콘: 하트·새싹·나무·물방울) / Grey Flow(Smart Technology, 아이콘: 톱니바퀴 머리·사람들·보행·스마트폰). 같은 아이콘 세트가 부지의 여러 위치에 반복해 꽂힘(예: 녹색 세트 2곳 + 분홍 세트 2곳). 지시선 = 같은 색 점선(아이콘 → 수변 지점 마커). 청록 해칭 화살표 = 물(수로) 흐름 방향(시가지에서 만 쪽으로 향하는 것으로 보임, 추정), 금색 점선 = 수변 가장자리를 따르는 연속 띠(보행로로 추정, 범례에 없음). 하단 4원 = 4개 전략의 합이 상단 5개 흐름의 기반이 된다는 수식("Sponge City + Softening the Edge + Restore the Habitat + Supporting the Ecosystem"). 정보 위계: 축측도 > 아이콘 기둥 > 4원 > 범례. 방위·스케일 표기 없음. 하단 캡션 본문 크기가 서로 다름(3번째 캡션만 작음, 4번째가 큼).
- 텍스트: 제목 "Grow + Flow:  Ecological Infrastructure as a Catalyst for Urban Renewal" / 한글 "생태기반 조경계획". 범례 문구(원문): "Legend / Green Flow: Active Sport + Wellbeing — creation of outdoor sport facilities + recreational space, for healthy lifestyle / Yellow Flow: Events — main outdoor event space, view to waterfront + skyline + landscape / Orange Flow: Art + Education — pavilions for education + art exhibitions along the waterfront / Pink Flow: Phytoremediation Terraces — water + soil filtering by plants, planted at different terraces. / Grey Flow: Smart Technology — connection to the start-up neighbourhood, young neighbourhood + talent." 4원 캡션(원문): "Sponge City — A sponge city is designed to passively absorb, clean and reuse rainfall in an ecologically friendly way that reduces the speed and pollution of runoff in the city." / "Softening the Edge — Consider the waterfront as an ecosystem, improve its natural dynamics and reinforce its role in the city." / "Restore the Habitat — Naturally treat and remediate soil quality of the site. Phytoremediation strategies to be used." / "Supporting the Ecosystem — Creation of permeable features through the urban fabric. Creating an ecologically good place to be. Working with nature to come back stronger after disruptive natural events." 글자 수 중간~많음. 톤: 명사구 + 동사 원형 지시("Consider…", "Creation of…").
- 발표 설득 기능: "생태 = 부가 사업이 아니라 도시 재생의 촉매(Catalyst)"를 4개 전략의 수식으로 압축하고, 5색 흐름으로 프로그램(스포츠·이벤트·예술교육·정화·스마트)이 생태 띠에 얹히는 점을 보임. 발표자 한 문장(추정): "빗물을 흡수하고, 가장자리를 부드럽게 하고, 토양을 정화하고, 생태계를 지탱하는 네 가지가 모여 도시를 재생하는 촉매가 됩니다." 보고서 p.46(인쇄 40) "Grow + Flow: Ecological Infrastructure as a Catalyst for Urban Renewal | Resilient Landscape Strategies | 생태기반 조경계획"을 압축.
- 앞뒤 연결: s.51(주거 단면)에서 받은 물·바람 전략 → s.52(전체 도시 스케일 생태 인프라) → s.53(스펀지 시티 상세·식재 팔레트). 묶음 시작.
- 재사용 포인트: "N개 원형 전략 + 기호로 합산" 하단 줄 템플릿(원형 도식 4개와 "+" 3개) 문법, 상단에는 조감 축측도 위에 흐름별 색 아이콘 기둥을 꽂는 방식. 5색 흐름 범례는 박스 하나(색 막대 + 흐름명 + 1줄 설명). 구경주역: 철도 폐선축(80.3km)을 따라 흐르는 "녹지·역사·모빌리티" 흐름을 색으로 구분해 아이콘 기둥으로 표시 가능.

### s.53 — Creation of City that Passively Absorbs, Cleans, + Reuses Rain (친환경 계획) — Planting Palette
- 유형: CONCEPT-DIAGRAM + SECTION-ELEV + CONTEXT-PHOTO(식물 사진 타일) / TABLE(식재 팔레트)
- 섹션·역할: REGENERATION / 초록 세로띠 / s.52의 "Sponge City"를 상세 설계로 풀고 식재 팔레트까지 제시해 실행 가능성을 입증하는 상세 슬라이드.

  2. 중앙 컷어웨이 축측도(s.52 Sponge City 원형과 같은 그림, 확대·주석 추가) — 파란 점선 원 안에 구름·빗방울 + 옥상녹화된 건물 매스 + 층상 지반(식재층 → 모래층 → 청록 저류층) — 라벨: "Green Roofs Retention Capacity 40L/m²", "Vegetation can increase 60x times Water Infiltration", "Reduction of Hard Infrastructure Capacity"(주황 하향 화살표), "Bioretention Facilities Ecological Complexity", "Distributed Storm Water Management"(굵게).

  4. ### s.55 — New Deal Zone:  Establishing Mutual Benefit (뉴딜구역 : 도시 상생 방안)
- 유형: MAP-ANALYSIS(조감 축측도 위 이용자 동선) / CONCEPT-DIAGRAM
- 섹션·역할: REGENERATION / 초록 세로띠 / 뉴딜구역 4장 묶음의 첫 장 — "대상지가 주변 구도심과 어떻게 상생(mutual benefit)하는가"를 3개 이용자 집단의 동선과 녹지 축으로 제시하는 논지 슬라이드.
- 레이아웃: 좌측 초록 세로띠("REGENERATION"). 제목 좌상단 굵게 "New Deal Zone:  Establishing Mutual Benefit", 한글 우상단 굵게 "뉴딜구역 : 도시 상생 방안". 조감 축측도가 제목띠 아래부터 하단·우측 끝까지 풀블리드(약 94%), 범례는 우하단 바다·산지 위. 이미지:텍스트 ≈ 98:2. 색: 회색 맥락 + 분홍(수변공원) + 반투명 녹색 띠 + 3색 동선(주황·청·적) + 황색 도로.
- 시각자료 인벤토리:
  1. 조감 축측도(전면) — 베이스는 회색 매스(기존 시가지, 구릉, 해안), 제안 대상지는 청색 계열 건물(문화·교육)과 "STARTUP CAMPUS"(적색 블록), 해칭 타원 "CENTRAL PARK", 수변은 분홍 면 3곳(모두 "WATERFRONT PARK" 라벨), 남서쪽 하단에서 북동쪽 상단으로 가로지르는 넓은 반투명 녹색 띠(나무 + 점경 인물 실루엣, 구도심에서 대상지로 이어지는 녹지 축으로 읽힘) — 약 94% — 시점 높은 조감(약 45°), 인물은 검정 실루엣 소수, 채도: 맥락 낮음 / 강조(분홍·녹색·동선) 높음.
  2. 이용자 동선 선 — 주황 실선·점선 호(Inhabitants, 주민: 구도심 골목 → 녹지 축 → 대상지/수변, 점선 호는 수변으로 직접 향하는 장거리 연결), 청색 선(Long-term Guest, 장기 체류객: 업무·교육 건물과 수변 사이, 위쪽 점선 화살표는 바깥 도시 방향), 적색 선(Tourist, 관광객: 수변공원 부두와 대상지 중앙 공원) — 각 경로 끝에 흰 원 노드, 화살촉.
  3. 도로 — 황색(황토색) 굵은 선으로 광역 접근로, 선 위에 한글+영문 라벨 "지역 간선도로('도남-정량'대교 경유) / Arterial Access(Donam-Jeongriang Bridge)"(경로를 따라 회전).
  4. 범례(우하단) — 3종: 주황 화살표 "Inhabitants", 청색 화살표 "Long-term Guest", 적색 화살표 "Tourist".
- 다이어그램 해부: 3개 이용자 = 3색 선이 같은 지도에 겹쳐 그려지고, 공통 접점은 (1) 구도심에서 대상지로 올라가는 녹색 띠(녹지 축) (2) 수변공원 (3) 중앙공원으로 수렴. 읽는 순서: 제목 → 녹색 띠(축) → 3색 동선(누가 어디로 가는가) → 우하단 범례 → 황색 도로(차량 접근은 외곽에서 처리). 색 규칙: 주황 = 주민, 청 = 장기 체류객, 적 = 관광객(범례 3종), 분홍 = 수변공원, 반투명 녹색 = 녹지 축, 황색 = 간선도로. 기호: 흰 원 노드 = 동선 시작·종점, 점선 호 = 장거리 직결, 검정 실루엣 = 보행자. 정보 위계: 3색 동선 + 녹색 축 > 대상지 건물 > 회색 맥락. 스케일·방위 없음. 도면 위 텍스트: 라벨 6개 내외(소형).
- 텍스트: 제목 "New Deal Zone:  Establishing Mutual Benefit" / "뉴딜구역 : 도시 상생 방안". 도면 라벨: WATERFRONT PARK ×3, CENTRAL PARK, STARTUP CAMPUS, 간선도로 라벨(한글·영문), 범례 3줄. 글자 수 적음. 톤: 명사구.
- 발표 설득 기능: "상생"을 문장이 아니라 3집단(주민·장기 체류객·관광객)의 동선이 같은 녹지 축을 공유하는 지도로 증명. 발표자 한 문장(추정): "구도심 주민이 녹지 축을 따라 올라와 수변공원에 닿고, 관광객과 장기 체류객도 같은 길을 씁니다." 보고서 p.48(인쇄 42) "New Deal Zone: Establish a Mutual Benefit | Focus on fundamental problems | 도시재생 상생 방안"과 대응.
- 앞뒤 연결: s.54(Proposal for 뉴딜구역) → s.55(상생 개념도) → s.56(핵심 쟁점별 해법)으로 "큰 그림 → 문제별 해법" 순서. 묶음 시작(s.55~58 = 뉴딜구역 4장).
- 재사용 포인트: 베이스맵을 회색으로 낮추고 이용자 집단별 색 동선을 겹치는 조감 다이어그램. 집단은 3개로 제한(주민/장기 체류/관광), 범례는 화살표 3줄. 구경주역: 원도심 주민·관광객·야간 이용자(거주인구/방문객 이원 지표와 연결)의 3색 동선으로 응용 가능. 간선도로·차량 접근은 한글+영문 라벨로 도로 위에 직접 기입.

### s.56 — New Deal Zone:  Focus on the Fundamental Issues (뉴딜구역 : 주요쟁점의 해결방안 모색)
- 유형: PHASING(4단계 순서 다이어그램) + CONTEXT-PHOTO(흑백 항공사진 비교) / CONCEPT-DIAGRAM

  1. 흑백 항공사진 2장(맞붙임) — 좌: 고층 아파트 단지(판상형 고층 타워와 수목, 'tower-in-park'형 재개발), 우: 저층 고밀 주거지(좁은 골목과 주차된 차량, 이 뉴딜구역의 현황 조직으로 읽힘) — 약 35% — 탈채색 항공사진, 라벨 없음, 대비로 "고층 재개발 vs 저층 골목 주거지"를 암시(추정).

- 다이어그램 해부: 읽는 순서는 좌→우 4단계(우하단 4개 아이소 + 단면)와 좌하단 큰 아이소(이 4단계를 합친 완성 상태)를 대응. 단면 스트립의 논리: 단계 ①에서 지상의 차량 아이콘이 가로를 점유 → 단계 ②에서 차량을 청색 타워와 지하 영역으로 옮겨 가로를 비움 → 단계 ③에서 비워진 필지에 공원·놀이터 → 단계 ④에서 커뮤니티 시설과 도시 농장. 색 규칙: 황 = 가로·골목, 청 = 주차(타워·지하), 녹 = 오픈스페이스, 적 = 커뮤니티 건물, 흰 = 기존 주택(불변). 기호: 작은 자동차 아이콘 = 주차 대수의 위치, 검정 실루엣 = 보행자. 정보 위계: 우하단 4단계 순서 > 좌하단 완성 아이소 > 상단 사진(맥락). 스케일·방위 없음. 도면 위 텍스트: 캡션 4개 + 단면 라벨 6개(영문 소형).

### s.57 — New Deal Zone:  Character Zones (뉴딜구역 : 주요쟁점의 해결방안 모색)
- 유형: MAP-ANALYSIS(성격 구역 평면 계획도) / CONCEPT-DIAGRAM
- 섹션·역할: REGENERATION / 초록 세로띠 / 뉴딜구역을 "성격이 다른 구역들의 집합"으로 쪼개 해법의 공간 구성을 확정하는 슬라이드(앞 장의 쟁점 해결 순서를 면적 단위 계획으로 구체화).
- 레이아웃: 좌측 초록 세로띠. 제목 좌상단 굵게 "New Deal Zone:  Character Zones", 한글 우상단 굵게 "뉴딜구역 : 주요쟁점의 해결방안 모색"(s.56과 같은 한글 부제 재사용). 평면 지도가 제목띠 아래부터 하단·우측 끝까지 풀블리드(약 94%). 범례 박스·축척·방위 없음. 이미지:텍스트 ≈ 95:5(지도 위 라벨). 색: 회색 베이스맵 + 연청 바다 + 반투명 6색 구역(분홍·노랑·청·주황·장미·보라).
- 시각자료 인벤토리:
  1. 평면 지도(전면) — 베이스는 회색 도로망과 흰·회색 건물 윤곽, 바다 연청. 뉴딜구역(검정 일점쇄선 경계)만 반투명 6색 면으로 구역화하고, 오른쪽 대상지(이전 장들의 중점설계구역)는 균일한 회색 면으로 눌러 둠(별도 강조 없음) — 약 94% — 평면 정사영, 채도: 베이스 낮음 / 구역색 중~높음, 인물·식생 표현 없음.
  2. 구역 라벨 — 대문자 영문 라벨을 구역 모양을 따라 회전·기입. 큰 흰색 대문자 = 주 용도(EDUCATION, APARTMENT HOUSES, RETAIL, CULTURE, INDUSTRY, COMMUNITY, MAIN AXIS), 작은 연한 대문자 = 세부 프로그램·분위기 키워드(PLAYGROUND, HIGH SCHOOL, LIBRARY, MIDDLE SCHOOL, NETWORK, FARM, PARK, PARKING, TREES, LIVELY, CALM, SOCIAL, URBAN FARM, MART, PUBS, CAFE, VILLAGE EVENT, EXPERIENCE, COOKING CLASS, OFFICE, OLD VILLAGE, DETACHED HOUSES, TOUR BUS, ATTRACTIVE, STREET MARKET, REGENERATION BY RESIDENTS 등).
  3. 분홍 굵은 화살표 "MAIN AXIS" — 남서에서 북동으로 구역을 가로질러 대상지의 "CENTRAL PLAZA"를 향함(화살촉이 대상지 경계 안으로 들어감), 축 위에 짙은 분홍 노드("PLAZA", "RETAIL", "COMMUNITY EVENT PLAZA", "COMMUNITY PUBS", "CAFE")와 옅은 분홍 띠("MIXED-USE").
- 다이어그램 해부: 색 코딩(범례 없이 라벨로 의미 전달): 분홍 = 상업·광장·교류(주축과 노드), 노랑 = "APARTMENT UNIT IN A HOUSE"(기존 주택을 다가구 유닛으로 개조하는 주거) + 주차·도시 농장, 청색 = APARTMENT HOUSES(공동주택), 주황 = OLD VILLAGE·DETACHED HOUSES·FARM(기존 마을 보존) + INDUSTRY·OFFICE(대상지 인접 업무 띠), 장미 = CULTURE(체험·쿠킹 클래스), 보라 = EDUCATION(중·고교·도서관·운동장·초등학교). 정보 위계: MAIN AXIS(1순위, 가장 큰 글자·가장 진한 노드) > 큰 구역 라벨 > 세부 키워드. 읽는 순서: 제목 → MAIN AXIS(남서 → 북동) → 구역별 큰 라벨 → 작은 키워드. 회전 규칙: 라벨이 구역 형태의 장축을 따라 기울어짐. 스케일·방위 표기 없음. 도면 위 텍스트 양: 많음(약 60개 라벨), 단 글씨가 대문자 짧은 단어라 판독은 빠름.
- 텍스트: 제목 "New Deal Zone:  Character Zones" / 한글 "뉴딜구역 : 주요쟁점의 해결방안 모색". 지도 라벨은 영문 대문자만(한글 없음). 톤: 명사·형용사 키워드(LIVELY, CALM, ATTRACTIVE).
- 발표 설득 기능: "뉴딜구역 재생은 한 가지 프로그램이 아니라 성격이 다른 8개 안팎의 마을 구역(교육·주거·마을·문화·산업·상업 축)으로 짜인다"는 구도를 한 장으로 제시하고, MAIN AXIS가 대상지 중앙 광장과 이어짐을 강조. 발표자 한 문장(추정): "구도심 한가운데 주축이 중앙 광장으로 이어지고, 교육·주거·문화·산업이 그 축 주위에 성격별로 모입니다." 보고서 p.49(인쇄 43) "Construction of Existing Open space | 기존 오픈스페이스의 활용" 또는 p.48의 뉴딜구역 계획도에 대응(추정).
- 앞뒤 연결: s.56(주차 → 공원 → 커뮤니티의 4단계) → s.57(구역별 성격 지정) → s.58(커뮤니티 공간 활성화)로 "쟁점 → 구역 → 장소" 순서. 묶음 중간.

### s.58 — New Deal Zone:  Enliven a Community Space (뉴딜구역 : 커뮤니티 공간의 활성화 방안)
- 유형: AERIAL(조감 축측도 + 거점 표시) / ICON-SYSTEM(활동 픽토그램) / PRECEDENT(원형 사진 9개)
- 섹션·역할: REGENERATION / 초록 세로띠 / 뉴딜구역 4장 묶음의 마무리 — 앞 장들의 개념(상생·쟁점 해법·성격 구역)을 "주민이 실제 쓰는 거점 7곳 + 프로그램 9종"으로 구체화하는 실행 슬라이드.
- 레이아웃: 좌측 초록 세로띠. 제목 좌상단 굵게 "New Deal Zone:  Enliven a Community Space", 한글 우상단 굵게 "뉴딜구역 : 커뮤니티 공간의 활성화 방안". 가운데 가로 띠(제목 아래부터 약 59% 높이)에 조감 축측도(우측 끝까지), 하단 약 22%에 원형 사진 9개 한 줄 + 캡션, 그 사이 얇은 여백. 이미지:텍스트 ≈ 90:10. 색: 회색 매스(기존) + 살구/연한 적색 매스(신축·리모델링) + 연두 녹지 + 적색 점선 원(거점) + 검정 픽토그램.
- 시각자료 인벤토리:
  1. 조감 축측도(가로 띠) — 기존 시가지는 회색·흰 매스, 변경·신축 건물은 살구색(연한 적색) 면, 녹지·마당은 연두와 짙은 녹색 수목 + 검정 점경 인물 다수, 각 거점을 적색 점선 원으로 둘러 강조(약 7개), 좌측은 바다 연청 + 해안공원 — 약 55% — 시점 약 40° 조감, 주간, 채도: 맥락 낮음 / 거점 중간, 인물은 검정 실루엣이라 사실감보다 활동량 표시.
  2. 프로그램 라벨 + 픽토그램 세트 — 살구색 글자 프로그램명 위에 검정 선 픽토그램 3~5개를 한 줄로(놀이터, 4인 군상, 울타리와 나무, 해와 새싹, 정원사, 가게 입면, 커피잔, 정보(i), 식기, 주차 P 건물, 물가 나무). 라벨: "Tongyeong 1945"(아이콘 없음) / "Playground for Local residents"(2곳) / "Cafe & Garden" / "Urban Farm" / "Community Center" / "Tongyeong Social Dining" / "Ocean Community Pubs" / "Ocean Road Walking Festival" / "Upcycling Music Performance".
  3. 주차 표식 — 작은 원 안의 "P"가 살구색 건물 위에 곳곳에 찍혀 있음(주차 타워/주차 건물 위치로 읽힘, s.56의 "Procure Parking zone"과 연결, 추정).
  4. 원형 사진 9개(회색 테두리, 지름 약 8%) + 캡션 — "Community Garden"(계단식 텃밭 조감), "Urban-Farm"(온실형 도시 농장 일러스트), "Community Center"(전시/강연을 듣는 사람들), "Cultural Street"(채색 캐노피가 덮인 거리), "Ocean Art Park"(해변의 노란 점박이 호박 조형물; 해외 유명 설치작 사례로 추정), "Playground"(어린이 놀이터), "Tongyeong 1945"(레트로 거리를 보는 두 사람), "Upcycling Art Factory"('UP CYCLE' 그래픽 벽), "Ocean Community Pubs"(바에서 식사하는 사람들).
- 다이어그램 해부: 읽는 순서는 제목 → 조감 축측도 위 적색 점선 원(거점의 위치) → 원 옆 프로그램 라벨·픽토그램(거기서 무엇을 하는가) → 하단 원형 사진(분위기 참고). 기호 규칙: 적색 점선 원 = 커뮤니티 공간 거점, 살구색 건물 = 신축·리모델링, 연두 = 신설 오픈스페이스, 검정 점경 = 보행·활동량, "P" 원 = 주차, 픽토그램 줄 = 그 거점에서 일어나는 활동의 약식 목록. 별도 범례 박스는 없고 라벨과 픽토그램이 스스로 설명(라벨 색은 살구색이라 흰 배경에서 대비가 낮음). 정보 위계: 조감도 > 라벨·픽토그램 > 원형 사진. 스케일·방위 없음. 도면 위 텍스트: 프로그램 라벨 10개 내외.
- 텍스트: 제목 "New Deal Zone:  Enliven a Community Space" / "뉴딜구역 : 커뮤니티 공간의 활성화 방안". 사진 캡션 9개(영문, 약 10pt, 하단 가운데). 한글은 부제만. 글자 수 적음. 톤: 명사구, 지역 고유 명칭("Tongyeong 1945", "Ocean Community Pubs")을 프로그램명에 삽입(s.32의 "1945 YoungMen Dazzi"와 같은 계열).
- 발표 설득 기능: "상생"을 구체적인 장소 7곳과 활동 9종으로 번역해 심사위원이 상상할 수 있게 함. 발표자 한 문장(추정): "골목마다 놀이터·텃밭·마을 식당·펍 같은 작은 거점을 넣어, 주민이 먼저 쓰는 공간부터 만듭니다." 보고서 p.50~51(인쇄 44~45) "New Deal Zone: Enliven a Community Space | Cultural Contents of Public Space Composition | 커뮤니티 공간의 활성화 방안"을 압축(한글 부제 일치).
- 앞뒤 연결: s.57(구역 성격) → s.58(거점·프로그램) → s.59(Business Strategy 구분)로 챕터 종료. 묶음 끝(s.55~58 뉴딜구역 4장의 끝).
